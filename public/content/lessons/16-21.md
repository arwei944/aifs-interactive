# 代理经济，代币激励，声誉

> 长期自主代理（METR的1小时到8小时工作曲线）需要经济代理。新兴的**5层栈**是：**DePIN**（物理计算）→**Identity** （W3C did +声誉资本）→**Cognition** (RAG + MCP)→**Settlement**（账户抽象）→**Governance** (agent dao)。生产代理激励网络包括**Bittensor** （TAO子网奖励任务特定模型）、**Fetch。ai / ASI Alliance** （ASI-1 Mini LLM + FET令牌）和**Gonka**（基于变压器的PoW，将计算重新分配给生产性ai任务）。学术工作：AAMAS 2025的去中心化LaMAS采用Shapley-value信用归属**来公平奖励贡献主体；谷歌研究“大型语言模型的机制设计”提出了单调聚合下具有二次价格支付的代币拍卖。本课程构建了一个最小的代理市场，将Shapley-value信用归属应用于多代理管道，并运行第二价格代币拍卖，从而使博弈论机制具体实现。

## 问题

当多个主体共同创造价值但需要单独奖励时，多主体系统会变得复杂。传统机制——平均分配、最后贡献者通吃——是不公平的，或者是可游戏的。基于Shapley值的基于联盟的奖励在结构上是公平的，但计算成本很高。2025-2026年的文献提出了有用的近似值：沙普利抽样，单调聚合拍卖，以及从确认的贡献中积累的链上声誉。

除了信用归属之外，该领域已经转向了实际的经济主体：Bittensor TAO奖励挖掘计算来微调特定子网的模型Fetch。ai/ASI用FET令牌奖励ASI-1 Mini LLM的使用，Gonka将变压器工作量证明重新分配给生产性ai任务。目前存在自主交易的代理；问题是如何协调激励措施。

本课将代理经济视为一个特定的问题家族——信用归因、机制设计和声誉——并用最简单的数学方法构建每个问题家族，从而使思想得以坚持。

## 概念

### 5层代理经济堆栈

1. **DePIN（物理计算）。**租用GPU、存储、带宽的去中心化基础设施。Bittensor子网，渲染网络，Akash。不是智能体;代理使用它。
2. * *的身份。** W3C分散式标识符（did）为每个代理提供独立于任何平台的持久ID。声誉累积到DID。代理网络协议（ANP）使用DID作为发现层。
3. * *认知。**代理推理回路：LLM + RAG + MCP。这是其他阶段构建的。
4. * *解决方案。**账户抽象（ERC-4337）允许代理从自己的余额中支付gas，而无需持有ETH。代理可以为服务、彼此或计算付费。
5. * *治理。**代理dao：人类和代理对协议更改进行投票的治理结构，投票权与声誉挂钩。

并不是每个生产系统都使用这五种方法。Bittensor使用1,2，部分3，部分4，不使用5。OpenAI代理只使用3。堆栈是一个引用映射，而不是必需的。

### Bittensor,取回。刚卡，什么东西在跑

** Bittensor(道)。子网是专门的任务（语言建模、图像生成、预测）。矿工提交模型输出。验证器对它们进行排序；加权得分分配TAO奖励。每个子网都有自己的评估。经济上的教训是：为特定任务的输出质量付费，而不是为使用的计算付费。

**获取。ai / ASI联盟。** ASI-1迷你LLM运行在Fetch上。​用户支付FET令牌进行推理。代理作为对等体的叙述在这里更强：Fetch上的代理可以调用另一个代理来完成任务并支付FET。

** Gonka。**变压器工作证明：“工作”是变压器的正向传递。矿工通过运行已知正确输出（来自训练数据）的推理任务来赚钱。资源生产性PoW，而不是基于哈希的PoW。

截至2026年4月，这三个都是生产级。收益分配不同。Bittensor相对于子网验证器奖励质量；付费用户衡量的获取奖励效用；Gonka奖励可验证的推理工作。

### Shapley-value信用归因

三个代理协作完成一项任务。输出得分为0.8。谁贡献了什么？

Shapley值：满足四个公理（效率、对称、线性、零）的唯一信用分配。代理

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

在哪里在实践中：列举所有排列，记录每个agent在每个排列中的边际贡献，平均值。

对于N=3个agent，有6种排列。对于N=10, 3.6M -所以在实践中你抽样排序而不是枚举。

### 第二价格拍卖的集合

谷歌Research（“大型语言模型的机制设计”）提出了用于聚合LLM输出的二级价格代币拍卖。设置：N个代理各提出一个完成；每个都有一个被选择的私有值。拍卖师挑选价值最高的提案，并支付“第二高”的价格。在单调聚合（价值取决于选择哪一个提议，而不是出价多少）下，这是真实的——代理出价他们的真实价值。

为什么这对LLM系统很重要：你可以以不同的价格将完成任务外包给多个代理；拍卖会挑选最优秀的人，而且报酬公平，经纪人也没有作假的动机。

### 声誉资本

与did绑定的声誉评分从确认的贡献中累积。一个简单的更新规则：

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

带有衰减因子声誉:

- 阅读路由决策（“将困难任务发送给高代表代理”）的成本很低。
- 伪造成本高（随时间累积，绑定到DID）。
- 可删减：验证失败的贡献减去。

### AAMAS 2025分散喇嘛

LaMAS提案（AAMAS 2025）结合了DID身份、Shapley-value信用归属和简单的拍卖机制。关键主张：分散信用归属步骤使系统可审计并且不受单点操纵的影响。

### 经济在哪里崩溃

- **价格oracle操纵。**如果信用函数可以博弈，代理就会进行博弈。每个机制都需要对抗性测试。
- * *女巫攻击。**一个经营者编造了N个假代理人来夸大他们自己的贡献。did会减慢但不会停止；声誉锻造成本是缓解措施。
- * *验证成本。**信用归属只与验证者一样公平。如果验证成本低（小型LLM），则可以进行博弈；如果昂贵（人工面板），系统无法扩展。
- * *监管过剩。**代理经济与金融监管交叉。截至2026年，Bittensor、Fetch和Gonka在一些司法管辖区都处于法律灰色地带。

### 当代理经济有意义时

- **异构运营商的开放网络。**没有一个团队可以控制所有代理。
- * *可核查的输出。**未经核实，信用归属是猜测。
- * *世界工作流。**一次性任务不会从声望积累中获益。
- 在您的管辖范围内，代币化支付在法律上是可行的。

在封闭的企业体系中，经济学让位于更简单的分配（经理分配工作，指标是内部的）。经济学文献大多适用于开放网络。

## 船这

2026年运行代理经济：

- **从声誉开始，而不是代币。**声誉的执行成本很低，但它本身就很有价值；代币增加了法律和经济的复杂性。
- **奖励前验证。**不要在没有独立验证步骤的情况下分发信用。自我报告的质量累积在游戏中。
- **沙普利样本，而不是沙普利精确值。**样品100-1000次订购；精确枚举不能伸缩。
- **瓶盖腐烂系数和地板声誉。**无界衰变清除合法贡献者；太慢的衰退只会奖励那些陈腐的高级特工。
- **对抗性审计机制。**打开网络前先运行红队场景。每个机制都有一个博弈论；你要找到漏洞，而不是攻击者。

## 练习

1. 运行确认Shapley值总和为总价值（效率公理）。改变价值函数；沙普利分配是否会朝着预期方向变化？
2. 实现Shapley *采样* （K阶蒙特卡罗）。K如何影响近似精度？比较N=4时的精确值。
3. 在拍卖前实施联盟形成步骤：代理人可以合并成团队并作为一个单位进行竞标。形成了哪些联盟？帕累托结果比个人竞价更好吗？
4. 阅读谷歌Research机制设计帖子。确定一个假设，如果违反，就会破坏真实性。在LLM设置中，失败模式是什么样的？
5. 阅读AAMAS 2025分散LaMAS论文。在一个合成任务中对10个代理执行Shapley步骤。精确计算需要多长时间？100次抽取的抽样结果有多接近？

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| DePIN | "Decentralized physical infrastructure" | Token-incentivized compute/storage/bandwidth. Bittensor, Akash, Render. |
| DID | "Decentralized identifier" | W3C spec for portable IDs. Agent reputation binds to DID, not to a platform. |
| ERC-4337 | "Account abstraction" | Contract accounts that can sponsor gas, enabling agent payments. |
| Shapley value | "Fair credit attribution" | Unique allocation satisfying efficiency, symmetry, linearity, null. |
| Second-price auction | "Vickrey auction" | Truthful mechanism: winner pays second-highest bid. Monotone aggregation compatible. |
| Reputation capital | "Accumulated quality score" | DID-bound score from confirmed contributions; decays over time. |
| Agentic DAO | "Agents + humans govern" | DAO with agent voters as first-class, voting power tied to reputation. |
| TAO / FET / GPU credits | "Token denominations" | Bittensor TAO, Fetch.ai FET, various DePIN tokens. |
