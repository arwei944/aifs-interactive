# 音频变压器-耳语架构

> 音频是频率随时间变化的图像。Whisper是一种虚拟计算机，它可以吃掉我的频谱图，然后回应我。

**Type:** Learn
**Languages:** Python
**Prerequisites:** Phase 7 · 05 (Full Transformer), Phase 7 · 08 (Encoder-Decoder), Phase 7 · 09 (ViT)
**Time:** ~45 minutes

## 这个问题

在Whisper （OpenAI, Radford et al. 2022）之前，最先进的自动语音识别（ASR）意味着wav2vec 2.0和HuBERT——自监督特征提取器加上微调头部。高质量，昂贵的数据管道，域脆弱。多语言语音识别需要每个语言族单独的模型。

Whisper下了三个赌注：

1. **培训一切。**从97种语言的互联网上抓取了68万小时的弱标记音频。没有干净的学术语料库。没有音素标签。
2. **多任务单模型。**一个解码器通过任务令牌进行转录，翻译，语音活动检测，语言ID和时间戳的联合训练。
3. **标准编码器-解码器变压器。**编码器消耗对数谱图。解码器自动回归生成文本标记。没有声码器，没有CTC，没有HMM。

结果：Whisper large-v3在没有清晰标记数据的口音、噪音和语言中都很健壮。它是2026年所有开源语音助手和大多数商业语音助手的默认语音前端。

## 这个概念

Z0

### 步骤1 -重新采样+窗口

音频在16 kHz。剪辑/垫到30秒。计算对数元谱图：80元箱，10毫秒步幅→~ 3000帧× 80个特征。这是Whisper看到的“输入图像”。

### 步骤2 -卷积系统

两个具有内核3和步幅2的Conv1D层将3000帧减少到1500帧。在不添加大量参数的情况下将序列长度减半。

### 步骤3 -编码器

一个24层（大型）变压器编码器超过1500个时间步长。正弦位置编码，自注意，GELU FFN。产生1500 × 1280个隐藏状态。

### 步骤4 -解码器

24层变压器解码器。它自回归地从BPE词汇表生成标记，该词汇表是GPT-2的超集，具有一些特定于音频的特殊标记。

### 步骤5 -任务令牌

解码器提示符以控制令牌开始，告诉模型该做什么：

```
<|startoftranscript|>  <|en|>  <|transcribe|>  <|0.00|>
```

或

```
<|startoftranscript|>  <|fr|>  <|translate|>   <|0.00|>
```

这个模型是根据这个惯例训练的。通过前缀控制任务。2026年相当于指令调整，但应用于语音。

### 步骤6 -输出

具有log- probb阈值的波束搜索（宽度5）。在音频中每0.02秒预测一次时间戳

## 构建它

参见我们不训练Whisper——我们构建对数谱图管道+任务令牌提示格式器。这些是你在生产中实际接触到的部件。

### 步骤1：合成音频

产生一个1秒的正弦波在440hz采样在16khz。16000个样本。

### 第二步：对数谱图（简化）

全mel谱图需要FFT。我们做了一个简化的帧+每帧能量版本，显示管道而不需要

”“python
Def frame_signal(x, frame_size=400, hop=160)：
帧= []
For start in range(0, len(x) - frame_size + 1, hop)：
帧。附加（x[start:start + frame_size]）
返回帧
```

Frame = 25 ms, hop = 10 ms. Matches Whisper's windowing. Per-frame energy stands in for mel bins for pedagogy.

### Step 3: pad to 30 s

Whisper always processes 30-second chunks. Pad (or clip) the spectrogram to 3,000 frames.

### Step 4: build the prompt tokens

```python
def whisper_prompt(lang="en", task="transcribe", timestamps=True):
    tokens = ["<|startoftranscript|>", f"<|{lang}|>", f"<|{task}|>"]
    if not timestamps:
        tokens.append("<|notimestamps|>")
    return tokens
```

这就是整个任务控制界面。4个令牌前缀。

## 练习

1. * *容易。**运行确认16 kHz，跳数10毫秒的1秒信号的帧数为~100帧。30秒：~ 3000帧。
2. * *介质。构建完整的对数谱图验证80个箱子是否匹配
3. * *难。**实现流推理：将音频块分成10秒的窗口，重叠2秒，在每个块上运行Whisper，合并转录。在一个5分钟的播客样本中测量单词错误率和单次通过。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Mel spectrogram | "Audio image" | 2D representation: frequency bins on one axis, time frames on the other; log-scaled energy per cell. |
| Log-mel | "What Whisper sees" | Mel spectrogram passed through log; approximates human perception of loudness. |
| Frame | "One time slice" | A 25 ms window of samples; overlapping at 10 ms stride. |
| Task token | "Prompt prefix for speech" | Special tokens like `<|transcribe|>` / `<|translate|>` in the decoder prompt. |
| Voice activity detection (VAD) | "Find the speech" | Gate that removes silence before ASR; cuts cost massively. |
| CTC | "Connectionist Temporal Classification" | Classic ASR loss for alignment-free training; Whisper does NOT use it. |
| Whisper-turbo | "Small decoder, full encoder" | large-v3 encoder + 4-layer decoder; 8× faster decoding. |
| Faster-whisper | "The production wrapper" | CTranslate2 reimplementation; int8 quantization; 4× faster than OpenAI's reference. |
