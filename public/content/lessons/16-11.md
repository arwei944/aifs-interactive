# 移交和例程——无状态编排

> OpenAI的Swarm（2024年10月）将多代理编排提炼为两个基本要素：**例程**（指令+工具作为系统提示符）和**移交**（返回另一个代理的工具）。没有状态机，没有分支DSL——LLM通过调用正确的切换工具进行路由。OpenAI Agents SDK（2025年3月）是生产后继产品。Swarm本身仍然是最干净的概念参考——它的整个源代码只有几百行。这种模式是病毒式传播的，因为API表面大致是“代理=提示+工具；切换=函数返回代理。”限制：无状态，所以内存是调用者的问题。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 04 (Primitive Model)
**Time:** ~60 minutes

## 问题

每个多代理框架都希望您学习它的DSL: LangGraph节点和边缘，CrewAI人员和任务，AutoGen GroupChat和管理器。dsl是真正的抽象，但它们让事情看起来比实际需要的要沉重。

Swarm向相反的方向推进：使用模型已经拥有的工具调用能力。交接变成了工具调用。协调器是当前持有对话的代理。状态机隐含在代理的系统提示中。

## 概念

### 两个原语

**例行公事。**定义座席角色和可用工具的系统提示符。你可以把它想象成一组限定范围的指令：“你是一个分诊代理；如果用户要求退款，就交给退款代理。”

**切换。一个代理可以调用的工具，它返回一个新的代理对象。Swarm运行时检测Agent返回值并为下一回合切换活动代理。

这是整个抽象概念。

```
def transfer_to_refunds():
    return refund_agent  # Swarm sees Agent return → switch active agent

triage_agent = Agent(
    name="triage",
    instructions="Route the user to the right specialist.",
    functions=[transfer_to_refunds, transfer_to_sales, transfer_to_support],
)
```

分诊代理的系统提示使其根据用户消息选择正确的切换。LLM的工具调用完成了路由。

### 为什么它是病毒性的

- * *小API。**学习两个概念。
- **使用模型已有的功能。**工具调用已经是跨提供商的生产级。
- **没有状态机负担。**不要描述图形；特工的提示描述了他们交给谁。

### 无国籍贸易

Swarm在运行之间是显式无状态的。框架在运行期间保留消息历史记录，但不持久化任何内容。内存、连续性、长时间运行的任务——都是调用者的问题。

在生产中（OpenAI Agents SDK， 2025年3月），这是主要的变化之一：SDK增加了内置会话管理、护栏和跟踪，同时保持了切换原语。

### 当蜂群/交接合适时

- * *分类模式。**前线座席将用户转给专家。
- * *技能的传递。**“如果任务需要代码，请致电编码员；如果需要研究，就给研究人员打电话。”
- **简短、有限的对话。**客户支持，常见问题到票证，简单的工作流程。

### 当Swarm挣扎时

- **使用共享内存的长时间会话。**切换将会话状态重置为新座席的提示加上历史记录。没有调用者管理的内存的代理之间没有持久状态。
- * *并行执行。**切换是一次一个-主代理切换。并行性要求调用者协调多个Swarm运行。
- **审计和重播。**无状态运行很难精确回放；法学硕士的交接选择不是确定的。

### OpenAI Agents SDK（2025年3月）

生产继任者补充道：

- * *会话状态。**跨运行的持久线程。
- * *护栏。**输入/输出验证挂钩。
- * *跟踪。**每个工具调用和移交都被记录。
- * *切换过滤器。**控制切换时的上下文传输。

传递原语保留了下来；生产人体工程学在它周围添加。

## 船这

检查表:

- * *切换日志记录。**每次切换写入跟踪事件与从代理，到代理，上下文快照。
- **上下文转移规则。**决定在移交时移动什么：完整的历史记录（昂贵的），最后N条消息，或摘要。
- **护栏交接。**与具有不同工具权限的专家的交接必须经过身份验证-否则提示注入可能会强制不必要的交接。
- * *循环检测。**两个代理来回传递是常见的故障；用简单的最后k环检查检测。
- * *回退的代理。**如果切换目标不存在，则退回到安全默认值。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Routine | "The agent prompt" | System prompt + tool list. Defines role and available handoffs. |
| Handoff | "Transfer to another agent" | A tool the active agent can call that returns a new Agent. The runtime switches active agent. |
| Stateless | "No memory between runs" | Swarm does not persist anything; memory is the caller's responsibility. |
| Active agent | "Who's speaking now" | The agent currently holding the conversation. Handoff changes this. |
| Context transfer | "What moves on handoff" | Policy for what history the incoming agent sees: full, last N, or summarized. |
| Handoff loop | "Agents ping-pong" | Failure mode where two agents keep handing back to each other. |
| OpenAI Agents SDK | "Production Swarm" | March 2025 successor; adds sessions, guardrails, tracing on top of the handoff primitive. |
| Handoff filter | "Gate on transfer" | SDK feature to inspect and modify context at the handoff boundary. |
