# 直接偏好优化家族

> Rafailov et al.（2023）表明RLHF的最优在偏好数据方面具有封闭的形式，因此可以跳过显式奖励模型直接优化策略。这一见解催生了一个家族——IPO、KTO、SimPO、ORPO、BPO——每个家族都修复了DPO的一种失败模式。在2026年，直接对齐算法比PPO提供了更多的前沿训练后运行。但第2课的过度优化曲线仍然适用：daa不会逃离Goodhart，它们只是移动到它叮咬的地方。

## 这个问题

RLHF目标（第一课）：

```
max_pi E_{x,y~pi} [ r(x, y) ] - beta * KL(pi || pi_ref)
```

有一个已知的最佳值：

```
pi*(y|x) = (1/Z(x)) * pi_ref(y|x) * exp(r(x, y) / beta)
```

因此，奖励隐含地由最优策略与参考策略之比定义：

```
r(x, y) = beta * log(pi*(y|x) / pi_ref(y|x)) + beta * log Z(x)
```

将其代入布拉德利-特里偏好似然和配分函数剩下的只是政策参数方面的损失——不需要任何奖励模式。这就是DPO。

难点在于：推导假设最优是可达的，偏好数据是分布中的，参考策略是真模式锚。这些说法都不准确。每个家庭成员都有不同的被侵犯假设。

## 这个概念

### DPO （Rafailov等人，2023）

```
L_DPO = -log sigmoid(
  beta * log(pi(y_w | x) / pi_ref(y_w | x))
  - beta * log(pi(y_l | x) / pi_ref(y_l | x))
)
```

哪里会出错：

- 隐性奖励差距一个微小的偏好可以产生任意大的差距。
- 损失驱动被选择和被拒绝的对数概率朝相反的方向运动。只要被拒绝的绝对对数下降得更快，它就可以将选择的绝对对数向下推。这就是退化选择响应现象。
- 非分布偏好（稀有配对vs稀有配对）会产生任意的隐性奖励。

### IPO （Azar等人，2024年）

身份偏好优化用偏好概率上的身份映射替换log-s形。损失变成了有界目标上的平方误差：

```
L_IPO = (log(pi(y_w | x) / pi_ref(y_w | x)) - log(pi(y_l | x) / pi_ref(y_l | x)) - 1/(2 beta))^2
```

边界由偏好强度与内隐奖励差距成正比。没有放大。

### KTO (Ethayarajh et al., 2024)

Kahneman-Tversky优化完全放弃了成对结构。给定单个标记输出和二进制“理想”或“不理想”信号，它映射到前景理论效用：

```
v(x, y) = sigma(beta * log(pi(y|x) / pi_ref(y|x)) - z_ref)
```

对收益和损失有不同的权重（损失厌恶）。好处：你可以使用非配对数据，这种数据要丰富得多。

### SimPO（孟等人，2024）

简单偏好优化将训练信号与生成信号对齐。完全删除引用策略并按长度规范化对数似然：

```
L_SimPO = -log sigmoid(
  (beta / |y_w|) * log pi(y_w | x)
  - (beta / |y_l|) * log pi(y_l | x)
  - gamma
)
```

有限度地长度归一化消除了利用DPO的长度偏差失效模式（更长）的动机

### ORPO （Hong et al., 2024）

比值偏好优化在标准SFT负对数似然中添加了一个偏好项：

```
L_ORPO = L_NLL(y_w) + lambda * L_OR
L_OR = -log sigmoid(log(odds(y_w) / odds(y_l)))
```

没有引用策略- SFT术语是正则化器。从基本模型到对齐模型的单阶段训练。没有单独的SFT检查点。

### BPO （ICLR 2026提交，OpenReview id=b97EwMUWu7）

识别退化选择响应问题：DPO保留排名BPO添加了单行修正，惩罚所选响应的向下移动。Llama-3.1-8B-Instruct在DPO上的数学推理准确率+10.1%。

### 普遍的结果是：daa仍然过度优化

Rafailov等。“直接对齐算法中奖励模型过度优化的缩放定律”（NeurIPS 2024）在跨KL预算的多个数据集上使用DPO， IPO， SLiC训练策略。gold-reward- kl曲线具有与Gao等人相同的峰崩形状。隐式奖励在训练过程中查询分布外样本；KL正则化不能稳定这一点。

daa逃不过古德哈特。它们改变了问题的表面，从“奖励模式过度优化”变成了“参考政策比率过度优化”。通用的解决办法——更好的数据、整合、提前停止——适用于两者。

### 从中选择（2026）

- 如果你有大量的配对偏好数据：DPO与保守的beta， SimPO如果长度偏差是明显的。
- 如果您有未配对的二进制反馈：KTO。
- 如果您想要一个来自基本模型的单级管道：ORPO。
- 如果您在DPO日志中看到降级的选择日志问题：BPO。
- 如果偏好优势差异很大，DPO趋于饱和：IPO。

每个实验室都用一个电池来运行这五个系统，并在每个任务中选出赢家。没有理由说数学推理和安全的最佳值是一样的。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| DPO | "RLHF without a reward model" | Loss derived from the closed-form RLHF optimum; policy parameters only |
| Implicit reward | "the log-ratio" | `beta * log(pi(y|x) / pi_ref(y|x))` — the DPO-implied reward |
| IPO | "bounded DPO" | Replaces log-sigmoid with identity; implicit reward gap capped by `1/(2 beta)` |
| KTO | "unpaired DPO" | Prospect-theory utility over single labels with loss aversion |
| SimPO | "reference-free DPO" | Length-normalized log-likelihood + margin; no reference policy |
| ORPO | "one-stage DPO" | NLL + odds-ratio preference term; trains from base model in one pass |
| BPO | "chosen-preserving DPO" | DPO plus a penalty for decreasing the chosen response's absolute log-prob |
| Degraded Chosen | "chosen goes down" | DPO decreases chosen log-prob so long as rejected falls faster |
| DAA | "direct alignment algorithm" | Any preference-loss method that skips an explicit RM |
