# Speech Recognition (ASR) - CTC, RNN-T, note

> Speech recognition classifies audio at each time step by gluing together a sequence model that knows English and silence. CTC, RNN-T and attention are three methods. Choose one and understand the reason.

**Type:** Build
**Languages:** Python

## This question

You have a 10-second 16 KHZ clip. You want a string: "Turn on the kitchen light." The challenge is structural: audio frames do not align one-to-one with the characters. The word "okay" might take 200 milliseconds or 1200 milliseconds. Silence is the punctuation mark of words. Some phonemes are longer than others. The number of output tokens is unknown in advance.

There are three formulas that can solve this problem:

1. CTC (Connectionist Temporal Classification). Issue the token probability for each frame, including a special "blank". During decoding, crash repetitions and blanks. Non-autoregressive, fast. Use wav2vec 2.0, MMS.
2. RNN-T (Recurrent Neural Network Sensor). The joint network predicts the next token for a given encoder frame and the previous token. Streamable. The ASR on Google's device is used by NVIDIA's long-tailed parrot.
3. Pay attention to the encoder-decoder. The encoder compresses the audio to hide the state, and the decoder cross-attends autoregressive to generate the token. Use Whisper, Seamless m4t.

In 2026, in the librisspeech test, the support rate of SOTA was 1.4% (Parakeet-TDT-1.1B, NVIDIA) and 1.58% (Whisper-Large-v3-turbo). The difference is very small; The deployment differences are huge.

## This concept


*The intuition of CTC. Let the encoder output the total CTC loss of all these lines for the target string. Reasoning: Each frame argmax, crash and repeat, delete blank Spaces.

Advantages: Non-autoregressive, fluidizable, zero lead. Disadvantage: * Conditional Independence assumption * - Each frame prediction is independent, so there is no internal language model. Repair the external LM through beam search or shallow fusion.

*RNN-T intuition. A * predictor * network has been added, embedded with token history and a *joiner*, which combines the predictor state with the encoder frame into a joint distribution to explicitly simulate the conditional dependencies ignored by CTC. It can be streamed because each step only requires past frames and past tokens.

Advantages: Flowable + internal LM. Disadvantages: More complex training and memory consumption (3D loss lattice); The RNN-T loss kernel function itself is a complete library.

** encoder-decoder follow. The encoder (6-32 transformer layer) is in logarithmic frames. The decoder (6-32 transformer layer) cross-pays attention to the encoder output to generate tokens autoregressively. No alignment constraints - attention can be focused anywhere in the audio. Non-flow, unless you limit your attention (Block Whisper flow, 2024).

Advantages: The highest quality on offline ASR and easy to train with standard seq2seq tools. Disadvantage: The autoregressive delay is proportional to the output length; There can be no flow without engineering.

### Step 2: beam-search CTC

```python
def ctc_beam(frame_logits, beam=8, blank=0):
    import math
    beams = [([], 0.0)]  # (tokens, log_prob)
    for p in frame_logits:
        log_p = [math.log(max(pi, 1e-10)) for pi in p]
        candidates = []
        for seq, lp in beams:
            for t, lpt in enumerate(log_p):
                new = seq[:] if t == blank else (seq + [t] if not seq or seq[-1] != t else seq)
                candidates.append((new, lp + lpt))
        candidates.sort(key=lambda x: -x[1])
        beams = candidates[:beam]
    return beams[0][0]
```

Production adopts the integration of prefix tree beam search and LM. This is the conceptual framework.

## Pitfalls that still ship in 2026

- **No VAD.** Running Whisper on silence produces hallucinations ("Thanks for watching!"). Always gate with VAD.
- **Character vs word vs subword WER.** Report word-level WER *after* normalization (lowercase, punctuation stripped).
- **Language ID drift.** Whisper's auto LID mis-routes noisy clips to Japanese or Welsh; force `language="en"` when you know.
- **Long clips without chunking.** Whisper has a 30-second window. Use `chunk_length_s=30, stride=5` for anything longer.

## Key Terms

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| CTC | The blank-token loss | Marginal over all frame-to-token alignments; non-AR. |
| RNN-T | The streaming loss | CTC + next-token predictor; handles word-order. |
| Attention enc-dec | Whisper-style | Encoder + cross-attending decoder; best offline quality. |
| WER | The number you report | `(S+D+I)/N` at word level. |
| Blank | The emptiness | Special token in CTC signalling "no emission this frame". |
| LM fusion | External language model | Add weighted LM log-probs during beam search. |
| VAD | The silence gate | Voice activity detector; trims non-speech. |
