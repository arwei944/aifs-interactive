# 建立一个MCP客户端-发现，调用，会话管理

> 大多数MCP内容都会发布服务器教程并向客户端挥手示意。客户端代码是硬编排所在的地方：流程生成、功能协商、跨多个服务器的工具列表合并、抽样回调、重新连接和名称空间冲突解决。本课构建了一个多服务器客户机，该客户机将三个不同的MCP服务器提升到模型的一个平面工具名称空间中。

### 合并后的名称空间

当客户端看到聚合工具列表时，名称可能会发生冲突。两个服务器可能都公开客户端有三个选项：

1. **以服务器名称作为前缀。**清晰但丑陋。
2. 先**沉默。**后期服务器风险;隐藏了碰撞。
3. **碰撞被拒绝。**拒绝加载第二服务器；通知用户。对安全敏感的主机最安全。

Claude Desktop使用逐服务器前缀。游标使用冲突拒绝并显示明显错误。VS Code MCP也采用了逐服务器前缀。

### 通知处理

`notifications/resources/updated` means re-read the resource if it is in use. 通知不能产生响应——不要试图回复它们。

一个常见的客户机错误：阻塞读循环使用后台读线程将每个消息推入队列；主线程去队列和分派。

### 重新连接

传输可能失败：服务器崩溃，操作系统终止进程，工作室管道破裂。客户端在标准输出时检测到EOF，并将会话视为死亡。选项:

- 静默重启服务器并重新握手。对于纯只读服务器是OK的。
- 向用户显示故障。对于具有用户可见会话的有状态服务器是OK的。

第13.09阶段涵盖了Streamable HTTP重连接语义；studio更简单。

### Keepalive和会话id

Streamable HTTP使用studio没有会话id -进程标识就是会话。Keepalive ping是可选的；录音室管道在不活动的情况下不会破裂。

## 练习

1. 运行使用SIGTERM终止一个模拟的服务器进程，并观察客户端如何检测EOF并将该会话标记为死亡。

2. 实现命名空间前缀。当两个服务器公开时更新调度表，确认工具调用路由正确。

3. 为服务器重启添加连接池风格的回退：连续失败时的指数回退，上限为30秒，在三次失败后向用户发出通知。

4. 设计一个支持100个并发MCP服务器的客户端。用什么数据结构代替简单的分派字典？（提示：trie表示前缀命名空间，另加一个指标表示每台服务器的工具数量。）

5. 将客户端移植到官方的MCP Python SDK。SDK封装代码应该从200行缩减到40行，同时保留多服务器路由。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| MCP client | "The agent host" | Process that spawns servers and orchestrates tool calls |
| Session | "Per-server state" | Capabilities, tool list, and pending-request bookkeeping |
| Merged namespace | "One tool list" | Flat set of tool names across all active servers |
| Namespace collision | "Two servers same tool" | Client must prefix, reject, or first-come the duplicate |
| Routing | "Who gets this call?" | Dispatch from tool name to owning server |
| Background reader | "Non-blocking stdout" | Thread or task that drains server stdout into a queue |
| Sampling callback | "LLM-as-a-service" | Client handler for `sampling/createMessage` from server |
| `notifications/*_changed` | "Primitive mutated" | Signal the client must re-discover or re-read |
| Reconnection policy | "When server dies" | Restart semantics when transport fails |
| Stdio session | "Process = session" | No session id; child process lifetime is the session |
