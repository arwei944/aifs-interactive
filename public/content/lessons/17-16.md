# 将路由模型作为降低成本的原语

> 动态代理评估每个请求（任务类型、令牌长度、嵌入相似度、置信度），并将简单的查询发送到廉价模型，将复杂的查询升级到前沿模型。也称为模型级联。生产案例研究表明，在美国/英国/欧盟部署的相同质量下，成本降低了20-60%；在大容量的SaaS上，30%的路由效率提高将带来每年六位数的节省。2026年的背景是，LLM推理价格每年下降约10倍——从2022年底到2026年，gpt -4级代币从20美元/M降至0.40美元/M。大部分的下降是更好的服务栈（阶段17·04-09），而不是硬件。路由就是你如何在不回归产品的情况下将价格下降转化为利润。失败模式是廉价模型漂移：这条路线将40%的人推到较弱的模型上，推理任务的质量下降了3-5%，一个季度都没有人注意到。门路通过在线质量度量，而不仅仅是离线评估集。

**Type:** Learn
**Languages:** Python (stdlib, toy cascading router simulator)
**Prerequisites:** Phase 17 · 01 (Managed LLM Platforms), Phase 17 · 19 (AI Gateways)
**Time:** ~60 minutes

## 学习目标

- 解释模型级联：先进行低置信度检查，再进行低置信度检查。
- 列举四种路由信号（任务分类、提示长度、嵌入与已知硬集的相似性、首次通过的自信心）。
- 计算目标路由分割的期望混合成本和质量损失容忍度。
- 说出捕获廉价模型蠕变的漂移监测指标（在线质量门）。

## 这个问题

你的GPT-5服务每月花费8万美元。你的分析显示，70%的查询都很简单：“巴黎现在几点？”“改写这句话。”俳句级的模型只需3%的成本就能完美地处理这些问题。30%需要GPT-5的推理-编码，数学，多步骤计划。

如果你将70%分配给廉价，30%分配给昂贵，在同样的产品质量下，你的账单会下降65%。这是路由。诀窍是在不降低质量的情况下构建经纪人。

## 这个概念

### 四种路由信号

1. **任务分类**：简单/复杂/编码/数学/聊天。可以是基于规则的分类器，小型LLM (haiku类，0.25美元/M)，或者嵌入与标记桶的相似性。输出：route = cheap / balanced / frontier。

2. **提示长度**：提示>4K令牌通常需要边界一致性。<500个令牌的提示通常不会。

3. **嵌入已知硬集的相似度**：如果查询接近（余弦> 0.88）到已知硬桶，直接升级到边界。

4. **自信来自第一关**：送去廉价；如果模型的log-probs显示低置信度或拒绝或输出对冲语言，则在边界上重试。在约10%的流量上增加P95延迟，但在其他90%上节省50%以上。

### 三种模式

**预路由**（分类器前端）：增加~5-10ms延迟；最快的整体。

**级联**（廉价优先，在低置信度下升级）：~1.2倍中位延迟（廉价运行加验证），~2x升级。最优质的地板。

**集成路线**（运行廉价和前沿平行的样本，奖励模型选择）：最高的质量，最高的成本；仅用于关键A/B。

### 实现

AI网关（阶段17·19）公开路由。LiteLLM有门钥匙有守卫+路由。Kong AI Gateway有基于插件的路由。OpenRouter的模型市场公开了一个推荐API。

开源：RouteLLM (LMSYS), Not Diamond（商业），Prompt Mule。

### 2026年的价格曲线

| Model class | Late 2022 | 2026 | Change |
|-------------|-----------|------|--------|
| GPT-4-level quality | ~$20/M | ~$0.40/M | 50x cheaper |
| Frontier (GPT-5, Claude 4) | — | ~$3-10/M | new tier |

大部分的改进是服务效率——第17·04-09阶段的核心经验变成了供应商端的成本下降。路由可以让你在应用程序层获得这些收益，而不是等待所有用户迁移到廉价层。

### 漂移才是真正的风险

你的路线会给便宜的模式带来40%的收益。六个多月后，任务分配发生了变化（用户变得更老练，问的问题更长）。路由器没有注意到，因为它的分类器是在Q1数据上训练的。质量默默地下降。没有人抱怨得够大声。你在竞争对手的基准测试中发现你输了。

在线质量指标的登机口路线：

- 每个路由的用户大拇指向上/向下。
- 自动llm对每条路线的保留样本（5%）进行判断。
- 升级率：如果级联正在向上路由>30%，则廉价模式正在被过度路由。
- 每条路线的拒绝率。

### 你应该记住的数字

- 2026年在相同质量下节省路由：20-60%的案例研究。
- 2022-2026年LLM价格下降：每年累计约10倍。
- gpt -4级别2022 vs 2026: ~ 20美元/月→~ 0.40美元/月。
- 级联延迟影响：中值约1.2倍，升级约2x（约占流量的10%）。

## 练习

1. 运行梯级打预航路的精度是多少？
2. 你的用户基础是30%的企业用户（复杂查询），70%的免费用户（简单查询）。设计路由分割。在线度量标准是什么？
3. 一条线路的质量下降了2%，但节省了40%。那是船吗？取决于产品——两者都说。
4. 使用OpenAI / Anthropic api的logprobs实现信心检查。起始的阈值是多少？
5. 六个月后，升级率从8%上升到22%。诊断出三个原因，并找出解决方法。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Model routing | "cost broker" | Dynamic choice of model per request |
| Model cascade | "cheap-first escalate" | Run cheap, fall through to frontier on low confidence |
| Pre-route | "classify first" | Classifier up front; no re-run |
| Ensemble route | "parallel pick" | Run multiple, reward-model picks best |
| Escalation rate | "uprouted %" | Fraction of cascade requests that escalated |
| RouteLLM | "LMSYS router" | OSS router library |
| Not Diamond | "commercial router" | SaaS model-routing product |
| Drift | "cheap creep" | Distribution shift without router noticing |
| Online quality gate | "live check" | Automated LLM-judge sampling live traffic |
