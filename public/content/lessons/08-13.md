# 流量匹配和整流

> 扩散模型需要20-50个采样步骤，因为它们从噪声到数据走一条曲线路径。流量匹配（Lipman et al., 2023）和整流（Liu et al., 2022）训练了直线路径。更直的路径意味着更少的步骤意味着更快的推断。Stable Diffusion 3, Flux.1和AudioCraft 2都在2024年切换到流匹配。

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 8 · 06 (DDPM), Phase 1 · Calculus
**Time:** ~45 minutes

## 这个问题

DDPM的逆向过程是一个1000步的随机游走DDIM将其分解为20-50个确定步骤。你想要更少的步骤——最好是一个。阻碍因素是求解逆向过程的ODE是僵硬的；这条路是弯曲的。

如果你能训练模型，使从噪声到数据的路径是一条“直线”，从流匹配直接构建：从def 一个直线插值

整流（Liu 2022）更进一步：通过回流过程迭代地拉直路径，从而产生逐渐接近线性的ODE。经过两次回流迭代，两步采样器匹配50步DDPM质量。

## 这个概念


### 直线流

定义:

```
x_t = t · x_1 + (1 - t) · x_0,   t ∈ [0, 1]
```

在哪里沿着这条直线的时间导数是常数

```
dx_t / dt = x_1 - x_0
```

def 一个神经向量场

```
L = E_{x_0, x_1, t} || v_θ(x_t, t) - (x_1 - x_0) ||²
```

这是**条件流匹配**损失（Lipman 2023）。训练是无模拟的：您永远不会展开ODE。只是个例子

### 抽样

在推理时，对学习到的向量场*向后*进行时间积分：

```
x_{t-Δt} = x_t - Δt · v_θ(x_t, t)
```

### 整流（Liu 2022）

直线流可以工作，但学习到的路径“实际上不是直的”——它们是弯曲的，因为很多整流的回流步长：

1. 随机配对的列车流模型v_1。
2. 样本N对
3. 在成对的例子上训练v_2。因为这对现在是“ode匹配”的，它们之间的直线插值是真正平坦的。
4. 重复。

在实践中，2个回流迭代使您接近线性，支持2-4步推理。SDXL-Turbo、SD3-Turbo、LCM都是从流匹配模型中提炼出来的。

### 为什么它赢得了2024年的最佳图像奖

三个原因:

1. **无模拟训练** -在训练期间没有ODE展开，很容易实现。
2. **更好的损耗几何形状** -直线路径具有一致的信噪比，而DDPM ε-损耗在调度边缘具有较差的信噪比。
3. **更快的推理** - 4-8步在SDXL-Turbo质量；1步用稠度蒸馏。

## 流量匹配vs DDPM -确切的连接

与高斯条件路径匹配的流是具有特定噪声调度的扩散*。选择对于高斯路径，这两者在代数上是等价的。

流匹配增加了什么：目标的“清晰度”（普通速度），更清晰的损失，以及使用非高斯插值进行实验的许可。

```python
def sample(net, num_steps):
    x = rng.gauss(0, 1)
    for i in range(num_steps):
        t = 1.0 - i / num_steps
        dt = 1.0 / num_steps
        x -= dt * net_forward(x, t)
    return x
```

## 陷阱

- **时间参数化。**流量匹配使用DDPM使用相同的方向，不同的尺度。报纸经常在这方面出错。
- **计划选择。**整流的直线是“”流匹配时间表，但你可以使用余弦或对数正态t-抽样（SD3这样做）更好的规模覆盖。
- **回流成本。**为回流生成配对数据集是每个样本的完整推理通过。只有当你真的需要1-2步推理时才做回流。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Flow matching | "Straight-line diffusion" | Train `v_θ(x, t)` to match `x_1 - x_0` along an interpolant. |
| Rectified flow | "Reflow" | Iterative procedure that straightens learned flows. |
| Velocity field | "v_θ" | Output of the model — the direction to move `x_t`. |
| Straight-line interpolant | "The path" | `x_t = (1-t)·x_0 + t·x_1`; trivial target derivative. |
| Euler sampler | "1st order ODE solver" | Simplest integrator; works well when paths are straight. |
| Logit-normal t | "SD3 sampling" | Concentrate `t` sampling toward mid-values where gradients are strongest. |
| Consistency distillation | "1-step sampler" | Train a student to map any `x_t` directly to `x_0`. |
| CFG with velocity | "v-CFG" | `v_cfg = (1+w) v_cond - w v_uncond`; same trick, new variable. |
