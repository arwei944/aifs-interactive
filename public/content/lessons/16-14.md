# agent的共识和拜占庭容错

> 经典分布式系统BFT满足随机llm。2025-2026年出现了三个研究方向：**CP-WBFT** (arXiv:2511.10400)通过信任探针对每个投票进行加权；**DecentLLMs** (arXiv:2507.14928)在并行工人建议和几何中位数聚合下实现无领导；**WBFT** (arXiv:2505.05103)结合加权投票和分层结构聚类来分割核心和边缘节点。“AI代理能达成一致吗？”（arXiv:2603.01213）的问题是，即使是标量协议在今天也是脆弱的——一个欺诈性的代理可以破坏代理的混合物。BFT是必要的，但不是充分的。本课构建了一个最小的BFT协议，注入了三种特定于代理的攻击（拜占庭式谎言、奉承式顺从、相关错误单一文化），并测量了每个共识变体的应对方式。

## 问题

你有N个LLM代理，每个代理产生一个答案。他们不同意。多数投票选择了错误的一个，因为两个代理是相关的（相同的基本模型，相同的训练数据，相同的故障模式）。第三个主体碰巧以一种新颖的方式错了——所以多数是假多数。

现在再加上一种欺骗剂：它是故意撒谎的。或者是一个谄媚的代理人：它同意最后发言的人。在经典BFT中，假设拜占庭节点是一个分数2026年的现实是，LLM节点是随机的，即使是诚实的，跨模型相关的，并且受到彼此输出的影响。你不能把他们当作独立的伯努利选民。

经典的BFT （PBFT, 1999）并没有错——它是不完整的。它处理任意位翻转。它不处理“三个诚实的特工共享幻觉，因为他们共享训练数据。”本课程建立在PBFT的基础上，并在2025-2026年的三次改编上分层。

## 概念

### 多么经典的BFT给你

实用拜占庭容错（Castro & Liskov, OSDI 1999）容忍该协议有三个阶段（预准备、准备、提交）和两个原语（签名消息、仲裁证书）。就单一价值达成的协议

保证是强有力的，但假设：

1. * *独立的缺点。**拜占庭人不协调。
2. **诚实节点是真正诚实的。**诚实输出的正确性不是问题；协议只是调和分歧。
3. 这个问题有一个基本事实的答案。对错误事实的共识仍然是共识。

LLM代理违反了这三条。运行相同基本模型的两个代理共享错误。一个“诚实的”法学硕士仍然会产生幻觉。在模棱两可的问题上，“真相”是由代理人决定的——没有外部的神谕。

### 三种针对llm的攻击

**拜占庭谎言。**一个代理故意输出错误的答案。经典BFT处理这个问题

**谄媚的一致性。**一个代理在投票前阅读其他人的答案，并与最后发言的人保持一致。不是恶意的，但与最大声的声音有关。经典BFT不会阻止这种情况，因为代理会通过每个签名检查。

** Correlated-error单作。**三个代理共享一个基本模型。他们产生了同样的错误答案。大多数人错了。经典的BFT没有帮助，因为所有三个“诚实地”同意。

### 2025-2026年的回应

**CP-WBFT** (arXiv:2511.10400) -置信探测加权BFT。每个选民都给自己的答案加上一个信心探测器（一个自我报告的概率，或者一个单独的校准模型的预测）。投票权重与信心挂钩。在完全图上报告了+85.71%的BFT改进。缓解：阿谀奉承的顺从（顺从的代理人往往对他们自愿的职位缺乏信心）。

**DecentLLMs** (arXiv:2507.14928) - Leaderless。工人代理并行提出建议，评估代理评分建议，最终答案是得分位置的几何中位数。稳健时缓解：拜占庭谎言和相关误差（几何中位数对异常值具有鲁棒性，并且倾向于密集的集群，而不是模型偏差的平均值）。

**WBFT** (arXiv:2505.05103) -基于层次结构聚类的加权BFT。投票权重由回应质量加上从历史中获得的信任分数来分配。聚类代理分为核心代理和边缘代理；核心代理必须首先达成共识，边缘代理紧随其后。缓解：可扩展性（核心共识小而快）和部分单一文化（核心可以选择多样性）。

### 经验主义：“人工智能代理会同意吗？”(arXiv: 2603.01213)

本文测量了跨多个前沿模型的标量协议（LLM代理就单个数值达成一致）。这一发现令人不安：

- 即使没有对手，在许多基准测试中，LLM代理在标量问题上的分歧率也超过30%。
- 一个采用欺骗角色的单个代理可以将混合代理共识从诚实基线中拉出40多个百分点。
- 不一致率与模型多样性有关——异质集成比同质集成更不一致（好的：不相关的错误），但漂移也更慢（坏的：达成一致的时间更长）。

结论：BFT为您提供了对齐输出的机制，但它并没有告诉您对齐后的输出是否正确。结合验证（第16.08阶段角色专业化）、多样性（第16.15阶段辩论变体）和评估代理（第16.24阶段基准）。

### 核心协议，剥离

LLM代理的最小BFT轮：

```
1. task arrives; each agent i produces answer a_i
2. each agent attaches confidence probe c_i in [0, 1]
3. aggregator collects (a_i, c_i) from all n agents
4. aggregator groups by semantic cluster (equivalent answers)
5. aggregator computes weight for each cluster C:
     w(C) = sum_{i in C} c_i
6. winner = cluster with max weight, if max > threshold * sum(c_i)
   else: retry or escalate
7. minority clusters logged with provenance for post-hoc audit
```

语义聚类步骤是llm特有的变化。两个答案“研究报告4.2%”和“4.2%改善”是同一组。简单的字符串相等检查会忽略这一点。在生产中，使用便宜的嵌入模型或显式规范化。

### 阈值调整

The太低：你接受微弱的多数。太高了，你什么都不接受。经验范围：0.5-0.67低于阈值，升级到人类或不同的代理集合。

### 在共识不起作用的地方

- * *模棱两可的问题。如果问题没有根据，共识就是一种意见。就这么说吧。
- * *复合问题。“编写代码并解释它”——两个答案。各自独立投票。
- * *对抗multi-round。**如果智能体可以观察前几轮并模仿（杜2023辩论），他们开始同意彼此不管真相。绑定回合（通常为2-3回合）。

## 船这

在发布任何共识机制之前：

- **至少使用上述三种模式进行攻击测试。您的协议应该可预见地失败，而不是无声地失败。
- **记录每个少数派集群**的来源。少数集群是相关错误的早期预警系统。
- **强制有界回合。**不要说“继续辩论直到达成协议”——那只会奖励阿谀奉承。
- **将协议与正确性分开。**共识输出给验证者；验证器独立于集成。
- **监控协议率。**大幅上涨意味着从众倾向；急剧下降意味着模型漂移。

## 练习

1. 运行当单一文化置信度低于0.7时，CPWBFT部分缓解了单一文化攻击。
2. 添加第四种攻击模式：**沉默弃权** -一个代理拒绝回答（“我不知道”）。每个聚合器应该如何对待弃权？执行你的选择。
3. 将语义聚类从字符串规范化转换为嵌入相似性（使用任何开源嵌入模型）。谄媚攻击会发生什么？
4. 读取CP-WBFT （arXiv:2511.10400）。实现置信度探针校准步骤（一个单独的校准模型检查每个代理的自我报告置信度）。测量单一栽培场景下的精度增益。
5. 阅读“人工智能代理能达成一致吗？”(arXiv: 2603.01213)。重现一个简化的标量协议实验：三个代理人，一个标量问题，欺骗角色提示。CPWBFT或DecentLLMs能抓住它吗？

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| BFT | "Byzantine fault tolerance" | Castro-Liskov 1999 protocol for consensus with `f < n/3` arbitrary faults. |
| Byzantine | "Any bad behavior" | A node that can lie, drop messages, fail silently — anything but crash safely. |
| Confidence probe | "How sure are you?" | Self-reported or calibrator-predicted probability attached to a vote. |
| Semantic clustering | "Same answer, different words" | Grouping equivalent answers before counting votes. |
| Geometric median | "Robust center" | The point minimizing sum of distances to sample points. Robust to outliers, unlike the mean. |
| Monoculture | "Same model, same failures" | Correlated errors when agents share training data or base model. |
| Sycophantic conformity | "Agreeing with the loud voice" | An agent's vote biases toward whoever spoke first/loudest. |
| Core/Edge | "Hierarchical BFT" | WBFT split: small Core consensus first, Edge nodes follow. Bounds latency. |
