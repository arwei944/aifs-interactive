# The consensus of Agents and Byzantine fault tolerance

> The classic distributed system BFT satisfies random llm. Three research directions emerged in 2025-2026: **CP-WBFT** (arXiv:2511.10400) weighting each vote through trust probes; **DecentLLMs** (arXiv:2507.14928) achieves leaderless performance under parallel worker suggestions and geometric median aggregation; **WBFT** (arXiv:2505.05103) combines weighted voting and hierarchical structure clustering to segment core and edge nodes. Can AI agents reach an agreement? The problem with (arXiv:2603.01213) is that even scalar protocols are vulnerable today - a fraudulent proxy can disrupt the mixture of proxies. BFT is necessary, but not sufficient. This lesson constructed a minimal BFT protocol, injected three agent-specific attacks (Byzantine lies, flattering compliance, and related erroneous monoculture), and measured the responses of each consensus variant.

## "Problem"

You have N LLM agents, and each agent generates an answer. They didn't agree. The majority vote chose the wrong one because the two agents are related (the same basic model, the same training data, and the same failure mode). The third subject happened to be wrong in a novel way - so the majority is a false majority.

Now add another deceptive agent: it is a deliberate lie. Or it could be a sycophantic agent: one who agrees with the last speaker. In a classic BFT, it is assumed that a Byzantine node is a fraction. The reality in 2026 is that LLM nodes are random, even if they are honest, cross-model correlated, and affected by each other's outputs. You can't treat them as independent Bernoulli voters.

The classic BFT (PBFT, 1999) is not wrong - it is incomplete. It handles arbitrary bit flipping. It does not deal with "three honest agents sharing illusions because they share training data." This course is built on the foundation of PBFT and is stratified in three adaptations from 2025 to 2026.

## Concept

### What a classic BFT for you

Practical Byzantine fault tolerance (Castro & Liskov, OSDI 1999) tolerates that the agreement has three stages (pre-preparation, preparation, submission) and two primitives (signed message, arbitration certificate). An agreement reached on a single value

The guarantee is strong, but assume:

1. The disadvantages of independence. The Byzantines were not harmonious.
2. Honest nodes are truly honest. The correctness of honest output is not an issue; The agreement merely reconciles differences.
3. There is a basic factual answer to this question. The consensus on the erroneous facts remains a consensus.

The LLM agent violated these three points. Two agents running the same basic model share errors. An "honest" master of laws can still have hallucinations. On ambiguous issues, the "truth" is determined by the agent - there is no external oracle.

### Three types of attacks targeting LLMS

*Byzantine lies. An agent deliberately output an incorrect answer. Classic BFT handles this issue

*The consistency of flattery. An agent reads the answers of others before voting and aligns with the last speaker. It's not malicious, but it's related to the loudest sound. Classic BFT will not prevent this situation because the agent will check each signature.

** Correlated-error solo. Three agents share a basic model. They produced the same wrong answer. Most people are wrong. The classic BFT is of no help because all three "honestly" agree.

### The response for 2025-2026

**CP-WBFT** (arXiv:2511.10400) - Confidence Detection Weighted BFT. Each voter adds a confidence detector (either a self-reported probability or a prediction from a separate calibration model) to their answer. The voting weight is linked to confidence. A BFT improvement of +85.71% was reported on the full graph. Relief: Sycophant compliance (Compliant agents often lack confidence in the positions they voluntarily take).

**DecentLLMs** (arXiv:2507.14928) - Leaderless The worker agent makes suggestions in parallel, evaluates the agent's scoring suggestions, and the final answer is the geometric median of the score position. Steady-time mitigation: Byzantine lies and correlation errors (the geometric median is robust to outliers and tends to cluster densely rather than the average of model biases).

**WBFT** (arXiv:2505.05103) - Weighted BFT Based on Hierarchical clustering. The voting weight is allocated by the quality of the response plus the trust score gained from history. Clustering agents are divided into core agents and edge agents. The core agent must first reach a consensus, followed closely by the edge agent. Mitigation: Scalability (small and fast core consensus) and partial monoculture (core can choose diversity).

### Empiricism: "Will AI agents agree?" (arXiv: 2603.01213)

This paper measures scalar protocols across multiple frontier models (where LLM agents reach an agreement on a single value). This discovery is disturbing:

- Even without rivals, in many benchmark tests, the divergence rate of LLM agents on scalar issues exceeds 30%.
- A single agent that adopts a deceptive role can pull the hybrid agent consensus out of the honesty baseline by more than 40 percentage points.
- The inconsistency rate is related to model diversity - heterogeneous ensembles are more inconsistent than homogeneous ensembles (good: irrelevant errors), but drift is also slower (bad: It takes longer to reach consensus).

Conclusion: BFT provides you with a mechanism to align the output, but it does not tell you whether the aligned output is correct. Combine verification (Stage 16.08 role specialization), diversity (Stage 16.15 debate variant), and evaluation of agents (Stage 16.24 benchmarks).

### Core protocol, stripping

The minimum BFT round represented by LLM:

```
1. task arrives; each agent i produces answer a_i
2. each agent attaches confidence probe c_i in [0, 1]
3. aggregator collects (a_i, c_i) from all n agents
4. aggregator groups by semantic cluster (equivalent answers)
5. aggregator computes weight for each cluster C:
     w(C) = sum_{i in C} c_i
6. winner = cluster with max weight, if max > threshold * sum(c_i)
   else: retry or escalate
7. minority clusters logged with provenance for post-hoc audit
```

The semantic clustering step is a unique variation of llm. The two answers, "Research report 4.2%" and "4.2% improvement", belong to the same group. A simple string equality check will ignore this. In production, use inexpensive embedded models or explicit normalization.

### Threshold adjustment

The is too low: You accept a weak majority. It's too high. You won't accept anything. Experience range: 0.5-0.67 Below the threshold, upgrade to human or different agent sets.

### Where consensus doesn't work

- Ambiguous questions. If a problem has no basis, consensus is just an opinion. Just put it this way.
- A compound problem. "Write code and interpret it" - two answers. Each person votes independently.
- "Fight against multi-round. If the agents can observe the previous rounds and imitate (Du 2023 debate), they start to agree with each other that they don't care about the truth. Binding rounds (usually 2-3 rounds).

## This ship

Before releasing any consensus mechanism:

- At least use the above three modes for attack testing. Your agreement should fail predictably rather than silently.
- Record the source of each minority cluster. A few clusters are early warning systems for related errors.
- Forced bounded turns. Don't say "Keep debating until an agreement is reached" - that will only reward flattery.
- Separate the protocol from correctness. The consensus is output to the validator; The validator is independent of the integration.
- Monitor the protocol rate. A significant increase indicates a tendency to follow the crowd. A sharp decline means model drift.

## Key terms

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| BFT | "Byzantine fault tolerance" | Castro-Liskov 1999 protocol for consensus with `f < n/3` arbitrary faults. |
| Byzantine | "Any bad behavior" | A node that can lie, drop messages, fail silently — anything but crash safely. |
| Confidence probe | "How sure are you?" | Self-reported or calibrator-predicted probability attached to a vote. |
| Semantic clustering | "Same answer, different words" | Grouping equivalent answers before counting votes. |
| Geometric median | "Robust center" | The point minimizing sum of distances to sample points. Robust to outliers, unlike the mean. |
| Monoculture | "Same model, same failures" | Correlated errors when agents share training data or base model. |
| Sycophantic conformity | "Agreeing with the loud voice" | An agent's vote biases toward whoever spoke first/loudest. |
| Core/Edge | "Hierarchical BFT" | WBFT split: small Core consensus first, Edge nodes follow. Bounds latency. |
