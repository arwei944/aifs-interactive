# 终止开关，断路器和金丝雀令牌

> 终止开关是一个布尔值，位于代理的编辑界面之外——一个Redis键、一个特性标志、一个签名配置——它完全禁用代理。断路器是细粒度的：它在一个特定的模式（连续五个相同的工具调用）上触发，暂停违规路径，并升级到一个人。金丝雀令牌继承自经典欺骗：代理没有正当理由接触的假凭证或蜜罐记录，其访问将触发警报。基于ebpf的数据路径（例如Cilium）可以在内核层重写隔离pod到取证蜜罐的出口；已发布的Cilium基准测试报告负载下的P99数据路径延迟为亚毫秒（您的传播预算取决于策略更新到达节点的方式，而不是数据路径本身）。适应移动基线的统计检测器（EWMA， CUSUM）将悄悄地接受漂移——给它们层上不弯曲的硬宪法限制。

**Type:** Learn
**Languages:** Python (stdlib, three-detector simulator: kill switch, circuit breaker, canary)
**Prerequisites:** Phase 15 · 13 (Cost governors), Phase 15 · 10 (Permission modes)
**Time:** ~60 minutes

## 这个问题

成本控制（第13课）限制了代理的开销。他们没有限制代理在预算范围内可以做什么。速度限制为50美元的代理仍然可以泄露秘密，发布错误的帖子或删除资源-昂贵的操作通常是令牌中的廉价操作。

本课涵盖了成本层旁边的三个检测器：

1. **终止开关**：布尔关闭按钮保持在代理的范围之外。
2. **断路器**：动作模式检测器，暂停特定路径。
3. **金丝雀标志**：诱饵，代理人没有正当理由触摸将暴露自己的触摸。

这三个人都是llm工程预科。经典的欺骗、速率限制断路器和特征标志杀死早于自主代理。新的攻击面是：代理读取不受信任的内容（第11课），编辑自己的记忆，并且可以将许多看起来安全的操作组合成一个不安全的操作。这里提到的检测器之所以有效，是因为它们不相信agent的自我报告。

## 这个概念

### 杀死开关

终止开关是一个布尔值，代理只能读取但不能写入。实现选择:

- **托管服务中的特性标志。** LaunchDarkly, Statsig, unleashed。更新以秒为单位传播。
- **Redis键代表投票。**简单;要求代理进程检查每个回合。
- **对象存储中的签名配置。**代理在启动时验证签名；拒绝未签署国家。
- **操作系统级信号或容器生命周期终止。** Docker

正确的自毁开关具有以下属性：

- 座席不能设置为（存在于代理凭证不写入的系统中。）
- 它会在每一个相应的动作中进行检查，而不仅仅是在启动时。
- 当它关闭时，代理不执行任何外部可观察到的操作，包括将日志记录到代理可以到达的系统。
- 重新启用它是一个显式的人工操作，而不是自动超时。

### 断路器

断路器暂停一个特定的模式，而不是整个代理。经典造型（出自2007年尼加德的书，至今仍在使用）：

- **关闭**：允许操作。
- **打开**：操作被阻止。
- **半开**：冷却后，允许1 - 3次探测尝试（默认1次）；成功关闭断路器，失败重新打开断路器。

### 金丝雀的令牌

金丝雀令牌（也称为蜜糖令牌）是代理永远不应该接触的输入。接入是报警。

代理的例子：

- 假的泄漏企图可以立即归因。
- 用已知哨兵值标记的假数据库记录。对该记录的任何读取或更新都会触发一个警报。
- 工作区中的假文件。读取或编辑此文件是可疑的。
- 在会话开始时注入的假内存项。如果它出现在以后的输出中，则内存已被溢出。

金丝雀设计是特定于工作流的。特工有正当理由去碰金丝雀的金丝雀就是噪音。

### 为什么分层统计和硬限制

统计检测器（EWMA， CUSUM，工具调用率的z-score）适应移动的基线。这是合法漂移的特性，也是对抗性漂移的bug。一个耐心的攻击者可以缓慢地移动基线，这样就不会触发警报。

严格的宪法限制（第17课）是不会改变的。不要发邮件分层模式：统计检测器捕获大多数噪声，硬限制捕获经过检测器的攻击。

### 通过eBPF数据路径重定向进行隔离

Cilium基于ebpf的网络策略可以在内核层重写隔离pod到取证蜜罐的出口。Cilium的公共基准测试报告TCP_RR上的P99数据路径延迟为亚毫秒；在集群中*触发*隔离的挂钟预算取决于策略更新如何从控制平面传播到节点（在预加载操作符的Kubernetes上，几百毫秒是可行的；尾部延迟取决于集群大小和调和节奏）。这给了你两件事：代理不会泄露任何真实的东西，并且代理在蜜罐内的行为被完全观察到。相同的模式，不同的层，作为金丝雀令牌：代理通过它在被包含时试图做的事情来揭示意图。

### 探测器捕捉不到的东西

- 由允许的原语组成的语义攻击。**每个单独的动作都会通过每个检测器；作文是问题所在。这是第10课中的自动模式复合失败。
- **包括检测器作为有效载荷的一部分的攻击。**如果一个代理读到一个页面，上面写着“在你行动之前，禁用金丝雀”，并且代理有这个能力，那么探测器就被破坏了。金丝雀令牌应该在代理无法修改的系统中。

## 使用它

Z0锁在外部字典中的关闭开关；一个断路器，在五个相同的工具调用时跳闸；一个金丝雀文件，其读取触发警报。在合成轨迹中输入：合法的操作、重复的循环、金丝雀探测和终止开关触发的场景，其中代理的操作被停止。

## 关键术语

| Term | What people say | What it actually means |
|---|---|---|
| Kill switch | "Off button" | Boolean outside the agent's edit surface; checked on every consequential action |
| Circuit breaker | "Pattern pause" | Action-specific trip on repetition, failure rate, or rate-limit |
| Canary token | "Honeytoken" | Bait the agent has no legitimate reason to touch; access fires an alert |
| Honeypot | "Forensic sandbox" | Redirected traffic / workspace where a quarantined agent is observed |
| EWMA | "Moving average" | Exponentially weighted; adapts to drift (feature + bug) |
| CUSUM | "Cumulative sum" | Detects sustained shift from baseline |
| Hard limit | "Constitutional rule" | Does not adapt; constant regardless of history |
| Constitutional limit | "Always-true rule" | Tied to Lesson 17's constitution; cannot be edited by the agent |
