# 思想树和LATS：深思熟虑的搜索

> 单一的思维链轨迹没有回头路。ToT （Yao et al., 2023）将推理转化为一棵在每个节点上都有自我评价的树。LATS （Zhou et ., 2024）在蒙特卡罗树搜索下将ToT与ReAct和reflection结合起来。Game of 24从4% （CoT）上升到74% (ToT)；LATS在HumanEval上的点击率为92.7% pass@1。

**Type:** Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 14 · 01 (Agent Loop), Phase 14 · 03 (Reflexion)
**Time:** ~75 minutes

## 学习目标

- 框架推理作为搜索：节点是“想法”，边缘是“扩展”，价值是“多么有希望”。
- 实现一个带有自评价评分的标准库tot风格的BFS树搜索。
- 通过选择/扩展/模拟/反向传播扩展到一个玩具LATS MCTS环路。
- 决定什么时候搜索值得令牌乘数（24的游戏，代码生成），什么时候单一的轨迹就足够了（简单的问答）。

## 这个问题

思维链是一种线性行走。如果第一步是错误的，那么接下来的每一步都是在一个错误的前提下进行的。在Game of 24（用4个数字+−× ÷表示24）中，GPT-4 CoT的准确率为4%。该模型较早地选择了错误的子表达式，并且无法恢复。

推理需要的是提出多个候选人，评估他们，选择有希望的，当死胡同出现时，退回的能力。这就是搜索。思想树和LATS是两个典型的表述。

## 这个概念

### 思想树（Yao et al., NeurIPS 2023）

每个节点都是一个连贯的中间步骤（“一个想法”）。每个节点可以扩展到K个子思想。LLM使用评分提示对每个节点进行自我评估。搜索搜索树——BFS、DFS或beam。

```
                     (root: "find 24 from 4 6 4 1")
                    /               |            \
           ("6 - 4 = 2")    ("4 + 1 = 5")    ("4 * 6 = 24")  <- Score: HIGH
              /   \              |                  |
          ...    ...          ...                finish
```

自我评价是承重件。论文展示了三种变体：在24场比赛中，他们三人都击败了科比（4% -> - GPT-4的74%）。

### LATS （Zhou等人，ICML 2024）

LATS在MCTS下统一了ToT、ReAct和reflection。LLM有三个作用：

- **策略**：建议候选人下一步行动（反应式）。
- **值函数**：对部分轨迹进行评分（tot风格的自我评估）。
- **自我反射器**：在失败时，写一个自然语言反射（反射风格），并使用它来重新播种未来的推出。

环境反馈（观察）混合到价值函数中，因此搜索是由真实的工具结果通知的，而不仅仅是模型的意见。论文时的结果：使用GPT-4 （SOTA）时，HumanEval pass@1平均得分为92.7%，使用GPT-3.5（接近基于梯度的微调）时，WebShop平均得分为75.9。

### 未经中华人民共和国交通部,最低限度

每个迭代有四个阶段：

1. **选择** -使用UCT（树的上置信度界限）从根到叶。
2. **扩展** -通过策略生成K个子节点。
3. **模拟** -从一个使用策略的孩子开始滚动，用价值函数（或环境奖励）对叶子进行评分。
4. **反向传播** -更新访问计数和价值估计的路径。

UCT公式：第一个术语是剥削；第二是探索。曲调

### 成本现实

搜索令牌爆炸。24小时游戏中的ToT使用100 - 1000倍的ToT代币。LATS也是类似的。这不是免费的；预约搜索：

- 单一轨迹明显不够的任务（游戏邦注：24人游戏，复杂代码）。
- 在这些任务中，时钟比正确性更重要。
- 具有廉价、可靠的值函数的任务（代码的单元测试，数学的明确目标）。

如果你的任务只有一个正确答案和一个嘈杂的评价者，搜索通常会让事情变得更糟——它会找到一个“得分不错”的错误答案。

### 2026年定位

大多数生产代理不运行LATS。他们使用基于工具的验证来运行ReAct （CRITIC，第05课）。搜索显示在专业领域：

- 将运行测试的代理编码为值函数（humaneval风格）。
- 探索多个查询路径的深度研究代理。
- 在LangGraph子图中规划繁重的工作流。

AlphaEvolve（第11课）是2025年的极限：对代码的进化搜索，机器可检查的适应度，边界增益（56年来首次4x4人工智能改进）。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Tree of Thoughts | "Branching CoT" | Yao et al. — tree of thought nodes with self-evaluation |
| LATS | "MCTS for LLMs" | Zhou et al. — unifies ToT + ReAct + Reflexion under MCTS |
| UCT | "Upper confidence bound" | Select formula balancing exploitation (Q) and exploration (ln N / n) |
| Value function | "How good is this state" | Prompted LLM score or environment reward; feeds backprop |
| Policy | "Action proposer" | ReAct-style generator; emits candidate next thoughts/actions |
| Rollout | "Simulated trajectory" | Walk from a node to a leaf using policy, score with value |
| Backpropagate | "Update ancestors" | Push the leaf's reward up the path, updating visit counts and Q |
| Search cost | "Token explosion" | 100-1000x CoT on Game of 24; budget before you adopt |
