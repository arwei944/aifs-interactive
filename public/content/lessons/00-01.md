# 开发环境

> 你的工具塑造了你的思维。布置一次，布置好。

**Type:** Build
**Languages:** Python, Node.js, Rust
**Prerequisites:** None
**Time:** ~45 minutes

## 学习目标

- 从头开始设置Python 3.11+、Node.js 20+和Rust工具链
- 为可再现的构建配置虚拟环境和包管理器
- 用CUDA/MPS验证GPU访问并运行测试张量操作
- 理解四层栈：系统、包、运行时、AI库

## 这个问题

你将使用Python、TypeScript、Rust和Julia学习200多节人工智能工程课程。如果您的环境被破坏了，那么每一个教训都变成了与工具的斗争，而不是学习。

大多数人跳过环境设置。然后他们花费数小时调试导入错误、版本冲突和缺少CUDA驱动程序。我们要好好做一次。

## Build It

### Step 1: System Foundation

Check your system and install the basics.

```bash
# macOS
xcode-select --install
brew install git curl wget

# Ubuntu/Debian
sudo apt update && sudo apt install -y build-essential git curl wget

# Windows (use WSL2)
wsl --install -d Ubuntu-24.04
```
