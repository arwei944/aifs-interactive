# 变色龙和早期融合仅标记的多模态模型

> 到目前为止，我们看到的每个VLM都将图像和文本分开。视觉符号来自视觉编码器，流入投影仪，然后在LLM内遇到文本。视觉词汇和文本词汇从不重叠。变色龙（Meta， 2024年5月）问：如果他们这样做了呢？训练一个VQ-VAE，将图像转换为来自共享词汇表的离散符号序列。每个多模态文档现在都是一个序列-文本标记和图像标记交错，单个自回归损失。副作用：该模型可以生成混合模态输出-在单个推理调用中交替使用文本和图像标记。本课阅读早期融合论文，并建立一个玩具版本端到端。

**Type:** Build
**Languages:** Python (stdlib, VQ-VAE tokenizer + interleaved decoder)
**Prerequisites:** Phase 12 · 05, Phase 8 (Generative AI)
**Time:** ~180 minutes

## 学习目标

- 解释为什么共享词汇表+单个损失会改变模型的功能。
- 描述VQ-VAE如何将图像标记为与Transformer的下一个标记目标兼容的离散序列。
- 命名变色龙的训练稳定性技巧：QK-Norm， dropout placement， LayerNorm排序。
- 比较变色龙和BLIP-2的Q-Former方法，并描述每种方法何时是正确的选择。

## 这个问题

基于适配器的vlm （LLaVA、BLIP-2、Qwen-VL）将文本和图像视为两种不同的东西。文本令牌通过图像穿过模型有两条输入路径，它们在中间合并。

三种后果:

1. LLM只能使用图像，而不能发出图像。输出仅为文本。
2. 混合模态文档（交替的段落和图像，就像在文章中一样）很尴尬—您要么解析模型之外的多模态输入，要么解析链生成。
3. 分配不匹配。视觉标记和文本标记位于隐藏空间的不同区域，造成了微妙的对齐问题。

变色龙拒绝了这个前提：图像只是来自共享词汇表的离散符号序列。在交错文档上训练模型，一个损失，一个自回归解码器，你就可以免费解锁混合模态生成。

## 这个概念

### VQ-VAE作为图像标记器

该标记器是一个矢量量化变分自编码器。体系结构:

- 编码器：CNN + ViT，将图像映射到空间特征映射，例如暗256的32x32特征。
- 码本：一个学习词汇K向量（变色龙使用8192），也dim 256。
- 量化：对于每个空间特征，根据L2距离查找最近的码本条目。用整数索引替换连续特征。
- 解码器：CNN，将量化特征还原为像素。

培训：VAE重构损失+承诺损失+码本损失。码本索引形成图像的离散字母表。

对于变色龙：从8192个词汇表中提取的一个图像变成32*32 = 1024个符号。与文本标记（来自LLM的BPE词汇表，例如32000）连接。最终词汇：40192。Transformer看到一个序列，一个损耗。

### 共享词汇表

变色龙的词汇表结合了文本标记、图像标记和情态分隔符。每个令牌都有一个ID。输入嵌入层将每个ID映射到一个D-dim隐藏向量。输出投影映射隐藏回词汇表。Softmax选择下一个令牌，不管它的模态是什么。

### Mixed-modality代

推理是共享词汇表中的下一个令牌预测。示例提示：“画一只猫并描述它。”变色龙发出:

```
<image> 4821 1029 2891 ... (1024 image tokens) </image>
The cat is orange, sitting on a windowsill...
```

模型自动选择顺序——它可以生成图像然后文本，文本然后图像，或者交错。同样的解码器，同样的损失。

与仅生成文本的适配器vlm相比。变色龙重新打开了模型输出模态的问题。

### 训练稳定性- QK-Norm， dropout， LayerNorm排序

早期融合训练在规模上不稳定。变色龙的纸记录了三种技巧：

- QK-Norm。将LayerNorm应用到查询和关键投影中，注意点积之前。防止在深度处发生logit级爆炸。用于多个2024年后的大型模型。
- 辍学的位置。在每次残差添加之后，而不仅仅是在注意和MLP之后。当图像标记的梯度占主导地位时，需要更多的正则化。
- LayerNorm排序。剩余分支（标准）上的预LN，加上最后一个块的跳过连接上的额外LN。稳定末层梯度流动。

没有这些技巧，34B-param变色龙训练在多个检查点偏离。有了它们，它就收敛了。培训配方的贡献与体系结构一样大。

### 标记器的重建天花板

VQ-VAE是有损的。在每个512x512图像8192个码本条目和1024个令牌时，重建PSNR上限约为26-28 dB。对于可识别的图像生成，这已经足够了，但明显比连续空间扩散差（稳定扩散3达到32+ dB）。

标记器是瓶颈。更好的标记器（magvitv -v2， IBQ, SBER-MoVQGAN）提升了上限。Emu3（第12.12课）仅通过更好的标记器实现sdxml质量的生成。

### 变色龙vs BLIP-2 / LLaVA

变色龙（早期融合，共享词汇）：
- 一个损失，一个解码器。
- 生成混合模态输出。
- Tokenizer是质量上限。
- 昂贵：VQ-VAE解码器每个生成的图像在推理路径上。

BLIP-2 / LLaVA（后期融合，独立塔）：
- 视觉输入，文字输出。
- 重用预训练的LLM。
- 没有标记器的理解瓶颈。
- 便宜：单向前传球。

按任务挑选。如果需要图像生成，变色龙家族。如果您只需要理解，适配器- vlm更简单，并且重用更多的预训练计算。

### Fuyu和AnyGPT

Fuyu （Adept, 2023）是一种相关的方法：完全跳过单独的视觉编码器，通过LLM的输入投影提供原始图像补丁，就好像它们是令牌一样，没有令牌器。比变色龙简单，失去了共享词汇输出的生成。

AnyGPT （Zhan et al., 2024）将变色龙扩展到四种模式：文本、图像、语音、音乐。相同的VQ-VAE技巧用于每个共享Transformer。任意对任意的一代。第12.16课详细介绍。

## 使用它


- 一个微小的vq - vee风格量化器，将8x8补丁映射到码本索引（K=16）。
- 共享词汇表（文本id 0..）31) +(图像id 32..47) +（分隔符48,49）。
- 一个玩具自回归解码器（双元表）在合成字幕+图像标记序列上训练。
- 给出提示时发出交替的文本+图像标记的采样循环。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Early fusion | "Unified tokens" | Images converted to discrete tokens sharing the transformer's vocabulary from step one |
| VQ-VAE | "Image tokenizer" | CNN + ViT + codebook that maps images to integer indices the transformer can predict |
| Shared vocabulary | "One dictionary" | A single token ID space covering text + image + modality separators |
| QK-Norm | "Attention stabilizer" | LayerNorm applied to query and key before their dot product, prevents norm blowup |
| Mixed-modality generation | "Text + image output" | Inference that autonomously produces interleaved text and image tokens in one pass |
| Codebook size | "K entries" | Number of discrete vectors the VQ-VAE can quantize to; trades compression for fidelity |
| Tokenizer ceiling | "Reconstruction limit" | Best PSNR achievable by decoding VQ tokens; bounds the model's image quality |
