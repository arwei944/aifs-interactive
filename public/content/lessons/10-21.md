# Jamba - Hybrid ssm - Transformer

> The state space model (ssm) and the converter require different things. Transformers purchase quality at a secondary cost through attention. ssm purchases linear time inference and constant memory through recursive but lagging quality. AI21's Jamba (March 2024) and Jamba 1.5 (August 2024) place them in the same model: every 7 Mamba layers correspond to 1 Transformer layer, each block corresponds to a MoE layer, and a 256k context window fits a single 80GB GPU. Mamba-3 (ICLR 2026) tightens the SSM side through complex-valued state space and MIMO projection. This lesson will provide a comprehensive reading of these two architectures and explain why the hybrid formula can survive for three years even when long context attempts of pure ssm and pure transformer fail.

## This question

Attention is quadratic in sequence length. The state space model is linear. This difference is complex: in the case of 256k tokens, the attention map of the Transformer is 65B entries per person; Regardless of the sequence length, the loop state of SSM is of a fixed size.

Pure ssm models (Mamba, MAMBA-2) struggle to match Transformer confusion at a small scale, but lag behind in state tracking tasks and fail in context retrieval for certain categories. Intuition: ssm compresses history into a fixed state. When the history is very long, information will be leaked. Attention accurately remembers everything, but at a secondary price.

The obvious solution is: use both. Place the Transformer layer where precise recall is required. Use the SSM layer elsewhere. Adjust the proportion. Jamba is the first production-level model to release this hybrid formula on a large scale (with a total of 52B, 12B activities, 256k contexts, and a single 80GB GPU). Jamba 1.5 expands the family to a total of 398B / 94B activities. Mamba-3 (ICLR 2026) is currently the best pure ssm benchmark, and hybrid vehicles can be rebuilt on this basis.

This lesson will read all three papers and generate a mental model of "choosing the correct proportion".

## This concept

### One SSM is on one page

The state space model processes sequences

```
h_t = A h_{t-1} + B x_t
y_t = C h_t
```

At each step, the state evolves through linear dynamics Note the key attribute: Computational memory remains unchanged. The inference for each token is 0(1).

The structure is the key to modeling quality. S4 (Gu 2021) uses highly structured matrices, which can effectively evaluate long volume volumes during training. Mamba (Gu, Dao 2023) further simplifies the structure by replacing the fixed MamBA-2 (2024). Mamba-3 (2026) has re-added complexity in specific areas.

Key feature: For the decoder LLM, the SSM layer is a direct alternative to the attention layer, featuring a fixed-size state per layer rather than an ever-growing KV cache.

### Jamba Block

The Jamba block is based on an interlaced layer of two numbers:

- Z0Jamba is used
- Z0Jamba is used

The sequence of layers within the block

```
M  M  M  M  M  M  M  A    (7 Mamba + 1 Attention)
|  M  |  M  |  M  |  M    (where | marks MoE applied)
```

Each Jamba block has 8 layers. At 4 depths (a total of 32 layers), you obtain 28 mambas and 4 attention layers. Among them, 16 use MoE.

### Why is it a 1:7 ratio

In long context assessment, the ratio of attention to Mamba provides the best per-parameter confusion and context recall?

- Excessive focus (1:1) : Quality improves, but memory and speed decline.
- Attention deficit (1:15) : Good memory, but failed context retrieval.
- The best points are 1:7 or 1:8.

Intuitive perception: The Transformer layer handles precise recall and state tracking. The Mamba layer handles most of the cheap processing.

### Location encoding

The Mamba layer itself is position-aware (through recursion). The attention layer in the initial Mamba-based mixture did not use the rope-SSM layer to provide position information. Jamba 1.5 adds RoPE to the attention layer for long context generalization, which is a post hoc improvement based on empirical long context evaluation.

### Mamba-3: Pure ssm baseline in 2026

Mamba-3 (ICLR 2026, arXiv:2603.15569) introduced three innovations in pure ssm:

1. Exponential-trapezoidal discretization. The discretization of the Euler method in Mamba-2 has been replaced with more expressive recursion. Operations similar to convolution are applied to the state input within the core recursion rather than as external convolution

2. Complex-valued status update. The previous Mamba simplified the state matrix from a complex matrix (S4) to a real diagonal matrix (Mamba) and then to a scaled identity matrix (Mamba-2). Mamba-3 re-added complex values - equivalent to performing data-dependent rotation embeddings on the state. This restores the state tracking functionality consumed in the previous real-value simplification.

3. Multiple-input multiple-output (MIMO) projection. Instead of scalar projections for each feature, use matrix value projections. Improve the modeling ability and the hardware utilization rate of inference time without increasing the decoding delay.

Under the 1.5B parameter, the average downstream accuracy of Mamba-3 is 0.6 points higher than that of the gated DeltaNet. The number of MIMO variants increased by 1.2, with a total gain of 1.8 points. Under the same state size, Mamba-3 matches half of Mamba-2.

The Mamba-3 has not yet been mass-produced as a hybrid, but it is clearly a candidate for the SSM aspect of the next Jamba-class model.

### When should I switch to a hybrid vehicle

Mixed-race individuals win in the following circumstances:

- The context is long enough for the pure transformer KV cache to become painful (64k+).
- The task combines short-term structure (suitable for SSM) and long-term recall (requiring Transformer).
- You want to deploy on a single gpu memory budget, but the Transformer KV cache alone is not suitable.

Mixed-race individuals will fail in the following situations:

- The context is very short (less than 16k). The SSM overhead has been wasted. A pure transformer will do.
- The task requires ubiquitous attention (deep reasoning, multi-document cross-reference). In hybrid games, the sparsity of the attention layer can cause harm.
- You will scale to a cutting-edge model with trillions of parameters. Pure-Transformer + MLA + MoE (DeepSeek V3 style) is currently winning the ability race.

### Competitive landscape

| Model | Family | Scale | Unique claim |
|-------|--------|------|-------------|
| Mamba-2 | pure SSM | 3B | linear time, constant memory |
| Jamba | hybrid | 52B/12B | 256k on 80GB |

Outlook for 2026: Pure transformer MoE dominates, but hybrid vehicles have an environmental niche of over 256k. The status tracking victory of Mamba-3 may reduce the mixing ratio (more SSM, less attention) in the next generation.

## Key terms

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| State space model (SSM) | "Recurrence with a fixed state" | A layer with a learned recurrence `h_t = A h_{t-1} + B x_t`; constant memory per token |
| Selective SSM | "Mamba's trick" | Data-dependent A, B, C parameters that give the model gating-like selectivity at linear time |
| Attention-to-Mamba ratio | "How many attention layers" | In Jamba, `l = 8` means 1 attention layer per 7 Mamba layers |
| Jamba block | "The 8-layer group" | One attention + seven Mamba + MoE on alternate positions |
| SSM state | "The hidden buffer" | Fixed-size per-layer state that replaces the KV cache for Mamba layers |
| 256k context | "Jamba's flagship number" | The sequence length Jamba-1 fits on a single 80GB GPU; pure Transformer cannot at that size |
| Mamba-3 | "2026 pure SSM" | Current-best pure-SSM architecture with complex state + MIMO; the baseline hybrids rebuild around |
| MIMO | "Multi-input multi-output" | Mamba-3 innovation using matrix-valued projections instead of scalar per-feature |
| Exponential-trapezoidal discretization | "Mamba-3's recurrence" | More expressive recurrence that subsumes Mamba-2's Euler-method discretization |
| Hybrid architecture | "Mix attention and SSM" | Any model that interleaves Transformer and SSM layers; Jamba is the production archetype |
