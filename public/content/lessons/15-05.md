# AI科学家v2 -车间级自主研究

> Sakana的AI Scientist v2 （Yamada et al., arXiv:2504.08066）运行完整的研究循环：假设，代码，实验，数据，书面记录，提交。这是第一个在ICLR 2025研讨会上通过同行评审的系统。独立评估（Beel et al.）发现42%的实验因编码错误而失败，文献综述经常将已建立的概念错误地标记为新颖。Sakana自己的文档警告说，代码库执行llm编写的代码，并建议隔离Docker。这幅图的两边都是重点。

**Type:** Learn
**Languages:** Python (stdlib, research-loop state-machine toy)
**Prerequisites:** Phase 15 · 03 (AlphaEvolve), Phase 15 · 04 (DGM)
**Time:** ~60 minutes

## 这个问题

研究是一项开放式的任务。与AlphaEvolve的算法搜索或DGM的基准有限自我修改不同，研究结果没有机器可检查的正确性标准。一篇论文是由审稿人而不是单元测试来评判的。这使得这个循环更难关闭——如果关闭了就更有价值，因为研究是复合进步的所在。

AI Scientist v1 （Sakana, 2024）通过从人类创作的模板开始完成了这个循环。LLM在固定支架内填充实验。AI Scientist v2 （Yamada et al., 2025）通过使用带有视觉语言模型批判循环的代理树搜索来消除模板需求。该系统产生想法、实施实验、生成图表、撰写论文，并根据审稿人的反馈进行迭代。

同行评议结论：一篇由v2生成的论文被ICLR 2025研讨会接受（已披露）。独立评估结论：该系统远不可靠。两者都是对的。

## 这个概念

### 体系结构

1. * *思想的一代。**法学硕士提出的研究思路取决于一个主题和先前的文献。V1使用的模板；V2在假设空间上使用代理搜索。
2. * *新奇的检查。**文献检索步骤检查该想法是否已发表。这是Beel等人的评估发现错误标记的步骤-建立的方法经常被归类为新颖。
3. * *实验计划。**代理起草实验协议并编写代码。
4. * *执行。**代码在沙盒中运行。失败被反馈到重试循环中。在Beel等人的测量中，42%的实验在这一阶段因编码错误而失败。
5. * *图生成。**视觉语言模型读取生成的图形并重写它们以使其清晰。这是v2的关键技术补充。
6. * *那样。**法学硕士起草一篇论文，与内部审稿人进行迭代。
7. * *可选:提交。论文被提交到会场。

### 车间验收结果意味着什么

一篇v2生成的论文通过了ICLR 2025研讨会的同行评审。作者向项目委员会披露了论文的来源。接受度是一个数据点；这并不是声称该系统“做研究”的许可。

重要背景：研讨会论文的标准低于主要会议论文。同行评议是嘈杂的；在任何一天都有一小部分提交被接受。一个成功是概念的证明，而不是可靠性的声明。《自然》2026年的论文记录了端到端循环，它本身是由人类研究人员共同撰写的；它不是“系统写了一篇自然论文”。

### 独立评估发现了什么

Beel等人（arXiv:2502.14297）进行了外部评估。标题发现:

- * *实验失败。** 42%的实验失败是因为编码错误（导入错误、形状不匹配、变量未定义）。重试循环捕获了一些，而不是全部。
- * *新奇不当。**文献检索步骤经常将已建立的概念标记为新颖。这在研究上相当于幻觉。
- * *表达质量差距。**视觉语言图形批判产生了出版级的视觉效果，掩盖了潜在的实验弱点。

最后一个发现是本阶段的重要发现。一个没有进行令人信服的研究就产生令人信服的产出的系统比一个明显失败的系统更危险，而不是更安全。评估必须达到潜在的权利要求，而不是停留在数字上。

### 沙盒逃逸问题

Sakana自己的存储库README警告：

> 由于本软件执行llm生成的代码，我们无法保证安全性。存在危险包、不受控制的web访问以及产生意外进程的风险。自担风险，并考虑Docker隔离。

这是未经验证的域中自治的操作形式。法学硕士写代码；代码运行；代码可以执行进程允许执行的任何操作。如果没有硬限制文件系统、网络和进程操作的沙箱，任何自我导向的研究代理都可以泄露数据、烧毁计算或重写自身。

AlphaEvolve的沙盒故事更简单，因为它的评估器很紧凑。AI Scientist v2的循环运行带有开放式目标的开放式代码。这就是为什么它需要更强的隔离（Docker最小；seccomp / gVisor优先）和每次提交离开系统之前的手动审查。

### v2在前沿堆栈中的位置

| System | Target | Output kind | Evaluator | Known failure |
|---|---|---|---|---|
| AlphaEvolve | algorithms | code | unit + benchmark | bounded by evaluator rigor |
| DGM | agent scaffolding | code | SWE-bench | reward hacking |
| AI Scientist v2 | research papers | text + code + figures | peer review (weak) | experiment failures, mislabeling, polish masking weakness |

V2的自动评估器是三者中最弱的，输出面最宽，到达公共工件的路径最短。操作控制（沙箱、审查、披露）承担了大部分安全工作。

## 使用它

Z0根据Beel等人的发现，每个状态都有一个可配置的故障概率。运行模拟器N次循环并计数：

- 有多少想法被提交。
- 有多少意见书在抛光纸上隐藏了一个关键的实验缺陷。
- 重试预算如何权衡质量与产出。

## 练习

1. 运行多少次循环可以产生“干净”的纸张？什么样的分数会产生一篇带有实验失败缺陷的论文？

2. 默认值已经使用了Beel等人的42% / 25%。重新运行在这两轮运行中，完美但有缺陷的股票是如何变化的？

3. 阅读Sakana的AI Scientist v2 repo README关于沙盒需求。请列出两个额外的限制（除了Docker之外），您将应用于多日自治运行。

4. 阅读Beel等人。第四部分：陈述质量差距。设计一个额外的评价器，用来捕捉看起来光鲜但实验上有缺陷的论文。

5. 为研究代理的产出提出一个人类审查协议，比“博士阅读每一篇论文”的规模更大。识别瓶颈并围绕它进行设计。

## 关键术语

| Term | What people say | What it actually means |
|---|---|---|
| AI Scientist v1 | "Sakana's templated research agent" | Filled experiments into a fixed scaffold |
| AI Scientist v2 | "Template-free research agent" | Agentic tree search with VLM figure critique |
| Agentic tree search | "Branching research agent" | Expands multiple experiment plans in parallel; prunes by internal critic |
| Vision-language critique | "VLM polish on figures" | Multimodal model reads figures and rewrites them for clarity |
| Literature retrieval | "Novelty check" | Searches prior work to confirm idea novelty — documented to mislabel |
| Polish masking | "Pretty paper, broken research" | Presentation quality exceeds experimental quality; hides weaknesses |
| Sandbox escape | "LLM code breaks out" | Agent-executed code does things the loop designer did not intend |
