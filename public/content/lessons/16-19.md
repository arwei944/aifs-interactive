# Group Optimization (PSO, ACO) of llm

> Bio-inspired optimization is making a comeback for Master of Laws. **LMPSO** (arXiv:2504.09247) uses PSO, where the velocity of each particle is a prompt, and the LLM generates the next candidate particle; It can handle structured sequence output (mathematical expressions, programs) very well. **Model swarm ** (arXiv:2410.11163) regards each LLM expert as a PSO particle on the model weight manifold and reports an average gain of **13.3% ** over 12 baselines of 9 datasets with only 200 instances. ** Swarm Hint ** (ICAART 2025) Hybrid PSO + Gray Wolf Hint Optimization. **AMRO-S** (arXiv:2603.12933) is an ACO-inspired pheromone expert for multi-agent LLM routing - ** 4.7x acceleration **, interpretable routing evidence, asynchronous updates for quality control, and decoupling inference from learning. This lesson implemented the particle swarm optimization algorithm on the prompt parameter space and the ant colony algorithm on proxy routing, and measured why these classic algorithms are suitable for the LLM era and when they are not.

## "Problem"

You have a hint that you scored 62% in your task assessment. You want to improve it. The naive approach is to make manual adjustments without gradients, but it has very poor scalability. Reinforcement learning requires reward signals and sufficient training. Backpropagation through prompts is actually impossible - a prompt is a discrete string rather than a differentiable parameter.

The classic bio-inspired optimization - the particle swarm algorithm for continuous search space and the ant colony algorithm for path selection - is precisely designed for this pattern: gradientless, population-based, and low cost per evaluation. Pair them with LLMS for gradient-free search steps, and you will get a surprisingly practical optimizer.

The same pattern also applies to proxy routing in multi-proxy systems. An ACO-style pheromone trajectory records which agent works best on which task type, allowing the router to utilize this trajectory and attenuate the pheromone in order to rediscover the route.

## Concept

### PSO Review (Kennedy & Eberhart 1995)

Particle swarm optimization: Particle swarm in a continuous search space. Each particle has a position in each iteration:

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

Where is it?

### The PSO-LMPSO on the LLM output

arXiv:2504.09247 Structured output (mathematical expressions, programs) generated by llm adapted to PSO. Each particle is a candidate output. Speed is a "prompt" that describes how to modify the current output to the personal/global best. The LLM generates new output from the speed prompt. The "inertia" of speed is a prompt similar to "make small incremental changes".

This is very effective in the following situations:
- The output is structured (parsable and evaluable).
- Fitness is automatic (test run, arithmetic evaluation).
- The population is very small (about 10 to 30 particles), so the total LLM calls remain controllable.

When adaptability needs to be checked manually, it doesn't work well - the cost of each iteration becomes prohibitive.

### Model group

arXiv:2410.11163 Move the PSO from the output layer to the model layer. Each "particle" is an expert LLM (parameter). The bee colony moves the parameters towards the collective optimum through gradientless update. Report: An average increase of 13.3% was achieved on 12 baselines across 9 datasets, with only 200 instances per iteration.

The key insight is that the LLM expert model is already near the shared parameter manifold (adapter weights, LoRA delta). This particle swarm optimization algorithm on low-dimensional subspaces is a cheap and effective algorithm.

### ACO refresher (Dorigo 1992)

Ant colony optimization: Ants traverse a graph; There are traces of pheromones on every path. The probability-weighted pheromone strength of ant movement. The pheromones secreted by the ants that have completed the task are directly proportional to the mass of the solution. Pheromones will decay over time.

### AMRO-S-ACO is used for proxy routing

arXiv:2603.12933 Multi-agent routing using ACO. Each task type is a "destination"; Each agent is a possible route. Pheromones enhance the routes that generate good output. Main contributions:

- Interpretable routing evidence. Pheromone strength is a human-readable signal.
- Quality gated asynchronous update. Pheromones are only updated after quality checks are passed, decoupling inference from learning.
- A 4.7-fold acceleration in the multi-agent routing benchmark.

The quality gate is very important: without it, fast but wrong agents will accumulate pheromones, and the system will lock onto the wrong route.

### When does a Master of Laws use PSO/ACO

*Use PSO when: **
- The search space is continuous or mapped to continuous parameters (prompt embeddings, LoRA weights, digital generation parameters).
- Fitness is both cheap and automatic.
- The population can be very small (10-30).

*Use ACO when: **
- You have a routing or path selection problem.
- Decisions will be strengthened over time (the same type of task will reappear).
- You need explainable evidence of routing decisions.

*Do not use either when: **
- Adaptability requires manual review (each iteration is too expensive).
- The search space is discrete and combinatorial, and to some extent, PSO does not cover it (using genetic algorithms instead).
- Real-time decision-making requires strict latency (PSO/ACO converges slowly compared to single-pass heuristic algorithms).

### Why does biodynamics still prevail

Gradient-based methods require differentiable signals. The output and routing decisions of LLM are non-differentiable. Pseudo-gradient methods (reinforcement learning routers, DPO-style prompt tuners) can work, but they require expensive training.

Particle swarm optimization algorithm and ant colony algorithm only require one * evaluator * function. If you can score candidate outputs or routing decisions, you can optimize the space. This significantly lowers the threshold for applicability.

### Actual limitations

- Population budget. N particles × T iterations × cost per calculation. For an LLM evaluation at $0.02 per time, the cost of running a 20-particle swarm of particles for 50 iterations is approximately $20. The corresponding plan.
- Exploration vs. Development. Pheromone attenuation rate and PSO inertia trade-off; Decay too fast → Forget the solution; Too slow → Stuck at the early local optimum.
- Catastrophic drift. Both algorithms can converge and then diverges if the fitness landscape changes (new data distribution). Monitor the best health stability.

## This ship

- Start with small things. 10 to 20 particles, 20 to 50 iterations. Only when the convergence curve shows a significant gain should it be proportionally amplified.
- Each iteration records pheromone or g_best. Debugging a group optimizer without tracking is painful.
- The quality inspection checkpoint has been updated. Especially for ant colony algorithms: Fast and incorrect agents cannot generate pheromones.
- Reset the attenuation distribution shift. When your evaluation distribution changes, aging pheromones are outdated. Temporarily reset or double the attenuation rate.
- Limit the cost of each iteration. Issue the cost metric for each iteration. A PSO that costs $500 per iteration and earns a 0.5% return is not publishable.

## Key terms

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| PSO | "Particle Swarm Optimization" | Kennedy-Eberhart 1995. Population-based gradient-free optimizer. |
| ACO | "Ant Colony Optimization" | Dorigo 1992. Path/route optimization via pheromone trails. |
| LMPSO | "PSO with LLM generation" | arXiv:2504.09247. Velocity is a prompt; LLM produces candidates. |
| Model Swarms | "PSO on expert weights" | arXiv:2410.11163. Gradient-free update on model parameter subspace. |
| AMRO-S | "ACO for agent routing" | arXiv:2603.12933. Pheromone matrix over task-type × agent. |
| p_best / g_best | "Personal / global best" | Per-particle and swarm-wide best solutions found so far. |
| Pheromone | "Routing memory" | Strength on an edge; decays over time; deposits on quality. |
| Quality-gated update | "Only learn from good runs" | Pheromone deposit conditioned on quality check. |
| Catastrophic drift | "Distribution shift" | Fitness landscape changes; old p_best and pheromones become stale. |
