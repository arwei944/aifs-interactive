# 主题建模- LDA和BERTopic

> LDA：文档是主题的混合物，主题是单词的分布。BERTopic：文档在嵌入空间中聚类，聚类是主题。相同的目标，不同的原语。

**Type:** Learn
**Languages:** Python
**Prerequisites:** Phase 5 · 02 (BoW + TF-IDF), Phase 5 · 03 (Word2Vec)
**Time:** ~45 minutes

## 这个问题

您有10,000个客户支持票，50,000篇新闻文章或200,000条tweet。你不需要读它，也需要知道它是关于什么的。您没有标记类别。你甚至不知道有多少个类别存在。

主题建模在没有监督的情况下回答了这个问题。给它一个语料库，获取一小组连贯的主题，并为每个文档提供这些主题的分布。

两个算法家族占主导地位。LDA（2003）将每个文档视为潜在主题的混合物，并将每个主题视为单词的分布。推理是贝叶斯的。它仍然在需要混合成员主题分配和可解释的词级概率分布的生产环境中提供。

BERTopic（2020）使用BERT对文档进行编码，使用UMAP降维，使用HDBSCAN聚类，并通过基于类的TF-IDF提取主题词。它在短文本、社交媒体以及任何语义相似性比单词重叠更重要的领域都是赢家。一个文档有一个主题，这对于长篇内容来说是一个限制。

本课建立了对两者的直觉，并指出了为给定语料库选择哪一个。

- Z0

** BERTopic管道. * *

1. 用句子转换器对每个文档进行编码(例如，384 -昏暗的向量。
2. 使用UMAP将维数减少到5维。BERT嵌入对于聚类来说太过模糊。
3. 使用HDBSCAN进行集群。基于密度，产生可变大小的集群和一个“离群值”标签。
4. 对于每个集群，在集群的文档上计算基于类的TF-IDF，以提取最重要的单词。

输出是每个文档一个主题（加上-1异常值标签）。可选地，通过HDBSCAN的概率向量获得软成员资格。

### Step 2: BERTopic (production)

```python
from bertopic import BERTopic

topic_model = BERTopic(
    embedding_model="sentence-transformers/all-MiniLM-L6-v2",
    min_topic_size=15,
    verbose=True,
)

topics, probs = topic_model.fit_transform(documents)
info = topic_model.get_topic_info()
print(info.head(20))
valid_topics = info[info["Topic"] != -1]["Topic"].tolist()
for topic_id in valid_topics[:5]:
    print(f"topic {topic_id}: {topic_model.get_topic(topic_id)[:10]}")
```

过滤器打开`min_topic_size` controls HDBSCAN's minimum cluster size; BERTopic的库默认值是10。本例将课程的等级显式地设置为15。对于超过10,000个文档的语料库，增加到50或100个。

### 第三步：评估

这两种方法都输出主题词。问题是这些话是否连贯。

- **主题连贯（c_v）。**结合滑动窗口上下文中top-word对的NPMI（归一化点互信息），将得分聚合为主题向量，并通过余弦相似度对这些向量进行比较。越高越好。使用
- * *主题的多样性。**在所有主题的热门词汇中，唯一单词的比例。越高越好（主题不重叠）。
- * *定性检查。**阅读每个主题的关键词。他们会命名一个真实的东西吗？人类的判断仍然是最后一道防线。

## 什么时候选哪个

| Situation | Pick |
|-----------|------|
| Short text (tweets, reviews, headlines) | BERTopic |
| Long documents with topic mixtures | LDA |
| No GPU / limited compute | LDA or NMF |
| Need document-level multi-topic distributions | LDA |
| LLM integration for topic labeling | BERTopic (direct support) |
| Resource-constrained edge deployment | LDA |
| Max semantic coherence | BERTopic |

最大的实际考虑是文档的长度。BERT嵌入截断；LDA计算任何长度的工作。对于长度超过嵌入模型上下文的文档，要么使用块+聚合，要么使用LDA。

## 使用它

2026年的堆栈：

- * * BERTopic。**默认用于短文本和任何语义重要的内容。
- ****生产的经典LDA，成熟，经过实战考验。
- ****简单的LDA实验。
- * * NMF。**非负矩阵分解。快速替代LDA，在短文本上的质量相当。
- * * Top2Vec。**与BERTopic设计相似。较小的社区，但在某些基准上表现不错。
- * * FASTopic。**更新，在非常大的语料库上比BERTopic更快。
- * * LLM-based标签。**运行任何集群，然后提示模型命名每个集群。

## Key Terms

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Topic | A thing the corpus is about | A probability distribution over words (LDA) or a cluster of similar documents (BERTopic). |
| Mixed membership | Doc is multiple topics | LDA assigns each document a distribution over all topics. |
| UMAP | Dimensionality reduction | Manifold learning that preserves local structure; used in BERTopic. |
| HDBSCAN | Density clustering | Finds variable-size clusters; produces "noise" label (-1) for outliers. |
| c_v coherence | Topic quality metric | Average pointwise mutual information of top topic words within sliding windows. |
