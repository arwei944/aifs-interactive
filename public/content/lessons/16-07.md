# 心智社会与多智能体辩论

> 明斯基在1986年提出的前提——情报是一个由专家组成的社会——每十年都会被重新发现。2023年，Du等人把它变成了一个具体的算法：多个LLM实例提出答案，阅读彼此的答案，批评和更新。经过N轮的测试，他们最终达成了一个共识，这个共识击败了零射击的CoT和对六个推理和事实性任务的反思。两个发现很重要：**多代理**和**多轮**都独立贡献。社会战胜了单一代理人的独白；多轮交换胜过一次投票。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 04 (Primitive Model)
**Time:** ~60 minutes

## 问题

自我一致性——对一个模型进行多次采样，然后取大多数的答案——是你所能依赖的最廉价的推理改进。它是有效的，但很快就饱和了。你可以将样本翻倍，而不会看到另一个有意义的跳跃。

辩论打破了饱和。不是从一个模型中获得N个独立样本，而是N个智能体读取彼此的推理并进行修改。样本之间的相关性下降（它们不再是i.i.d），而在i.i.d投票肯定是错误的地方，收敛点通常是正确的。

## 概念

### Du et al. 2023算法

来自arXiv:2305.14325 (ICML 2024)：

1. N个代理中的每一个都会产生问题的初始答案。
2. 对于圆r = 2…R：每个代理显示其他代理的R -1轮答案，并被要求“考虑到这些，给出你的最新答案。”
3. R轮之后，多数人投票决定最终答案。

论文测试了MMLU、GSM8K、传记、数学和事实基准。辩论总是胜过CoT和自我反省。

### 两个独立旋钮

同一张纸上的消融：

- **单独代理计数**（1轮，N的多数投票）在大多数任务中击败单代理，但停滞不前。
- **单轮数**（1个代理看到自己的先验推理）几乎没有帮助-反射的已知弱点。
- **两者一起**产生大跳跃。多个代理之间的多轮交换驱动增益。

### 为什么它有效？

两种机制:

1. **接触分歧。**当一个代理看到另一个代理的推理链有不同的结论时，它必须证明或更新。不管怎样，r+1的上下文比r更丰富。
2. **减少相关误差。**在自一致性中，所有样本都来自同一模型，因此误差是相关的——你平均得到一个自信的错误答案。不同的模型或不同的种子不相关。不同的“有争议的观点”进一步解除了相关性。

### 异构的辩论

A-HMAD及相关随访针对不同的药物使用不同的基础模型。Llama + Claude + GPT辩论减少了单一文化的崩溃（第26课），因为一个模式家庭的相关错误不会被其他家庭共享。

缺点：参与辩论的弱模型可能会将共识拖向错误的答案（参见“我们应该发疯吗？”，arXiv:2311.17371）。

### NLSOM - 129个代理扩展

诸葛等人（《基于自然语言的心理社会中的思维风暴》，arXiv:2305.17066）将这一想法扩展到129个成员的社会。其结果是：专业化和自组织随着规模的扩大而出现，系统在视觉问答等任务上的表现优于单一智能体。

### 失效模式

- * *谄媚级联。**所有代理都听从听起来最有信心的代理。辩论被最响亮的声音打断了。提示对抗性角色（“一个代理必须主张相反的立场”）是有帮助的。
- * *主题漂移。**多次辩论都偏离了最初的问题。缓解方法：每轮重新注入问题。
- * *计算崩溃。** N个代理× R轮= N·R个LLM调用，每个调用都有一个增长的上下文。一场5人5轮的辩论是在不断发展的背景下的25次判罚。每个问题的成本可能超过单个CoT呼叫的10倍。

## 构建它

Z0代理都是脚本化的——每个代理都是通过对邻居的回答进行平均来“更新”的。收敛性在逐轮日志中是可见的。

该演示展示了两个关键效果：

- 一轮交换可以让代理人更接近正确答案。
- 第二轮之后的额外回合显示收益递减（符合Du等人的平台）。

## 船这

如果你发布辩论：

- ** 3轮封顶。** Du等人展示了3轮捕获大部分增益。更多的是成本，而不是质量。
- **帽代理在5。**超过5级，环境膨胀和成本占主导地位。
- **默认为异构。**池中至少有两个不同的基本模型。
- * *敌对的插槽。**一名代理人被提示不同意。谄媚。
- **记录每一轮。**隐藏中间回合的辩论系统不能被调试或审计。

## 练习

1. 运行额外的收敛在哪一轮停止？
2. 添加第四个具有对抗作用的代理：永远不同意当前的大多数。这会破坏还是促进趋同？
3. 绘制（打印）每轮的协议分数（代表多数答案的百分比）。它何时达到1.0，这是否等同于“正确”？
4. Read Du et al。第四节烧蚀。使用此代码复制“仅代理”、“仅轮询”和“两者”的结果。
5. 阅读“我们应该发疯吗？”（arXiv:2311.17371）并列出两种超越循环赛的辩论形式——例如，法官主导、辩论链、对抗性。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Society of Mind | "Minsky's idea" | Intelligence as interacting specialists; 1986 framing now operationalized via LLM debate. |
| Multi-agent debate | "Agents argue" | N agents propose, critique each other, revise over R rounds, majority-vote. |
| Consensus | "They agree" | Not epistemic truth — just fraction-on-majority-answer. Can be confidently wrong. |
| Rounds | "Exchange steps" | One round = each agent reads the others and updates once. |
| Heterogeneous debate | "Mix model families" | Using different base models to decorrelate errors. |
| Sycophancy cascade | "Everyone agrees with the loud one" | Debate failure where agents defer to the most confident agent regardless of correctness. |
| NLSOM | "129-agent society" | Natural-language society of mind; Zhuge et al.'s scaled version. |
| Correlated error | "Same model, same bug" | Why self-consistency saturates; debate across different views decorrelates. |
