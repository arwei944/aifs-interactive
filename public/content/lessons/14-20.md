# 基准测试：WebArena和OSWorld

> WebArena测试了四个自托管应用程序的web代理功能。OSWorld测试了Ubuntu、Windows和macOS的桌面代理功能。在发布时（2023-2024），两者都显示出同类最佳代理与人类之间的巨大差距。差距正在缩小；失效模式没有改变。

**Type:** Learn
**Languages:** Python (stdlib)
**Prerequisites:** Phase 14 · 19 (SWE-bench, GAIA)
**Time:** ~60 minutes

## 学习目标

- 描述WebArena的四个自托管应用，以及为什么基于执行的评估很重要。
- 解释为什么OSWorld使用真实的操作系统截图而不是易访问性api。
- 说出两种主要的OSWorld故障模式：GUI接地和操作知识。
- 总结OSWorld-G和OSWorld-Human在基本基准之上添加的内容。

## 这个问题

通才代理可以调用工具。他们能通过20次点击来驱动浏览器完成购物结账吗？他们能用键盘和鼠标来配置Linux机器吗？这些都是WebArena和OSWorld给出的答案。

## 这个概念

### WebArena（周等人，ICLR 2024）

- 横跨四个自托管web应用程序的812个长期任务：一个购物网站，一个论坛，一个类似gitlab的开发工具，一个商业CMS。
- 加上实用工具：地图，计算器，便签本。
- 评估是基于gym api的执行-订单是否已下，问题是否已解决，CMS页面是否更新？
- 发布时：最佳GPT-4制剂的成功率为14.41%，而人类为78.24%。

自托管框架很重要——基准测试并不脆弱，因为目标应用程序是固定的和可复制的。

### 扩展

- **VisualWebArena** -基于视觉的任务，其中成功取决于对图像的解释（截图作为一流的观察结果）。
- **TheAgentCompany**（2024年12月）-增加终端+编码；更像是一个真正的远程工作环境。

### OSWorld （Xie等人，NeurIPS 2024）

- 369个真实的计算机任务跨越Ubuntu， Windows, macOS。
- 自由形式的键盘和鼠标控制的实际应用。
- 1920×1080截图作为观察。
- 发布时：最佳模型12.24% vs人类72.36%。

### 主要失效模式

1. ** GUI接地。**像素→元素映射。模型很难在1920×1080中可靠地本地化UI元素。
2. **操作知识。**哪个菜单有设置，哪个键盘快捷键，哪个首选窗格。人类多年积累的知识尾巴。

### 跟进

- **OSWorld-G** - 564样品接地套件+绝地训练集。从计划中分解基础，以便您可以分别测量它们。
- **OSWorld-Human** -手动策划黄金行动轨迹。显示顶级代理使用的步骤比必要的多1.4-2.7倍（轨迹效率差距）。

### 为什么这很重要？

Claude计算机使用，OpenAI CUA, Gemini 2.5计算机使用（第21课）都是由WebArena和OSWorld塑造的工作负载。基准是目标；生产模型是发货的答案。

### 基准管理哪里出错了

- ** Screenshot-only测评。** OSWorld是截图驱动的；评估在OSWorld上使用DOM或可访问性api的代理忽略了接地的挑战。
- **忽略轨迹长度。**仅评分成功率错过了1.4-2.7x步骤效率低下的OSWorld-Human表面。
- **陈旧的自托管应用。** WebArena的应用锁定特定版本；没有重新整理的更新破坏了可比性。

## 构建它


- 一个最小的“购物应用”状态机：list_items， add_to_cart, checkout。
- 3个任务的黄金轨迹。
- 尝试每个任务的脚本代理。
- 基于执行的评估器（状态检查）和轨迹效率度量（步骤vs黄金）。

运行该程序:

```
python3 code/main.py
```

输出：每个任务的成功率和轨迹效率，反映了OSWorld-Human的方法。

## 使用它

- **WebArena验证**自托管在内部集群上进行持续评估。
- **OSWorld**在桌面代理的虚拟机舰队。
- **计算机使用代理**（第21课）- Claude, OpenAI CUA， Gemini -都接受过这样的工作量训练。
- **您自己的产品流** -为您的前20个任务捕获黄金轨迹；每周对它们运行代理。

## 练习

1. 用第二个应用程序（论坛）扩展玩具线束。写下3个任务加上黄金轨迹。
2. 增加每个任务的轨迹效率报告。在你的玩具上，药剂是黄金的1x， 2x，还是3x ？
3. 实施一个“分散注意力”的工具——一个黄金轨迹从未使用过的工具。脚本代理会受到诱惑吗？
4. 读OSWorld-G。在你自己的评估中，你如何区分接地失败和计划失败？
5. 阅读WebArena的应用程序README。当你升级一个固定的应用程序版本时，什么会中断？

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| WebArena | "Web agent benchmark" | 812 tasks across 4 self-hosted apps; gym-style evaluation |
| VisualWebArena | "Visual WebArena" | Visually grounded WebArena; screenshots are observations |
| OSWorld | "Desktop agent benchmark" | 369 tasks on real Ubuntu/Windows/macOS |
| GUI grounding | "Pixel-to-element mapping" | Model localizing UI elements in 1920x1080 |
| Operational knowledge | "OS know-how" | Which menu, which shortcut, which preference pane |
| OSWorld-G | "Grounding suite" | 564 grounding-only samples + training set |
| OSWorld-Human | "Gold trajectories" | Manual expert action sequences to measure efficiency |
| Trajectory efficiency | "Steps over gold" | Agent step count divided by human minimum |
