## 这个问题

将784像素的MNIST数字压缩为16位数的代码，然后进行重构。一个普通的自动编码器可以实现重构MSE，但是代码空间是一团乱麻。在编码空间中随机选择一个点，解码它，你就得到了噪声。它没有采样器。这是一个经过修饰的压缩模型。

你真正想要的是：(a)代码空间是一个干净、平滑的分布，你可以从中采样——比如说一个各向同性的高斯分布三个目标，一个架构，一个损失。

Kingma的2013 VAE通过训练编码器输出一个*分布*来解决这个问题在推理时间，丢弃编码器，采样KL惩罚是强制代码空间结构化的原因。

在2026年，VAEs很少单独发布——它们在原始图像质量方面已经被扩散超越了——但它们是每个潜在扩散模型（SD 1/2/XL/3, Flux, AudioCraft）的首选编码器。学习了VAE，你就学会了你使用的每个图像管道中不可见的第一层。

## 这个概念


** Autoencoder。**非结构化的代码空间。

** VAE编码器。**输出两个矢量：它们def 了

**损失。**证据下限（ELBO），两项：

```
loss = reconstruction + β · KL[q(z|x) || N(0, I)]
     = ||x - x̂||²  + β · Σ_i ( σ_i² + μ_i² - log σ_i² - 1 ) / 2
```

重建推动KL推他们相互权衡。小β(<1) =更清晰的样本，代码空间更少的高斯。大β(>1) =更清晰的代码空间，更模糊的样本。β-VAE （Higgins 2017）使这个旋钮出名，并开启了解开纠缠的研究。

**抽样。**推断：画一个正向传递-没有像扩散那样的迭代采样。

## 构建它

Z0输入是8维合成数据，从8维的2分量高斯混合物中提取。编码器和解码器是单隐藏层mlp。我们实现了tanh激活、向前传递、丢失和手写的向后传递。不是生产，而是教学。

### 第一步：编码器转发

```python
def encode(x, enc):
    h = tanh(add(matmul(enc["W1"], x), enc["b1"]))
    mu = add(matmul(enc["W_mu"], h), enc["b_mu"])
    log_sigma2 = add(matmul(enc["W_sig"], h), enc["b_sig"])
    return mu, log_sigma2
```

`log σ²` instead of `σ` so the network output is unconstrained (softplus of σ is a trap — gradients die at σ ≈ 0).

### Step 2: reparameterize and decode

```python
def reparameterize(mu, log_sigma2, rng):
    eps = [rng.gauss(0, 1) for _ in mu]
    sigma = [math.exp(0.5 * lv) for lv in log_sigma2]
    return [m + s * e for m, s, e in zip(mu, sigma, eps)]

def decode(z, dec):
    h = tanh(add(matmul(dec["W1"], z), dec["b1"]))
    return add(matmul(dec["W_out"], h), dec["b_out"])
```

### 第三步：ELBO

”“python
Def (x, x_hat, mu, log_sigma2, beta=1.0)：
Recon = sum(（a - b) ** 2 for a, b in zip(x, x_hat)）
Kl = 0.5 * sum（数学）Exp （lv) + m * m - lv - 1 for m, lv in zip(mu, log_sigma2)）
返回recon + beta * kl， recon, kl
```

Exact closed-form KL because both distributions are Gaussian. Do not integrate numerically. People still ship code with monte-carlo KL estimates in 2026 — it is 3x slower for no reason.

### Step 4: generate

```python
def sample(dec, z_dim, rng):
    z = [rng.gauss(0, 1) for _ in range(z_dim)]
    return decode(z, dec)
```

这就是生成模型。五行。

## 陷阱

- **后崩溃。** KL术语驱动修正：β-退火（开始β=0，斜坡到1），自由位，或跳过非活动维度上的KL。
- **模糊样本。**高斯解码器的似然意味着MSE重建，这是贝叶斯最优的L2（平均值）-一组似是而非的数字的平均值是一个模糊数字。固定：离散解码器（VQ-VAE， NVAE），或使用VAE仅作为编码器和堆栈扩散的潜在（这是什么稳定扩散做）。
- **β太大，太早。**参见后倾。从β≈0.01开始，然后逐渐增加。
- **潜伏昏暗太小。** 16-D适用于MNIST， 256- d适用于ImageNet 256²，2048-D适用于ImageNet 1024²Stable Diffusion的VAE压缩512×512×3→64×64×4（空间面积32倍的下采样因子，通道32倍）。

## 使用它

2026年VAE堆栈：

| Situation | Pick |
|-----------|------|
| Image-latent encoder for diffusion | Stable Diffusion VAE (`sd-vae-ft-ema`) or Flux VAE |
| Audio-latent encoder | Encodec (Meta), SoundStream, or DAC (Descript) |
| Video latents | Sora's spatiotemporal patches, Latte VAE, WAN VAE |
| Disentangled representation learning | β-VAE, FactorVAE, TCVAE |
| Discrete latents (for transformer modelling) | VQ-VAE, RVQ (ResidualVQ) |
| Continuous latents for generation | Plain VAE, then condition a flow/diffusion model in that latent space |

潜扩散模型是一种在编码器和解码器之间存在扩散模型的VAE。VAE做粗压缩，扩散模型做重压缩。同样的模式用于视频（VAE +视频扩散DiT）和音频（Encodec + MusicGenTransformer）。

## 练习

1. **容易。**改变记录最终的重构MSE和KL，哪一个β最适合你的合成数据？
2. **介质。**用伯努利似然（交叉熵损失）替换高斯解码器似然。在相同合成数据的二值化版本上比较样品质量。
3. **难。**扩展比较重构MSE并报告使用了多少码本条目（码本崩溃是真实的）。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Autoencoder | Encode-decode network | `x → z → x̂`, learn MSE. Not generative. |
| VAE | AE with a sampler | Encoder outputs a distribution, KL penalty shapes code space. |
| ELBO | Evidence lower bound | `log p(x) ≥ recon - KL[q(z|x) \|\| p(z)]`; tight when `q = p(z|x)`. |
| Reparameterization | `z = μ + σ·ε` | Rewrites stochastic node as deterministic + pure noise. Enables backprop through sampling. |
| Prior | `p(z)` | Target distribution for the latent, typically `N(0, I)`. |
| Posterior collapse | "KL term wins" | Encoder ignores `x`, outputs the prior; decoder must hallucinate. |
| β-VAE | Tunable KL weight | `loss = recon + β·KL`. Higher β = more disentangled but blurrier. |
| VQ-VAE | Discrete latent | Replace continuous `z` with nearest codebook vector; enables transformer modelling. |
