# 火烈鸟与少射VLMs的门控交叉注意

> DeepMind的火烈鸟（Flamingo， 2022年）在两件事上做得比任何人都早。它表明，单个模型可以处理任意交错的图像、视频和文本序列。它表明VLMs可以在上下文中学习-给出三个例子（图像，标题）对的几张照片提示，模型标题是一个新的图像，没有任何梯度步骤。其机制是：闸门交叉注意层，插入在冻结的LLM现有层之间，具有从零开始的学习tanh门，因此LLM的文本能力在初始化时保留。本课将介绍Flamingo的percepver重新采样器和门控交叉注意架构——Gemini的交错输入和Idefics2的视觉标记的祖先。

**Type:** Learn
**Languages:** Python (stdlib, gated cross-attention + Perceiver resampler demo)
**Prerequisites:** Phase 12 · 03 (BLIP-2 Q-Former)
**Time:** ~120 minutes

## 学习目标

- 通过tanh(gate) = 0解释闸门交叉注意如何在初始化时保留冻结LLM的文本能力。
- 通过一个感知器重新采样器：N个图像补丁→K个通过交叉注意固定的“潜在”查询。
- 描述Flamingo如何处理具有因果掩蔽的交错图像-文本序列，并尊重图像位置。
- 重现几个镜头的多模态提示结构（3个图像标题示例然后一个查询图像）。

## 这个问题

BLIP-2将32个视觉标记输入到冻结的LLM的输入层。适用于每个提示一个图像。但是，如果你想输入与文本交错的*许多*图像，如“这是图像A，标题它；这是图片B，加上标题；现在这是图片C，标题是？LLM的自关注需要在单个流中处理图像令牌和文本令牌，而哪个位置可以处理哪个图像的问题变得棘手。

Flamingo的答案是：根本不改变LLM的输入流。在现有LLM块之间插入额外的交叉注意层。文本标记仍然像往常一样流经法学硕士的因果自我关注。在每隔几个LLM块之间，文本令牌还通过一个新的门控层交叉关注图像特征。门（初始化为零）意味着在第0步，新层是无操作的——模型的行为完全像预训练的LLM。随着训练的进行，门打开了，视觉信息开始流动。

Flamingo回答的第二个问题是：如何处理每个提示符中可变数量的图像（0、1或多个）？一个感知器重新采样器-一个小的交叉注意模块，无论你有多少补丁，并产生固定数量的视觉潜在标记。无论提示符中有多少图像，LLM交叉注意层都会看到相同的形状。

## 这个概念

### 冷冻LLM

火烈鸟从冰冻的Chinchilla 70B LLM开始。所有70B重量不变。现有文本自关注和FFN运行正常。

### 感知者重新取样

对于提示符中的每个图像，ViT生成N个补丁令牌。感知器重采样器有K个固定的可学习电位（Flamingo使用K=64）。每个重采样块有两个子步骤：

1. 交叉关注：K个专利参与了N个补丁令牌（来自专利的Q，来自补丁的K/V）。
2. 自我关注+潜在内FFN。

在6个重采样器块之后，输出K=64个暗淡1024的视觉标记，而不管ViT产生了多少个补丁。一个224x224的图像（196个补丁）和一个480x480的图像（900个补丁）都以64个重新采样器令牌退出。

对于视频，重新采样器是临时应用的：每帧的patch产生64个潜伏，并且临时位置编码让模型区分t=0和t=N。完整的视频变成T * 64视觉符号。

### 封闭的cross-attention

在冻结LLM的每M层之间（Flamingo使用M=4），插入一个新的门控交叉注意块：

```
x_after_llm_block = llm_block(x_before)
cross = cross_attn(x_after, resampler_output)
gated = tanh(alpha) * cross + x_after
x_before_next_block = gated
```

- 剩余连接意味着即使完全打开的门也不会覆盖LLM的文本表示；它只是在顶部添加了视觉信息。

这是Flamingo中最重要的设计选择：视觉调节是加性的、门控的，初始化时为零。第0步的火烈鸟在纯文本输入上是完美的Chinchilla 70B。

### 交错输入的掩蔽交叉注意

在像“<image a > caption a <image B> caption B <image C> ?”这样的提示符中，每个文本标记应该只看到序列中出现在它之前的图像。交叉注意掩码在位置强制：文本标记“只看到最后一个前面的图像”或“看到所有前面的图像”都是有效的选择；火烈鸟选择了前者。

### 情境下的少镜头学习

Flamingo提示符看起来像这样：

```
<image1> A photo of a cat. <image2> A photo of a dog. <image3> A photo of a
```

模型看到完成模式并输出“bird”（或image3显示的任何内容）。没有梯度步骤。冻结LLM的情境学习能力贯穿了封闭式交叉注意——这是论文的妙语，也是为什么它很重要。

### 训练数据

火烈鸟在三个数据集上训练：

1. MultiModal MassiveWeb (M3W): 43M网页，图文交错，重构阅读顺序。
2. 图像-文本对（ALIGN + LTIP）： 4.4B对。
3. VTP (video - text Pairs)：支持27M短视频。

OBELICS（2023）是交错网络语料库的开放复制，Idefics、Idefics2和大多数开放的“类似火烈鸟的”模型都在其上进行训练。

### 打开火烈鸟和水獭

开放火烈鸟（2023）是开放复制。架构相同（感知器重采样器+门控交叉注意对冻结的美洲驼或MPT）。3B, 4B， 9B都有检查点。由于基础LLM较小和数据较少，质量滞后于Flamingo。

Otter（2023）建立在OpenFlamingo上，在MIMIC-IT（多模态指令的数据集）上进行指令调优，也显示了指令跟随的门控交叉注意工作。

### 的后裔

- ideficics / Idefics2 / Idefics3：拥抱脸的门控交叉注意谱系，逐渐简单（Idefics2放弃了重采样器，支持带有自适应池的直接补丁令牌）。
- 火烈鸟到变色龙的转变：到2024年，许多团队转向早期融合（第12.11课）；火烈鸟式门控交叉注意仍然存在于需要骨干冻结的生产中。
- Gemini的交错输入：从概念上继承了Flamingo的交错格式灵活性，尽管确切的机制是专有的。

### 与BLIP-2比较

| | BLIP-2 | Flamingo |
|---|---|---|
| Visual bridge | Q-Former once at input | Gated cross-attention at every M layers |
| Visual tokens | 32 per image | 64 per image per cross-attn layer |
| Frozen LLM | Yes | Yes |
| Few-shot in-context | Weak | Strong — the paper's centerpiece |
| Interleaved inputs | No native support | Yes, the design target |
| Training data | 130M pairs | 1.3B pairs + 43M interleaved pages |
| Parameter count | 188M trained | ~10B trained (cross-attn layers) |
| Compute | Days on 8 A100s | Weeks on thousands of TPUv4 |

在预算有限的情况下，为单图像VQA选择BLIP-2。选择Flamingo/Idefics2进行交错、少拍或多图像推理。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Perceiver resampler | "Fixed-latent cross-attention" | Module that produces K fixed tokens from a variable number of input patches |
| Gated cross-attention | "Tanh-gated bridge" | Residual layer `y = tanh(alpha)*cross + x`, learnable alpha, init 0 |
| Interleaved input | "Mixed sequence" | Prompt format with images and text mixed freely in reading order |
| Frozen LLM | "No LLM gradients" | The text LLM's weights do not update; only resampler + cross-attn layers train |
| Few-shot | "In-context examples" | Give a few (image, answer) pairs in the prompt; model generalizes without finetuning |
| OBELICS | "Interleaved web corpus" | Open dataset of 141M web pages with images and text in reading order |
| Chinchilla | "70B frozen base" | Flamingo's frozen text LLM, from DeepMind's Chinchilla paper |
| Gate schedule | "How alpha moves" | The rate at which the cross-attention gate opens during training |
| Cross-attn frequency | "Every M layers" | How often a gated cross-attention block is inserted; Flamingo uses M=4 |
| OpenFlamingo | "Open reproduction" | MosaicML/LAION open checkpoint at 3-9B; architecture-identical to Flamingo |
