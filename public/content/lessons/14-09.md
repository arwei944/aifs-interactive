# 混合存储器：矢量+图形+ KV （Mem0）

> Mem0 （Chhikara等人，2025）将记忆视为并行的三个存储——向量用于语义相似性，KV用于快速事实查找，图用于实体关系推理。评分层在检索上融合了这三者。这是2026年外部存储器的生产标准。

## 学习目标

- 解释为什么单个存储（仅向量、仅图、仅KV）对于代理内存是不够的。

- 描述Mem0的融合评分——相关性、重要性、近代性——以及为什么它是一个加权和，而不是一个层次。
- 类在标准库中实现一个玩具三存储内存

## 这个问题

以下三个查询类中的一个存储是错误的：

- **语义相似度** -“上周我们讨论了agent漂移吗？”向量获胜;KV和图miss。
- **事实查找** -“用户的电话号码是什么？”KV获胜;向量是浪费的，图形是多余的。
- **关系推理** -“哪些客户共享同一个账单实体？”图胜;矢量和KV无法回答。

生产代理在一个会话中发布所有这三个。对于其中的两个来说，单存储器总是错误的。Mem0的贡献是将三者连接在一起

## 这个概念

### 三个平行的商店

[j] .中国科学院学报（自然科学版）

1. 从文本中提取候选事实（法学硕士驱动的步骤）。
2. 将每个事实写入向量存储（嵌入）以进行语义搜索。
3. 将每个事实写入键为（user_id, fact_type, entity）的KV存储中，以进行O(1)查找。
4. 将每个事实作为类型化边写入图存储（Mem0g），用于关系查询。

On

1. 向量存储通过嵌入余弦返回top-k。
2. KV存储返回直接命中查询派生的（user_id, type, entity）。
3. 图存储返回可从查询实体访问的子图。
4. 得分层融合了这三者。

### 融合得分

```
score = w_relevance * relevance(q, record)
      + w_importance * importance(record)
      + w_recency * recency(record)
```

- **相关性** -矢量余弦，KV精确匹配，图路径权重。
- **重要性** -在写作时标记或学习（一些事实更重要：名称，id，策略）。
- **近因** -指数衰减随着时间的推移，因为上次写入或读取。

权重是针对每个产品进行调整的。更高更高更高

### 记忆和时间推理

Mem0g添加了一个冲突检测器。当新的事实与现有的边相矛盾时，现有的边被标记为无效，但不被删除。时态查询（“3月份用户所在的城市是什么？”）遍历有效时间子图。

这是Letta的无效模式概括的遵从级行为。

### 基准数据

备忘录文件报告（2025）：

- **LoCoMo**（长形式会话记忆）：91.6
- **LongMemEval**（长视界情景记忆）：93.4
- **BEAM 1M** （1M-token内存基准）：64.1

比较基线（全背景128k LLM，平坦矢量存储，平坦KV）都损失了10+点。单独的基准测试并不能证明选择是正确的——操作形状是正确的——但数字表明融合设计不是一个舍入误差。

### 范围分类

Mem0按作用域拆分内存：

- **用户内存** -持续跨会话，键
- **会话内存** -保存在一个线程内。
- **代理内存** -每个代理实例状态。

每次写入选择一个作用域。检索可以跨范围查询每个范围的权重。不加思考地混合作用域是导致“助理告诉Alice Bob的项目”事件的原因。

### 这种模式哪里出错了

- * *嵌入漂移。**在前100个查询中看起来正确的向量结果会随着语料库的增长而降低。添加top- n使用记录的定期重新嵌入。
- **KV模式蠕变。**每季度审计类型集。
- * *爆炸图。**一个噪声提取器每条消息添加50条边。封顶图放弃不自信的优势。

## 练习

1. 用真实的嵌入模型（句子变形器，Ollama， OpenAI嵌入）替换玩具向量相似度。在合成的长对话中测量recall@10。超过1000次写入的排名是否会漂移？

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Hybrid memory | "Vector plus graph plus KV" | Three stores written in parallel, fused on retrieval |
| Fact extraction | "Memory ingestion" | LLM step that breaks text into (entity, relation, fact) tuples |
| Fusion scoring | "Relevance ranking" | Weighted sum of relevance, importance, recency |
| Scope | "Memory namespace" | user / session / agent — determines who sees what |
| Mem0g | "Memory graph" | Typed edges with temporal validity for relationship queries |
| Temporal invalidation | "Soft delete" | Mark contradicted edges invalid; never delete |
| Embedding drift | "Retrieval rot" | Vector quality degrades as corpus grows; re-embed periodically |
