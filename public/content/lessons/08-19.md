# 视觉自回归模型（VAR）：下一尺度预测

> 扩散模型在时间上迭代采样（去噪步骤）。VAR在尺度上迭代采样-它预测1x1令牌，然后2x2，然后4x4，直到最终分辨率，每个尺度都在前一个尺度上进行调节。2024年的论文表明，VAR与gpt风格的图像生成缩放定律相匹配，并且在相同的计算预算下击败了DiT。本课构建了核心机制。

**Type:** Build
**Languages:** Python (with PyTorch)
**Prerequisites:** Phase 7 Lesson 03 (Multi-Head Attention), Phase 8 Lesson 06 (DDPM)
**Time:** ~90 minutes

## 这个问题

自回归生成主导了语言建模，因为它可预测地扩展：更多的计算，更多的参数，更低的困惑，更好的输出。在2024年之前，图像生成有两个主要的AR尝试：PixelRNN/PixelCNN（逐像素）和DALL-E 1 / Parti / MuseGAN（在VQ-VAE代码上逐令牌）。

两者都存在代序问题。像素和标记被安排在二维网格中，但AR模型必须以一维光栅顺序访问它们。早期的角点像素不知道图像最终会变成什么样子。生成质量比文本上的gpt更差，并且在匹配计算时从未达到扩散模型质量。

VAR通过改变正在生成的内容来修复生成顺序问题。VAR不是在空间中一个接一个地预测图像标记，而是以不断增加的分辨率预测整个图像。第一步：预测一个1x1标记（整体图像“summary”）。步骤2：预测一个2x2的标记网格（较粗糙的特征）。步骤3：预测4x4网格。步骤K：预测最终的（H/8）x（W/8）网格。

每个音阶都与之前的所有音阶相关（按“音阶顺序”），并与自己的音阶平行。顺序问题消失了：尺度k的整个图像在一个变压器通道中产生。

## 这个概念

### VQ-VAE多尺度标记器

VAR需要一个多尺度离散标记器。对于图像x，它会产生一系列逐渐提高分辨率的令牌网格：

```
x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 of shape (1, 1)
f -> tokenize at 2x2: token grid z_2 of shape (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K of shape (H/p, W/p)
```

每个z_k使用相同的码本（典型大小为4096-16384）。每个尺度上的标记化不是独立的-它经过训练，以便将每个尺度上的残差求和重建f：

```
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

这是一个**残留VQ**变体。尺度k捕获尺度1..k - 1错过。解码器取所有尺度嵌入的和并产生图像。

多尺度VQ标记器训练一次（如VQGAN），然后冻结。所有的生成工作都是由上面的自回归模型完成的。

### Next-Scale预测

生成模型是一个转换器，它可以看到所有以前规模的令牌，并预测下一个规模的令牌。

输入序列结构：
```
[START, z_1 tokens, z_2 tokens, z_3 tokens, ..., z_K tokens]
```

位置嵌入编码标度索引和标度内的空间位置。注意在尺度顺序上是因果关系：尺度k上的标记，位置（i, j）可以注意尺度1上的所有标记。k和尺度k本身的标记，无论使用何种尺度内顺序（VAR使用固定的位置注意，没有尺度内因果关系——一个尺度内的所有位置都是并行预测的）。

训练损失：在每个尺度k下，给定所有的前尺度标记，预测标记z_k。离散VQ码的交叉熵损失。与GPT相同的结构，除了“序列”现在是规模结构。

### 一代

推理:
```
generate z_1 = sample from p(z_1)                    # 1 token
generate z_2 = sample from p(z_2 | z_1)              # 4 tokens in parallel
generate z_3 = sample from p(z_3 | z_1, z_2)         # 16 tokens in parallel
...
decode: f = sum of embed-and-upsample scales 1..K
image = VAE_decoder(f)
```

对于K = 10尺度，发电量为10次变压器正向通过。每个通道并行地产生它的整个尺度——在一个尺度内没有每个标记的自回归。对于256x256的图像，这大约是10次，而DiT是28-50次。

### 为什么下一个规模胜过下一个代币

三个结构性胜利：
1. **从粗到细与自然图像统计对齐。**人类视觉感知和图像数据集都表现出尺度依赖性规律：低频结构稳定且可预测；高频细节以低频内容为条件。下一尺度预测利用了这一点。
2. **规模内并行生成。**与gpt风格的代币AR不同，VAR在一步中以规模生成所有代币。有效发电长度是对数尺度的，而不是线性的。
3. **无代序偏差。**规模k的令牌见所有规模k-1；没有“左”或“上”的偏见，迫使早期的令牌在后期上下文可用之前提交。

### 标度律

Tian等人证明了VAR在ImageNet上对FID遵循幂律缩放曲线——就像GPT对perplexity所做的那样。加倍参数或计算可靠的一半误差。这是第一个像语言模型一样清晰地展示这种缩放行为的图像生成模型。结果是var规模的预测从计算中变得可预测，而不是每个体系结构的经验猜测。

### 与扩散的关系

VAR和扩散共享相同的数据压缩故事：它们都将生成问题分解为一系列更容易的子问题。

- 扩散：逐渐加噪，学会撤销一步。
- VAR：逐渐增加分辨率，学会预测下一个尺度。

它们在问题中是不同的坐标轴。两者都产生可处理的条件分布。根据经验，VAR在推理方面更快（更少的传递，在一个尺度内所有并行），并且在类条件ImageNet上匹配或击败DiT。文本条件VAR （VARclip， HART）是一个活跃的研究方向。

## 构建它

在
1. 构建一个微小的**多尺度VQ标记器**合成“图像”数据（二维高斯环）。
2. 训练一个var风格的变压器来预测标记。
3. 通过调用变压器4次（4个刻度）和解码进行采样。
4. 验证尺度有序的训练使生成在一个尺度内并行。

这是一个简单的实现。重点是要看到尺度结构的注意力掩膜和尺度内并行生成实际上是有效的。

## 练习

1. **鳞片计数消融。**用4、6、8、10个刻度训练VAR。测量重建质量与自回归通过次数。更多的尺度=更精细的残差=更好的质量，但更多的通道。

2. * *码书大小。**训练码本大小为512、4096、16384的标记器。更大的密码本可以更好地重建，但更难预测。找到膝盖。

3. * * Parallel-within-scale检查。**对于经过训练的VAR，要明确地测量注意模式。在尺度k内，模型是否关注跨尺度位置而不关注尺度内位置？验证掩码实现。

4. **VAR vs DiT缩放。**对于相同的ImageNet类条件任务，在匹配的参数预算（例如，33M, 130M, 458M）下训练VAR和DiT。绘制FID vs compute。VAR应该在每个规模上都领先于DiT——在小规模上复制论文的结果。

5. * *文本条件。**扩展VAR，通过adaLN将文本嵌入（CLIP池）作为额外的条件输入。这是HART食谱。FID对文本对齐采样的改进有多大？

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|----------------------|
| VAR | "Visual AutoRegressive" | Image generation by next-scale prediction over a pyramid of VQ token grids |
| Next-scale prediction | "Predict coarser, then finer" | The model predicts tokens at increasing resolution scales, conditioning on all previous scales |
| Multi-scale VQ tokenizer | "Residual VQ" | VQ-VAE that produces K token grids of increasing resolution, with decoder summing all scales |
| Scale k | "Pyramid level k" | One of K resolution levels, from 1x1 at k=1 up to (H/p)x(W/p) at k=K |
| Parallel-within-scale | "One forward per scale" | All tokens at scale k are predicted in one transformer pass, not autoregressively |
| Causal-across-scales | "Scale-ordered attention" | Token at scale k can attend to all of scales 1..k but not scales k+1..K |
| Residual VQ | "Additive tokenization" | Each scale's tokens encode the residual left by lower scales; decoder sums all scale embeddings |
| VAR scaling law | "Image GPT scaling" | FID follows a predictable power law in compute, like language models' perplexity |
| HART | "Hybrid VAR + text" | Text-conditional VAR variant combining MaskGIT-style iterative decoding with VAR's scale structure |
| Scale position embedding | "(scale, row, col) triple" | Positional encoding carries both the scale index and spatial coordinates within the scale |
