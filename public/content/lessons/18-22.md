# 法学硕士的差异隐私

> DP-SGD仍然是标准的——噪声注入的梯度更新提供了正式的（epsilon, delta）保证。计算、内存和实用程序方面的开销很大；参数高效DP微调（LoRA + DP- sgd）是常见的2025配置（ACM 2025）。两种证据处于紧张状态：基于金丝雀的隶属推理（Duan et al., 2024）报告了针对语言模型的有限成功；训练数据提取（Carlini et al., 2021; Nasr et al., 2025）可以恢复大量的逐字记忆。分辨率（arXiv:2503.06808, 2025年3月）：差距在于测量的内容-插入的金丝雀与“最可提取”的数据。新的金丝雀设计使基于损失的MIA没有阴影模型，并产生了具有现实DP保证的真实数据训练的LLM的第一个非平凡DP审计。备选方案：pmix （arXiv:2403.15638）——通过下一个令牌分布的混合专家在推理时进行私有预测；DP合成数据生成（谷歌Research 2024）。新兴攻击：通过LLM反馈的差分隐私逆转-信心得分泄漏。

## 这个问题

llm记忆。Carlini et al. 2021展示了生产语言模型可以按需逐字复制训练文本。DP是正式的防御训练，因此输出对任何单个训练示例都是可证明的不敏感。2024-2025年的证据表明DP-SGD是必要的，但部署的ε值可能与威胁模型不匹配。

## 这个概念

### （ε, δ）-差分隐私

随机化算法M = (ε, δ)-DP，如果对于任意两个数据集在一个例子和任意事件S中不同：
P(M(D) in S) <= e^ε * P(M(D') in S) + δ。

解释：输出分布足够接近（由ε参数化），任何单个个体的贡献都不能可靠地推断，除非概率为δ。

### DP-SGD

Abadi et al. 2016。标准配方：
1. 小批量取样。
2. 计算每个示例的梯度。
3. 将每个示例的梯度剪辑为阈值C。
4. 对裁剪后的梯度求和，加上高斯噪声，标准差σ * C。
5. 使用噪声求和来更新参数。

隐私成本由会计师（Moments accounting, r2013.dp accounting）跟踪。法学硕士文献中报告的ε值因威胁模型、数据敏感性和实用目标而有很大差异；不存在普遍“安全”的默认ε。在一些LLM训练设置中，已发表的示例跨度大约为ε≈1-10，但这些是说明性的-不推荐默认值。较低的ε通常需要更多的噪声，并可能增加效用损失。

### LoRA + DP-SGD

前沿模型的完整DP-SGD是令人望而却步的。LoRA （Hu et al. 2022）将梯度更新限制在一个小适配器上，减少了每个示例的梯度存储。LoRA + DP-SGD是2025的常见配置。DP保证适用于适配器；基本模型是固定的。

### 2024-2025年的紧张局势

两种证据：

- **Canary MIA （Duan et al. 2024）。**在训练数据中插入唯一的金丝雀，衡量成员推理攻击者能否识别它们。报告在语言模型上的成功有限。说明MIA很难。
- **训练数据提取（Carlini 2021, Nasr et al. 2025）。**用前缀提示模型；测量它是否从训练中恢复逐字文本。报告大量的记忆。说明MIA在相关意义上很简单。

2025年3月决议（arXiv:2503.06808）：两者测量的东西不同。MIA在插入的金丝雀上问“例子e在D中吗？”提取问“我可以从D中提取什么？”“最可提取”的例子是什么对隐私至关重要；金丝雀低估了这一点，因为它们没有被优化为可提取的。

新的金丝雀设计。没有阴影模型的基于损失的MIA。首先对具有实际DP保证的真实数据的LLM进行非平凡的DP审计。

### DP培训的替代方案

- * * PMixED (arXiv: 2403.15638)。**在推理时间的私人预测。下一个代币分配的混合专家；每个专家都会看到训练数据的碎片；聚合为DP增加了噪声。完全避免DP训练。
- **DP合成数据生成（谷歌Research 2024）。** lora -微调DP-SGD，采样合成数据，在合成数据上训练下游分类器。

两者都避免了以不同威胁模型为代价的完整DP训练的效用成本。

### 基于LLM反馈的差分隐私反转

2025年即将到来的袭击。使用dp训练模型的置信度分数作为重新识别个体的预言器。即使输出没有泄漏，置信度分布也会泄漏。

防御：不要暴露机密，或者在暴露之前截断/量化它们。这是(ε, δ)-DP训练之外的额外要求。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| DP | "(ε, δ)-differential privacy" | Formal privacy: output distribution close under neighbouring-dataset change |
| DP-SGD | "noise-injected SGD" | Gradient clipping + Gaussian noise addition; standard DP training |
| LoRA + DP-SGD | "efficient private fine-tune" | DP-SGD on low-rank adapters; standard 2025 configuration |
| MIA | "membership inference" | Attack that determines whether an example was in training data |
| Canary | "inserted watermark example" | Unique training example used to measure DP leakage |
| PMixED | "private inference mixture" | Inference-time DP via mixture-of-experts on next-token distributions |
| DP Reversal | "confidence leakage attack" | Attack that uses a model's confidence as an oracle for re-identification |
