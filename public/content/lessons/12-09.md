# Qwen-VL家族和动态fps视频

> Qwen-VL家族——Qwen-VL（2023）、Qwen2-VL（2024）、Qwen2.5-VL（2025）、Qwen3-VL（2025）——是2026年最具影响力的开放视觉语言模型谱系。每一代人都做出了一个决定性的架构赌注，其余的开放生态系统在12个月内复制：通过M-RoPE的本地动态分辨率，绝对时间对齐的动态fps采样，ViT中的窗口注意力和结构化代理输出格式。通过Qwen3- vl，方法已经稳定下来：一个带有本地长宽比输入的2D-RoPE-ViT编码器，一个MLP投影仪到一个大型Qwen3语言库，以及强调OCR，接地和代理行为作为一级目标的训练阶段。本课按时间顺序阅读家族，这样你就能理解为什么每个旋钮都在那里。

## 这个问题

Qwen-VL于2023年8月交付，作为对LLaVA-1.5和BLIP-2的直接响应。Qwen团队的目标是三个方面的差距：分辨率、视频和结构化输出。

分辨率：LLaVA-1.5运行在336x336。对于照片来说很好，但对于中文发票或密集的电子表格截图来说就没用了。Qwen-VL的第一个创新是448x448和接地边界盒输出，让模型指向事物。

视频：Video- llama堆叠每帧编码器并将它们馈送给LLM。它适用于短视频，而不适用于时间轴是信号的多分钟视频。Qwen团队想要一个能理解时间的编码器。

结构化输出：LLaVA发出自由格式的文本。代理需要JSON。Qwen-VL训练明确的JSON输出格式，包括边界框坐标作为文本。

每一代Qwen-VL都扩展了这三个轴中的一个。

## 这个概念

### Qwen-VL（2023年8月）

第一代：OpenCLIP vitg - bigg /14作为编码器（2.5B参数），llama兼容Q-Former（1步256查询），Qwen-7B基。贡献:

- 448 × 448分辨率（然后是SOTA的开放VLM）。
- 接地：使用显式坐标标记输出的图像-文本对进行训练。“猫在<框>(112、204),(280、344)< /框>”。
- 中英多语种培训从开始。

当时的基准：英语与GPT-4V相当，中文占优势。停飞监管才是真正的头条。

### Qwen2-VL（2024年9月）- M-RoPE和本机分辨率

Qwen2-VL用一个本地动态分辨率ViT编码器取代了固定分辨率+ Q-Former堆栈。主要变化:

- 本机动态分辨率。ViT接受任何可被28整除的HxW（补丁14与2x空间合并）。1120x672像素的图像（40x24合并的补丁）产生960个视觉标记。没有调整大小，没有平铺，没有缩略图。
- M-RoPE （Multimodal RoPE）。每个标记都带有3D位置（t, h, w），而不是1D。对于图像t=0，对于视频t= frame_index。RoPE按每个轴的频率旋转查询/键向量。没有位置嵌入表。
- 延时投影仪。放下Q-Former；对合并的补丁令牌使用2层MLP。
- 视频与动态FPS。视频采样在1-2 FPS默认，但模型接受任意帧数。

结果：Qwen2-VL-7B在几个多模式基准测试中与gpt - 40匹配，并在DocVQA上击败它（94.5 vs 88.4）。架构的改变是决定性的一步。

### Qwen2.5-VL（2025年2月）-动态FPS +绝对时间

Qwen2.5-VL的大转变是视频。动态FPS不只是“在需要的时候采样更多帧”。论文正式提出：

- 绝对时间符号。而不是位置索引（帧0,1,2…），使用实际的时间戳。“0点04分，猫跳了起来。”模型看到
- 动态FPS。慢镜头以1 FPS采样，动作以4+ FPS采样。用户或培训师选择；M-RoPE适应。
- ViT中的窗口注意。空间注意力是窗口（局部块内）的吞吐量；全球关注每隔几层。
- 显式JSON输出格式。培训tool-call数据:“{\“工具\”,\“点击\”,\“坐标\”:(380、220)}”。特工准备就绪。
- MRoPE-v2伸缩。位置与最大输入大小相匹配，因此10分钟的视频不会超出频率范围。

基准测试：Qwen2.5-VL-72B在大多数视频基准测试中击败了gpt - 40，在文档上匹配Gemini 2.0，并为GUI接地设置了开放模型SOTA （ScreenSpot: 84%的准确率，而gpt - 40的准确率为38%）。

### Qwen3-VL（2025年11月）

Qwen3- vl是一个渐进的升级，巩固而不是重新设计：更大的LLM主干（Qwen3- 72b），扩展的训练数据，改进的OCR，通过Qwen3“思维模式”进行更强的推理。ViT和M-RoPE留下来。本文关注的是数据和训练对体系结构的改进。

传承的收获：到2025年，Qwen-VL架构已经稳定下来。额外的代扩展计算和数据，而不是原语。

### M-RoPE数学

classic RoPE旋转查询

```
q_rot[2i]   = q[2i]   * cos(m * theta_i) - q[2i+1] * sin(m * theta_i)
q_rot[2i+1] = q[2i]   * sin(m * theta_i) + q[2i+1] * cos(m * theta_i)
theta_i     = 10000^(-2i/d)
```

M-RoPE将隐藏的光线分成三束。说将32个暗点分配给时间，32个分配给高度，32个分配给宽度。每个波段以自己的轴位置旋转。在（t=5, h=10, w=20）处的patch得到旋转

文本标记的使用视频帧使用单图像使用

好处：一个位置编码处理文本、图像和视频，而不需要分支代码或不同的位置表。

### 结构化代理输出

Qwen2.5-VL的代理训练明确针对结构化工具调用：

```
{
  "tool": "mouse_click",
  "coords": [1024, 512],
  "button": "left",
  "modifier": null
}
```

解析是确定性的：JSON。解析模型的输出。相比之下，自由格式的“click at（1024,512）”需要正则表达式和歧义处理。这就是为什么Qwen2.5-VL的ScreenSpot得分从Qwen2-VL的55%跃升至84%的原因。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| M-RoPE | "Multimodal RoPE" | 3D rotary position embedding with temporal, height, and width bands in the hidden dim |
| Dynamic FPS | "Smart sampling" | Frame sampling rate chosen per video based on motion, duration, and token budget |
| Absolute time token | "Timestamp token" | `<time>t</time>` interleaved in the sequence so the model sees actual seconds not frame index |
| Window attention | "Local attention" | Spatial self-attention restricted to small windows for speed; global attention added periodically |
| Structured agent output | "JSON mode" | Training data supervision teaching the VLM to emit parseable JSON with coords and tool names |
| min_pixels / max_pixels | "Resolution bounds" | Per-request Qwen2.5-VL controls bounding total pixel count and therefore token count |
| Grounding | "Point-at-it" | Outputting bounding-box coordinates as text tokens; used since Qwen-VL v1 |
