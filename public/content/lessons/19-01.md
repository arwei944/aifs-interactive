# 顶点01 -终端本地编码代理

> 到2026年，编码代理的形状就确定了。一个TUI线束，一个有状态的计划，一个沙盒工具表面，一个计划、行动、观察、恢复的循环。克劳德代码，游标3号和开放代码在50英尺外看起来都一样。这个顶点要求您构建一个端到端（CLI输入，pull request输出），并在sw -bench Pro上对mini-sw -agent和live -sw -agent进行测量。您将了解为什么困难的部分不是模型调用，而是工具循环，沙盒和50圈作业的成本上限。

**Type:** Capstone
**Languages:** TypeScript / Bun (harness), Python (eval scripts)
**Prerequisites:** Phase 11 (LLM engineering), Phase 13 (tools and protocols), Phase 14 (agents), Phase 15 (autonomous systems), Phase 17 (infrastructure)
**练习阶段：** P0·P5·P7·P10·P11·P13·P14·P15·P17·P18
**Time:** 35 hours

## 问题

编码代理在2026年成为主导的人工智能应用类别。《Claude Code》（Anthropic）、《Cursor 3》（带有Composer 2和Agent Tabs (Cursor)）、《Amp》（Sourcegraph）、《OpenCode》（112k stars）、《Factory Droids》和《谷歌Jules》都推出了相同架构的变体：终端线束、允许的工具表面、沙盒和围绕前沿模型构建的计划-行动-观察循环。边界很窄——Live-SWE-agent在经过Opus 4.5验证的SWE-bench上达到79.2%——但工程技术很广泛。大多数失效模式不是模型错误。它们是工具循环不稳定、上下文中毒、失控的令牌成本和破坏性的文件系统操作。

你不能从外部推断这些代理人。您必须构建一个，当ripgrep返回8MB匹配时，观察循环在第47回合崩溃，并重建截断层。这就是这个顶点的意义所在。

## 概念

线束有四个表面。**Plan**维护一个todowrite样式的状态对象，模型每轮重写一次。**Act**调度工具调用（读取，编辑，运行，搜索，git）。**观察**捕获标准输出/标准错误/退出代码，截断，并反馈摘要。**恢复**处理工具错误不吹上下文窗口或永远循环。2026年的形状增加了一个东西：**钩**。`PreToolUse`, `PostToolUse`, `SessionStart`, `SessionEnd`, `UserPromptSubmit`, `Notification`, `Stop`, and `PreCompact` — configurable extension points where the operator injects policy, telemetry, and guardrails.

沙盒是E2B或Daytona。每个任务都运行在一个新的devcontainer中，并将git工作树挂载为读写。这个工具永远不会触及主机文件系统。工作树会因成功或失败而被拆除。成本控制有三个层面：每回合令牌上限、每回合美元预算和硬回合限制（通常是50个）。可观察层是OpenTelemetry，它跨越了GenAI语义约定，并发布到一个自托管的Langfuse上。

## 构建它

1. **TUI和命令循环。**用墨水支撑Bun项目。接受打印分割视图：计划窗格（顶部），工具调用流（中间），令牌预算（底部）。在触发的Ctrl-C上添加取消

2. **计划状态。**def 一个类型化的TodoWrite模式（pending / in_progress / done）。模型将每个回合的完整状态重写为一个工具调用-不要让它增量地变化。坚持计划

3. **工具表面。**def 六个工具：在MCP StreamableHTTP上公开，这样线束是传输无关的。每个工具返回截断的输出（每次调用上限为4k令牌）。

4. **沙盒包装。**每个任务生成一个E2B沙盒。`git worktree add -b agent/$TASK_ID` a fresh branch. 所有的工具调用都在沙箱中执行。主机文件系统不可达。

## 练习

1. 将后台模型从Claude Sonnet 4.7切换到vLLM上的Qwen3-Coder-30B。比较pass@1和$-per-task。报告开放模型表现不佳的地方。

2. 添加一个测量假阳性评价是否会使SWE-bench的通过率低于单代理基线（提示：通常是）。

3. 对沙盒进行压力测试：编写一个尝试的任务确认两者都被PreToolUse钩子阻塞。记录这些尝试。

4. 实施测量在3倍压缩时损失了多少平面保真度。

5. 交换MCP StreamableHTTP传输为演播室。基准测试冷启动和每次调用延迟。选择一个仅在本地使用的赢家。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Harness | "The agent loop" | The code surrounding the model that dispatches tools, maintains plan state, and enforces budgets |
| Hook | "Agent event listener" | A user-authored script run on one of eight lifecycle events by the harness |
| Worktree | "Git sandbox" | A linked git checkout at a separate path; disposable without touching the main clone |
| TodoWrite | "Plan state" | A typed list of pending/in-progress/done items the model rewrites each turn |
| StreamableHTTP | "MCP transport" | 2026 MCP revision: long-lived HTTP connection with bidirectional streaming; replaces SSE |
| Token ceiling | "Context budget" | Per-turn or per-session cap on input+output tokens; triggers compaction or termination |
| pass@1 | "Single-attempt pass rate" | Fraction of SWE-bench tasks solved on the first run without retry or test-set peeking |
