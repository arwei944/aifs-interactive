# 投票、自一致性和辩论拓扑

> 最便宜的聚合：样本N个独立代理，多数投票。Wang et al. 2022自一致性用一个模型采样N次做到了这一点。多智能体扩展了它，使用异构智能体来逃避单一文化——不同的模型、不同的提示、不同的温度、不同的上下文。除了多数投票之外，辩论拓扑也很重要：MultiAgentBench （arXiv:2503.01935, ACL 2025）评估了星/链/树/图协调，发现**图最适合研究**，“协调税”超过4个代理。AgentVerse （ICLR 2024）记录了两种涌现模式——志愿者行为和从众行为——从众既是一种特征（寻求共识），也是一种风险（第24课，群体思维）。本课映射拓扑空间，构建每个变体，并测量协调税。

## 问题

辩论可以提高准确性（Du et al., arXiv:2305.14325）。它也可以降解它。辩论是否有帮助取决于四个结构性选择：

1. 谁与谁对话（拓扑）。
2. 多少轮（杜2023：轮和代理都是独立的）。
3. 代理是否异构（不同的基本模型打破了单一文化）。
4. 是否存在敌对的声音（钢铁工人vs.稻草工人）。

与单个代理相比，“运行5个代理并投票”的团队通常会倒退。失败不是随机的。它们跟踪拓扑结构和异构性。这一课是拓扑图。

## 概念

### 自一致性，单一模型基线

Wang et al. 2022（“自一致性改善思维链推理”）在温度为b>的情况下对同一模型进行了N次采样，并对推理路径的答案进行了多数投票。在GSM8K上的结果是：在单个贪婪解码中，N=40个样本获得了可观的收益。自一致性是多代理投票的单代理前身。

限制：自一致性使用一个基本模型。误差是按结构相关联的。如果模型有系统偏差，那么所有N个样本都有系统偏差。

### 多代理投票，异构扩展

用N *种不同的*剂代替N个样品。不同的基本模型（Claude， GPT, Llama），不同的提示，不同的工具访问。好处是：不相关的错误。成本：不同的药剂成本不同；协调它们会增加开销。

2026年异构辩论的规范名称是**A-HMAD**——对抗性异构多智能体辩论。虽然没有被普遍采用，但论文使用了“不同模式的辩论，这减少了单一文化崩溃带来的相关错误”这一术语。

### 四种拓扑

```
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           (fully connected)
```

明星：一个枢纽，其他所有人只对枢纽说话。相当于没有反向渠道的主管-工人。
链：线性，每个代理都看到前一个代理的输出。Pipeline-like。
树：分层的，由分层代理系统使用（第06课）。
图:任意对任意的。包括完全连接的集团和任意dag。

### 协调税（MultiAgentBench）

MultiAgentBench （MARBLE, ACL 2025, arXiv:2503.01935）在包括研究、编码和规划在内的任务套件上对星型、链型、树型、图型进行了基准测试。主要测量结果：

- **图**拓扑在研究任务中胜出。信息流从任何人到任何人；代理可以互相批评。
- ** **在快速回答事实性任务中获胜。集线器过滤和合并。
- **链**在逐步管道（分阶段优化）中胜出。
- **协调税**在图拓扑中显示过去~4个代理。挂钟和代币成本的增长速度快于质量。

4个代理的上限是经验性的，而不是根本性的。它反映了2026 LLM上下文容量：每个agent的上下文都充满了同伴的输出，当每个人都能看到每个人时，添加agent N+1的边际值就会下降。

### 多智能体辩论策略（“我们应该发疯吗？”）

arXiv:2311.17371是2023年MAD策略的调查。其他人重复的关键发现：当使用相同的预算时，与自一致性（独立抽样+聚合）“结构相似”的MAD变体通常表现不佳。当代理人是真正异构的，并且辩论具有对抗性结构（一个代理人反对）时，MAD最有帮助。

### AgentVerse紧急模式

AgentVerse （ICLR 2024, https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf）记录了两种从多智能体争论中出现的行为，即使没有明确的设计：

- * *志愿者。**代理会主动提供帮助（“我可以采取下一步”）。有用：它为子任务分配工作给最有能力的代理。
- * *。**智能体调整自己的姿态以匹配评论者，即使评论者是错误的。这是辩论中的阿谀奉承（第14课）。

一致性就是为什么“辩论到达成一致”会奖励恶霸。由单独法官进行的有限回合。

### 异质性：实际旋钮的移动精度

实用文献中的2024-2026模式：将N个代理中的一个交换为不同的基本模型，比将N增加1带来更大的准确性提升。直觉是单一文化——每一个新的独立误差源都比一个额外的相关样本更有价值。

在极限情况下，异质性胜过数量。在大多数任务中，三个不同的模型胜过一个模型的五个副本。

### 陪审团的方法

Sibyl框架（在Minsky-LLM文献中被引用）正式定义了一个“陪审团”——一组专门的代理，通过在每个阶段投票来改进答案。与简单的多数投票不同，陪审团有自己的角色：一名代理人交叉询问，一名提供背景，一名评估合理性。陪审团的方法是介于普通投票（便宜，倾向于单一文化）和完全MAD（昂贵，倾向于从众）之间的中间点。

### 当辩论投票占主导地位时

- 这个问题具有基本事实（事实、数学、代码行为）。投票趋同是有意义的。
- 代理可以访问不同的源或工具（异构性是可用的）。
- 回合是有限的（典型的2-3轮），并且有一个单独的裁判或验证者。
- 预算允许3-5名代理。在图拓扑5-7以上，协调税占主导地位。

### 当辩论式投票受到伤害时

- 这个问题是由观点决定的。智能体收敛于看起来最自信的答案，而不是最正确的答案。
- 所有代理共享一个基本模型。单一文化使共识变得毫无意义。
- 圆是无限的。循规蹈矩总是胜利的。
- 任务很简单。在N=5时具有自稠度的单一药剂更便宜，也同样准确。

## 船这

对于任何组合：

- 从N=5时的**自洽开始，使用一个强基础模型。这是一个廉价的基准。
- 如果准确性重要，升级到**异构投票在N=3**。测量delta。
- 只有当任务具有结构（研究，多步骤）且有界回合可行时，才升级到**辩论拓扑**。
- 始终记录少数派集群。当少数人始终正确时，你就得到了多元化的信号。
- 基准挂钟和代币以及准确性。“以10倍的成本提高准确性”是一个商业决策。

## 练习

1. 运行绘制图拓扑的协调税曲线：精度vs N，令牌vs N。曲线在多少N处发生弯曲？
2. 实现A-HMAD：三个具有故意不同偏差的代理。在第14课的单一文化攻击中，全同偏差基线与A-HMAD相比如何？

4. 阅读AgentVerse论文（ICLR 2024）。确定您的实现表现出最强烈的紧急行为。你能通过一个迅速的改变引起相反的行为吗？
5. 阅读MultiAgentBench （arXiv:2503.01935）第4节（拓扑实验）。用你的工具在论文中的一个任务上重现“图表胜研究”的结果。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Self-consistency | "Sample N times, vote" | Wang 2022. Single model, N temperature>0 samples, majority vote on reasoning paths. |
| Heterogeneity | "Different models" | Ensemble of different base models or prompt families. Breaks monoculture. |
| MAD | "Multi-agent debate" | Generic term for agents exchanging critiques over rounds. See Du 2023. |
| A-HMAD | "Adversarial Heterogeneous MAD" | MAD variant emphasizing different models + adversarial structure. |
| Topology | "Who talks to whom" | Star, chain, tree, graph. Determines information flow. |
| Coordination tax | "Diminishing returns" | Above ~4 agents on graph, cost grows faster than quality. |
| Volunteer behavior | "Unprompted help" | AgentVerse emergent pattern: an agent offers to take a step. |
| Conformity behavior | "Agreement under pressure" | AgentVerse emergent pattern: an agent aligns with a critic. |
| Jury | "Small specialized panel" | Sibyl-style ensemble with roles (examiner, context, scorer). |
