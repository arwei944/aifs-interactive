# Audio classification - from k-NN on mfc to AST and BEATs

## This question

You get a 10-second clip. You want to know: "What is this?" Urban sounds (sirens, drill sounds, dog barking), voice commands (yes/no/stop), language signs (en/es/ar), the speaker's mood (anger/neutral) or environmental sounds (indoor/outdoor, babbling). All of these are * audio classifications *, and the baseline architecture in 2026 is mature: log-mel→CNN or Transformer→softmax.

The core difficulty is not the network. It is data. The audio dataset features severe category imbalance, strong domain shift (clean vs. noisy), and label noise (who decides "urban noise" vs. "restaurant noise"?) 80% of the problems lie in management, enhancement and evaluation, rather than replacing CNNS with Transformers.

## This concept

Z0

*k-NN based on mfc (baseline of the 1990s). Tile out the mfc of each fragment, calculate the cosine similarity to the marker library, return the majority of votes in the top k, surprisingly powerful on clean small datasets (Speech Commands, ESC-50). No GPU running.

*2D CNN on log-meels (2015-2019). ResNet-18 or VGG-style should be used for treatment. The timeline of the global average pool. Softmax exceeds the class. It remains the bottom line for most competitions in 2026.

*Audio spectrum converter, AST (2021-2024). Patch logs (such as 16×16 patches), add location embeddings, and feed them to the ViT. The latest technology of AudioSet (mAP 0.485) for supervised learning.

*BEATs and WavLM-base (2024-2026). Millions of hours of self-supervised pre-training. Fine-tune your task with 1-10% of the supervised data you need. In 2026, this will be the default starting point for non-voice audio. beat -iter3 defeated AST 1-2 mAP on AudioSet while using 1/4 of the calculation.

*Whisper encoder as the backbone of freezing (2024). Adopt the encoder of Whisper, abandon the decoder, and add a linear classifier. In the case of zero audio enhancement, the language ID and simple event classification are close to sota. The bottom line of "free lunch".

### Class imbalance is the real challenge

ESC-50: 50 types, 40 clamps each balanced, easy. UrbanSound8K: 10 categories, imbalance 10:1. AudioSet: 632 classes, 100,000:1 long tail. Effective techniques

- Balance sampling during training (not in assessment).
- Mix: Linearly interpolate two clips (and their labels) as an addition.
- SpecAugment: Mask random time and frequency band. Simple; Of vital importance.

### "Evaluation

- Multi-category dedicated (voice command) : Top 1 in accuracy, top 5 in accuracy.
- Multiclass multi-label (AudioSet, UrbanSound style) : Average precision (mAP).
- Severe imbalance: Each type of recall + macro F1.

### Step 2: fixed-length summary

```python
def summarize(mfcc_frames):
    n = len(mfcc_frames[0])
    mean = [sum(f[i] for f in mfcc_frames) / len(mfcc_frames) for i in range(n)]
    var = [
        sum((f[i] - mean[i]) ** 2 for f in mfcc_frames) / len(mfcc_frames) for i in range(n)
    ]
    return mean + var
```

Simple yet powerful: The variation of the mean and variance over time gives a 26-point fixed embedding of the 13-coefficient MFCC. Run immediately. In the most recent 2017, it surpassed the state-of-the-art NN baseline on ESC-50.

### Step 4: upgrade to CNN on log-mels

In PyTorch:

```python
import torch.nn as nn

class AudioCNN(nn.Module):
    def __init__(self, n_mels=80, n_classes=50):
        super().__init__()
        self.body = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
        )
        self.head = nn.Linear(128, n_classes)

    def forward(self, x):  # x: (B, 1, T, n_mels)
        return self.head(self.body(x).flatten(1))
```

3 m parameters. On the ESC-50 train, using a single RTX 4090, it takes approximately 10 minutes. + 80% accuracy.

## Use It

The 2026 stack:

| Situation | Start with |
|-----------|-----------|
| Tiny dataset (<1000 clips) | k-NN on MFCC means (your baseline) + audio augmentation |
| Medium dataset (1K–100K) | BEATs or AST fine-tune |
| Large dataset (>100K) | Train from scratch or fine-tune Whisper-encoder |
| Real-time, edge | 40-MFCC CNN, quantized to int8 (KWS-style) |
| Multi-label (AudioSet) | BEATs-iter3 with BCE loss + mixup + SpecAugment |
| Language ID | MMS-LID, SpeechBrain VoxLingua107 baseline |

Decision rule: **start with a frozen backbone, not a fresh model**. Fine-tuning a BEATs head gets you 95% of SOTA in hours, not weeks.

## Key Terms

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| AudioSet | The ImageNet of audio | Google's 2M-clip, 632-class weakly-labeled YouTube dataset. |
| ESC-50 | Small classification benchmark | 50 classes × 40 clips of environmental sounds. |
| AST | Audio Spectrogram Transformer | ViT on log-mel patches; 2021 SOTA. |
| BEATs | Self-supervised audio | Microsoft model, iter3 leads AudioSet as of 2026. |
| Mixup | Pair augmentation | `x = λ·x1 + (1-λ)·x2; y = λ·y1 + (1-λ)·y2`. |
| SpecAugment | Mask-based augmentation | Zero-out random time and frequency bands of the spectrogram. |
| mAP | Main multi-label metric | Mean average precision across classes and thresholds. |
