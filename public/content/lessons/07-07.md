## This question

The language model answers a question: Given the first question, train this signal - for the next label prediction - and you get a model that can generate any text with one label at a time.

To perform end-to-end parallel training on the entire sequence, you need that the prediction of each position only depends on the previous position. Otherwise, the model will cheat by looking at the answers.

This is how the cause-and-effect mask works. It is an upper triangular matrix. After softmax, these positions become 0. Each position can only focus on itself and the positions in front. Because you applied it to the entire sequence once, you obtained N parallel predictions of the next tag in one forward pass.

GPT-1 (2018), GPT-2 (2019), GPT-3 (2020), GPT-4 (2023), GPT-5 (2024), Claude, Llama, Qwen, Mistral, DeepSeek, Kimi - they are all causal transformers with only decoders. Have the same core circuit. Just larger, better data and better RLHF.

## This concept


### Mask

Given a sequence of lengths

```
M[i, j] = 0       if j <= i
M[i, j] = -inf    if j > i
```

"Add Note that each row of the matrix represents the probability distribution of the previous position.

Implementation cost: 1. Computing time: nanoseconds. The impact on this field: everything.

### Parallel training, serial reasoning

Training: The full prequel is parallel to the sequence. This is why the GPT training scale - you batch process 1M tokens in one GPU pass.

Inference: You generate each token one by one. The hidden state saved in the KV cache of feed feed feed feed (Lesson 12) but the serial depth during reasoning = output length. This is the autoregressive tax, and it is also why decoding is the latency bottleneck for every LLM.

### Decoding strategy

After training, sampling selection is more important than people think.

| Method | What it does | When to use |
|--------|--------------|-------------|
| Greedy | Argmax every step | Deterministic tasks, code completion |
| Temperature | Divide logits by T, sample | Creative tasks, higher T = more diversity |
| Top-k | Sample from top-k tokens only | Kills low-probability tails |
| Top-p (nucleus) | Sample from smallest set with cumulative prob ≥ p | 2020+ default; adapts to distribution shape |
| Min-p | Keep tokens with `p > min_p * max_p` | 2024+; better at rejecting long tails than top-p |
| Speculative decoding | Draft model proposes N tokens, big model verifies | 2–3× latency reduction at same quality |

In 2026, a min-p + temperature of 0.7 is a reasonable default value for the open-weight model. Speculative decoding is the table bet of any production inference stack.

## Build it

### Step 1: Cause-and-Effect Mask

See one line of program:

”“python
Def causal_mask (n)：
[0.0 if j <= I else float("-inf") for j in range(n)] for I in range(n)]
```

Add it to attention scores before softmax. That's the entire mechanism.

### Step 2: a 2-layer GPT-ish model

Stack two decoder blocks (masked self-attention + FFN, no cross-attention). Add a token embedding, a positional encoding, and an unembedding (tied to the token embedding matrix — a standard trick since GPT-2).

### Step 3: next-token prediction, end-to-end

On a 20-token toy vocab, produce logits at every position. Compute cross-entropy loss against the shift-by-one target. No gradient — this is a forward-pass sanity check.

### Step 4: sampling

Implement greedy, temperature, top-k, top-p, min-p. Run each on a fixed prompt and compare outputs. A sampling function is 10 lines.

## Use It

PyTorch, 2026 idiom:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")
tok = AutoTokenizer.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")

prompt = "Attention is all you need because"
inputs = tok(prompt, return_tensors="pt")
out = model.generate(
    **inputs,
    max_new_tokens=64,
    temperature=0.7,
    top_p=0.9,
    do_sample=True,
)
print(tok.decode(out[0]))
```

Under the hood, each production LLM inference stack (vLLM, TensorRT-LLM, llama.cpp, Ollama, MLX) achieves the same loop-batch pre-filling, continuous batch processing, KV cache paging, and speculative decoding through extensive optimization.

## Key terms

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Causal mask | "The triangle" | Upper-triangular `-inf` matrix added to attention scores so position `i` only sees positions `≤ i`. |
| Next-token prediction | "The loss" | Cross-entropy of the model's distribution against the true next token at every position. |
| Autoregressive | "Generate one at a time" | Feed output back as input; parallelism only during training, not during generation. |
| Logits | "Pre-softmax scores" | Raw output of the LM head before softmax; sampling happens on these. |
| Temperature | "Creativity knob" | Divide logits by T; T→0 = greedy, T→∞ = uniform. |
| Top-p | "Nucleus sampling" | Truncate distribution to smallest set summing to ≥p; sample from what remains. |
| Min-p | "Better than top-p" | Keep tokens where `p ≥ min_p × max_p`; adapts cutoff to sharpness of distribution. |
| Speculative decoding | "Draft + verify" | Cheap model proposes N tokens; big model verifies in parallel. |
| Teacher forcing | "Training trick" | During training, feed the true previous token, not the model's prediction. Standard for every seq2seq LM. |
