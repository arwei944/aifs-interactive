# 间接提示注入-生产攻击面

> 间接提示注入（IPI）将指令嵌入到外部内容（网页、电子邮件、共享文档、支持票据）中，由代理系统在没有明确用户操作的情况下使用。IPI是2026年主要的生产威胁：它绕过用户输入过滤器，因为攻击者从不接触用户，它在代理处理更多外部内容时无声地扩展，并且它针对没有人读取提示的自动化工作流。MDPI Information 17(1):54 （January 2026）综合2023-2025年的研究。NDSS 2026的知识产权防御文件提出了核心挑战：注入的指令可能在语义上是良性的（“请打印Yes”），因此检测需要的不仅仅是关键字过滤。“The attack Moves Second”（Nasr等人，OpenAI/Anthropic/DeepMind联合出版，2025年10月）：自适应攻击（梯度、强化学习、随机搜索、人类红队）在12个已发布的防御中突破了90%，而这些防御最初报告的攻击成功率接近于零。

## 这个问题

直接提示注入要求攻击者到达用户或其提示符。IPI都不需要：攻击者在代理可能读取的任何内容中放置有效载荷-网页，收件箱中的电子邮件，GitHub问题，产品评论。代理在正常操作期间拾取它并执行指令。用户是信使，而不是意图。

## 这个概念

### 三种传递载体

- **检索增强生成（RAG）。**攻击者发布文档；检索步骤获取它；提示符将它连接在用户问题之前；模型执行攻击者的指令。
- **收件箱/文档工作流。**攻击者向用户发送电子邮件；代理人阅读电子邮件；提示符包括电子邮件正文；模型遵循电子邮件的说明。
- **工具输出。**攻击者控制代理使用的工具（例如，返回攻击者控制结果的web搜索）；工具输出包含指令；代理的控制流遵循它们。

这三者共享一个结构属性：攻击者控制提示符的片段，而不触及面向用户的输入。

### 为什么用户输入过滤器漏掉了它

IPI有效负载不会出现在用户的输入中。它出现在检索到的内容中。如果过滤器对用户输入进行了门控，则有效负载将绕过它。如果过滤器对到达模型的所有内容进行门控，则它必须应用于任意检索的文本—这是昂贵的，并且对碰巧包含命令式语音语言的合法内容产生误报。

### AI的信息流控制（IFC）

2026防御范例借鉴了经典的操作系统安全性。将每个内容源视为安全标签。将用户的查询标记为“可信”。将检索到的内容标记为“不可信”。将模型的控制流视为信息流：由不受信任的内容触发的操作必须在执行之前由受信任的输入批准。

CaMeL (Microsoft 2025), ConfAIde （Stanford 2024）和NDSS 2026知识产权防御文件以不同的方式运作IFC。共同的原则是：只要代码和数据共享相同的上下文窗口，目标就是遏制，而不是预防。

### 攻击者紧随其后

Nasr等人（2025年10月）使用自适应攻击（梯度搜索、RL策略、随机搜索、72小时人类红队）测试了12种已发表的IPI防御。每一个最初报告接近零ASR的防御都被打破到90% ASR。

方法论上的教训是：只发布带有适应性攻击评估的防御。静态攻击基准测试不是鲁棒性的证据；攻击者了解了防御者。

OWASP LLM Top 10（2025）将提示注入（直接+间接）列为LLM01，排名第一的应用层威胁。NIST AI SPD 2024将间接提示注入称为“生成式人工智能最大的安全漏洞”。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| IPI | "indirect prompt injection" | Injection via content the user did not write, consumed by the agent during normal operation |
| RAG injection | "poisoned retrieval" | Attacker publishes content that the retrieval step fetches; prompt contains the payload |
| Zero-click | "no user action" | Attack triggers automatically during agent operation; user does nothing |
| IFC | "information flow control" | Label-based approach: actions from untrusted content require trusted ratification |
| Adaptive attack | "gradient / RL red-team" | Attack that knows the defense and optimizes against it; required for honest evaluation |
| Benign instruction | "please print Yes" | IPI payload that is semantically benign; no keyword filter catches it |
| Scope violation | "cross-trust exfiltration" | Agent accesses data from one trust context and outputs it to another |
