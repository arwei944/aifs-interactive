## 这个问题

浏览器代理是一个长期代理，它读取不受信任的内容并采取相应的操作。代理访问的每个页面都是用户没有写入的输入。每个页面上的每个表单都是一个潜在的命令通道。2025-2026年的攻击语料库表明这不是假设：受污染的记忆让攻击者通过精心制作的页面将恶意指令绑定到代理的内存；HashJack将命令隐藏在代理访问的URL片段中；困惑彗星劫持命中在一个单一的点击。

防守的局面令人不安。OpenAI的准备负责人说，安静的部分很响亮：间接提示注射“不是一个可以完全修补的漏洞”。这是因为攻击存在于代理的读取vs行为边界中，该边界在架构上是模糊的——原则上，模型读取的每个令牌都可以作为指令读取。

本课命名了攻击面，命名了基准景观（BrowseComp, OSWorld, WebArena-Verified），并建模了最小的间接提示注入场景，以便您可以在第14和18课中推断真正的防御。

## 这个概念

### 2026年的景观，每个系统一段

**ChatGPT代理（OpenAI）。** 2025年7月推出。统一操作员（浏览）和深度研究（多小时研究）。2025年8月31日关闭独立运营商。BrowseComp的SOTA为68.9%；在OSWorld和WebArena-Verified上有很强的数字。

**克劳德十四行诗+ Vercept （Anthropic）。** Anthropic对Vercept的收购侧重于计算机使用能力。将Claude Sonnet在OSWorld上的排名从<15%移动到72.5%。Claude Computer Use作为工具API发布。

**双子座3 Pro浏览器使用（DeepMind）。**浏览器使用集成提供计算机使用控制；FSF v3（2026年4月，第20课）专门跟踪机器学习研发领域的自主性。

**WebArena-Verified （ServiceNow, ICLR 2026）。**修复了一个有案可查的问题：原来的WebArena有~11.3%的假阴性率（标记失败的任务实际上已经解决）。经过验证的版本根据人工策划的成功标准重新评分，并增加了一个258个任务的硬子集（ICLR 2026论文，openreview.net/forum?id=94tlGxmqkN）。

### 浏览器泵vs OSWorld vs WebArena

| Benchmark | What it measures | Horizon |
|---|---|---|
| BrowseComp | Finding specific facts on the open web under time pressure | minutes |
| OSWorld | Agent operating a full desktop (mouse, keyboard, shell) | tens of minutes |
| WebArena-Verified | Transactional web tasks in simulated sites | minutes |
| Hard subset | WebArena-Verified tasks with multi-page state transitions | tens of minutes |

不同的轴。BrowseComp得分高说明代理发现了事实；它没有说代理可以预订航班。OSWorld的得分更接近于“它在我的桌面上是否工作”。WebArena-Verified更接近于“它能否完成一个流程”。任何生产决策都需要与任务分布匹配的基准。

### 攻击面，命名为

1. **间接提示注射。**不受信任的页面内容包含说明。代理读取它们。代理执行它们。公开的例子：2024年Kai Greshake等人，2025年污点记忆论文，2026年HashJack （Cato Networks）。
2. **URL片段/查询注入。**不明显的；仍然在代理的上下文中。
3. * * Memory-binding攻击。Page指示代理写一个持久内存（第12课涉及持久状态）。下一个会话，内存在没有可见触发器的情况下触发有效负载。
4. **对认证会话进行csrf型攻击。**受污染的记忆类：代理登录在某个地方；攻击者的页面发出状态更改请求，代理使用用户的cookie执行。
5. * *一键劫持。**一个视觉上无害的按钮骑一个有效载荷的代理遵循。彗星类。
6. 代理主机表面的Content-Security-Policy漏洞。**渲染层和工具层本身可以是攻击向量；浏览器中的浏览器代理栈很宽。

### 为什么“不能完全修补”

攻击与代理的能力是同构的。代理必须读取不受信任的内容才能完成其工作。代理读取的任何内容都可能包含指令。代理所遵循的任何指令都可能与用户的实际请求不一致。防御（信任边界，分类器，工具允许列表，后续行动的HITL）提高攻击成本并减小其爆炸半径。他们不关门。

这与Lob定理（第8课）的推理模式相同：代理不能证明下一个令牌是安全的；它只能建立一个更容易检测到不安全令牌的系统。

### 实际上是防御姿态

- **读写边界。阅读从来不是结果性的。如果初始内容来自信任边界之外，则编写（提交表单、发布内容、调用具有副作用的工具）需要新的人工批准。
- **每个任务的工具允许列表。**代理可以浏览；除非为该任务显式启用了该工具，否则它无法启动电汇。第13课涉及预算。
- * *会话隔离。**浏览器代理会话仅使用限定范围的凭据运行。没有生产授权，没有个人邮箱。保留每个HTTP请求的日志以供审计。
- * *内容洗手液。**获取的HTML在连接到模型上下文之前会剥离已知的错误模式。（减少简单的攻击；不能阻止复杂的有效载荷。）
- **HITL对相应的行动。提议-提交模式（第15课）。
- **内存上的金丝雀标记。**如果一个内存条目被触发，用户会看到它（第14课）。

1. 运行确定杀毒程序捕获了哪些攻击，而读写边界没有捕获，哪些攻击仅捕获了读写边界。

## 关键术语

| Term | What people say | What it actually means |
|---|---|---|
| Indirect prompt injection | "Bad page text" | Untrusted content in a page the agent reads contains instructions the agent executes |
| Tainted Memories | "Memory attack" | Agent writes an attacker-supplied instruction to durable memory; triggered next session |
| HashJack | "URL fragment attack" | Payload hidden in URL fragment / query string is in the agent's context but not visibly rendered |
| One-click hijack | "Bad button" | Visible affordance rides a follow-on payload the agent executes |
| BrowseComp | "Web search benchmark" | Finding specific facts on the open web; minute-scale horizon |
| OSWorld | "Desktop benchmark" | Full OS control; multi-step GUI tasks |
| WebArena-Verified | "Fixed web-task benchmark" | ServiceNow's regraded WebArena with Hard subset |
| Read/write boundary | "Side-effect gate" | Reading never consequential; writing requires fresh approval if content is out-of-trust |
