# 从CLIP到BLIP-2 - Q-Former作为模态桥

> CLIP将图像和文本对齐，但不能生成标题、回答问题或进行对话。BLIP-2 （Salesforce, 2023）用一个小的可训练桥解决了这个问题：32个可学习的查询向量通过交叉注意参加冻结的ViT的特征，然后直接进入冻结的LLM的输入流。11B LLM与ViT-g/14连接的桥接参数为188M。到2026年，每一个基于适配器的VLM——miniigpt -4、instructlip、LLaVA的表亲——都是它的后代。本课阅读了Q-Former的架构，解释了它的两阶段训练，并构建了一个玩具版本，将视觉标记输入冻结的文本解码器。

**Type:** Build
**Languages:** Python (stdlib, cross-attention + learnable-query demo)
**Prerequisites:** Phase 12 · 02 (CLIP), Phase 7 (Transformers)
**Time:** ~180 minutes

## 学习目标

- 解释为什么冻结视觉编码器和冻结LLM之间的可训练瓶颈在成本和稳定性方面优于端到端微调。
- 实现一个交叉注意块，其中一组固定的可学习查询关注外部图像特征。
- 通过BLIP-2的两阶段预训练：表示（ITC + ITM + ITG）然后生成（LM损失与冻结解码器）。
- 将Q-Former与LLaVA中使用的更简单的MLP投影仪进行比较，并讨论每种选择何时胜出。

## 这个问题

您有一个冻结的ViT，每个图像产生256个dim1408的补丁令牌。您有一个冻结的7B LLM，它期望标记嵌入为dim 4096。显而易见的桥接——从1408到4096的线性层——可以工作，但是将所有256个补丁令牌放入LLM的上下文中需要为每个图像额外花费256个令牌。在一批32个图像中，仅视觉形式就消耗了8192个令牌。

BLIP-2问题：您能否将256个令牌的图像表示压缩为更少的令牌（比如32个），同时保留足够的信息，以便LLM对图像进行说明、回答问题和推理？你能在不接触冷冻骨架的情况下训练这座桥，使训练成本保持在桥的参数范围内吗？

答案是：Q-Former。32个可学习的“查询”向量交叉关注ViT的补丁令牌，产生LLM使用的32个令牌可视化摘要。参数总数为188M。在接触LLM之前，训练对比，匹配和生成目标。

## 这个概念

### 可学的查询

Q-Former的核心技巧：不是让LLM的文本令牌处理图像补丁，而是引入一组新的32个可学习的查询向量查询是模型的参数——它们是在训练过程中学习的，每个图像都使用相同的32个查询。

在交叉关注之后，每个查询都会保存图像的压缩摘要——“描述主要对象”、“描述背景”、“计算对象数量”等。这些查询并不专门化于语义标签；他们学习任何能降低下游损失的编码。

### 体系结构

Q-Former是一种小型Transformer（12层，~100M参数），有两条路径：

1. 查询路径：32个查询向量流经自关注（它们之间），然后在冻结的ViT补丁令牌上交叉关注，然后是FFN。
2. 文本路径：类似bert的文本编码器与查询路径共享自关注和FFN权重。文本路径禁止交叉注意。

在训练时，两条路径都运行。查询和文本通过共享的自关注进行交互，这意味着查询可以以需要它的任务的文本为条件（ITM、ITG）。在VLM切换的推理时，只有查询通过，产生32个视觉标记。

### 两级培训

BLIP-2预训练分为两个阶段：

阶段1：表征学习（非LLM）。三个损失:
- ITC（图像-文本对比）：池查询令牌和文本CLS令牌之间的clip风格对比。
- ITM（图像-文本匹配）：二进制分类器-这个图像-文本对匹配吗？Hard-negative-mined。
- ITG（基于图像的文本生成）：基于文本的因果LM，以查询为条件。强制查询编码可生成文本的内容。

只有Q-Former列车。ViT被冻结。不涉及LLM。

第二阶段：生成性学习。附上冷冻LLM （OPT-2.7B或Flan-T5-XL等）。通过一个小的线性层将32个查询输出投影到LLM的嵌入dim中。将它们添加到文本提示符前。只训练线性投影和Q-Former在连接的提示+图像+标题序列上的LM损失。

在第2阶段之后，Q-Former +投影是完整的视觉适配器。在推理时：图像→ViT→Q-Former→线性投影→前置到文本→冻结LLM输出。

### 经济参数

blp -2与viti -g/14 （1.1B，冷冻）+ OPT-6.7B （6.7B，冷冻）+ Q-Former （188M，训练）=共8B，训练188M。Q-Former仅占全栈参数的约2.4%。培训成本反映了这一点：在几个a100上花几天时间，而在端到端上花几周时间。

质量：在零射击VQA上，BLIP-2可以匹配或击败Flamingo-80B，但尺寸要小50倍。桥还能用。

### instructlip和指令感知Q-Former

instructlip（2023）用一个额外的输入扩展了Q-Former：指令文本本身。在交叉注意时间，查询现在可以访问图像补丁和指令。这些查询可以专门处理每条指令（“数汽车”、“描述心情”），而不是学习单一的固定摘要。搁置任务的基准收益。

### minipt -4和仅限投影仪的方法

MiniGPT-4保留了Q-Former，但只训练了输出线性投影，而冻结了其他一切。便宜，但成本就是质量——查询是BLIP-2的，不是你的。有利于快速迭代，而不是最好的架构。

### 为什么LLaVA更简单

LLaVA（2023，第12.05课）用一个普通的2层MLP取代了Q-Former，该MLP将每个ViT补丁令牌投影到LLM空间中-每个图像576个令牌用于24x24网格，全部馈送到LLM。更糟糕的压缩，但让LLM关注原始补丁。这在当时是有争议的；到2023年底，它占据主导地位，因为视觉指令数据（llva - instruction -150k）证明了MLP可以被训练以保留足够的信号。权衡：LLaVA的上下文填充速度更快，但它可以自然地扩展到多图像和视频。

到2026年，领域分裂：Q-Former在token预算重要的领域生存（长视频，多图像）；MLP投影仪在每个令牌的原始质量优先的地方占主导地位。

### 交叉注意：火烈鸟，祖先

火烈鸟（第12.04课）早于BLIP-2，并使用相同的交叉注意的想法，但在每个冻结LLM层，而不是作为一个单一的桥。BLIP-2表明，只压缩到输入层仍然可以工作。Gemini和ideics结合了这两者：交错输入令牌加上可选的上下文少数镜头的门控交叉注意。

### 2026年的后代

- Q-Former: BLIP-2, instructlip, MiniGPT-4，以及大多数视频语言模型，因为预算原因。
- 感知器重新采样器：火烈鸟的变体（第12.04课）；代表家庭，鹰，全能。
- MLP projector: LLaVA, LLaVA-NeXT, LLaVA-OneVision, Cambrian-1.
- 关注对象：VILA， PaliGemma。

这四个都是有效的。决定性的问题是您是否受到令牌预算或每个令牌质量的限制。

## 使用它


1. 模拟256个图像补丁令牌（dim 128）。
2. 实例化32个可学习查询（dim 128）。
3. 运行缩放点积交叉关注（Q来自查询，K/V来自补丁）。
4. 项目到LLM-dim（512）通过一个线性层。
5. 输出32个llm就绪的可视令牌。

所有数学都是纯Python的（向量上的嵌套循环）。玩具但形状正确。注意权重矩阵被打印出来，这样您就可以看到每个查询是从哪个补丁中提取的。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Q-Former | "Querying transformer" | Small transformer with 32 learnable query vectors that cross-attend to frozen ViT features |
| Learnable queries | "Soft prompt for vision" | A fixed set of parameters that serve as the query side of cross-attention; learned per model, shared across all inputs |
| Cross-attention | "Q from here, K/V from there" | Attention where query, key, and value come from different sources; how the queries pull from ViT patches |
| ITC | "Image-text contrastive" | CLIP-style loss applied to Q-Former pooled queries vs text CLS |
| ITM | "Image-text matching" | Binary classifier on hard-negative-mined pairs; forces the queries to discriminate fine-grained mismatches |
| ITG | "Image-grounded text generation" | Causal LM loss where text is generated conditioned on queries; forces queries to encode text-decodable content |
| Two-stage pretraining | "Representation then generative" | Stage 1 trains Q-Former alone (ITC/ITM/ITG); Stage 2 attaches frozen LLM and trains only the projection + Q-Former |
| Frozen backbone | "Do not finetune" | The vision encoder and LLM weights are fixed; only the bridge trains |
| Projection head | "Linear to LLM dim" | Final linear layer mapping Q-Former output to the LLM's embedding dimension |
| Perceiver resampler | "Flamingo's version" | Similar learnable-query cross-attention, used by Flamingo at every layer rather than as a single bridge |
