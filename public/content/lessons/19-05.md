# 顶点05 -自主研究代理（AI-Scientist班）

> Sakana的AI-Scientist-v2发表了完整的论文。实验室特工进行了实验。Allen AI分享了这些痕迹。2026年的形状是对实验的计划-执行-验证树搜索、预算成本、沙盒代码执行、视觉反馈LaTeX编写器和自动neurips风格的审阅器集合。最终目标是构建一个，端到端运行它，每篇论文的成本不超过30美元，并在Sakana记录的沙箱逃生红队中幸存下来。

**Type:** Capstone
**Languages:** Python (agent + sandbox), LaTeX (output)
**Prerequisites:** Phase 2 (ML), Phase 3 (deep learning), Phase 7 (transformers), Phase 10 (LLMs from scratch), Phase 14 (agents), Phase 15 (autonomous), Phase 16 (multi-agent), Phase 18 (safety)
**运行阶段：** P0·P2·P3·P7·P10·P14·P15·P16·P18
**Time:** 40 hours

## 问题

自主研究机构在2026年跨过了门槛。Sakana AI的AI- scientist -v2发表在《自然》杂志上，其生成的论文通过了研讨会的同行评审。ShinkaEvolve （ICLR 2026）将这条线扩展到进化假设。AMD的代理实验室运送了可重复的痕迹。代理不是魔法——它们是一个计划-执行-验证循环，运行在候选实验树上，具有成本上限、种子绑定沙箱和自动审查。飞船在循环中，预算和安全故事。

您可以通过在一个狭窄的领域(例如，在一个100m参数的Transformer上实现一个针对种子想法的循环来学习这个循环。它的价值不在于第一次运行就发现新的东西。其价值在于基础结构：树状搜索、实验沙盒、作者-评论者循环、红队报告。Sakana团队记录了沙盒逃脱失败；你的特工必须通过同一个红队。

## 概念

agent是最佳优先树搜索。节点为实验规范：（假设、配置、代码、预期结果）。扩展步骤建议使用小编辑（交换优化器，更改批大小，删除组件）的子进程。每个子节点都在一个具有硬资源上限的新鲜沙盒中运行。结果反馈到一个评分函数中，该函数根据（新颖性×质量×剩余预算）对节点进行排名。这棵树一直生长，直到预算耗尽，然后最好的树枝被写下来。

作者是多面手。它生成LaTeX草稿，对其进行编译，呈现图形，并将呈现的PDF反馈给Claude Opus 4.7的视觉模式，以对布局、图形易读性和索赔-证据对齐进行评论。由五位LLM评委组成的评审团给出neurips风格的评分（新颖性、严谨性、清晰度、可重复性、影响力）；如果平均值低于阈值，论文就会返回给作者进行评论。

安全是承载的。每个实验都在E2B或Daytona沙盒中运行，没有网络出口，有边界的挂钟和固定的资源限制。代理的代码生成步骤通过一个策略层，该策略层阻止逃离沙箱的系统调用。红队报告重现了sakana记录的攻击面（分叉炸弹、文件系统转义、llm编写的网络调用）。

```
seed idea + domain
      |
      v

      |
      v
  LangGraph plan-execute-verify tree
      |
      v
  +--- expand node ----+      per-node sandbox
  |                    |      (E2B / Daytona)
  v                    v      resource caps
  child_1           child_k   no network egress
  |                    |      deterministic seeds
  v                    v
  run experiment       run experiment
  |                    |
  v                    v
  score nodes by (novelty, quality, budget)
      |
      v
  best branch -> LaTeX writer
      |
      v
  compile + vision critique (Opus 4.7 vision)
      |
      v
  reviewer ensemble (5 LLM judges, NeurIPS rubric)
      |
      v
  paper.pdf + review.md + trace.json
```

## 堆栈

- 编制：带有检查点和人工审批门的语言图
- 树搜索：自def 最佳优先实验节点（来自Sakana v2的ab - mcts风格）
- 沙盒：每个实验E2B， Docker-in-Docker回退；通过组设置资源上限
- 文献：Semantic Scholar Graph API + OpenAlex +本地FAISS摘要缓存
- 作者：LaTeX模板+ Claude Opus 4.7（视觉模式）用于图形批判和布局
- 评审：5名评审（Opus 4.7, GPT-5.4, Gemini 3 Pro, DeepSeek R1, Qwen3-Max），加权汇总
- 实验框架：PyTorch 2.5用于物理实验，W&B用于日志记录
- 可观察性：Langfuse用于代理痕迹，每页30美元的硬预算

## 构建它

1. **种子和域范围。**以种子想法为例（例如，“研究sub-1BTransformer注意力地图中的稀疏模式”）。def 搜索空间：模型、数据集、计算预算。

2. **文学通过。**查询Semantic Scholar + OpenAlex 50篇被引次数最多的相关论文；缓存在本地抽象；生成1页的域摘要。

3. **树脚手架。**用种子假设初始化根。实施实施

4. **沙盒包装。**每个实验都能运行种子被写入沙箱；输出以只读方式挂载。

5. ** Plan-execute-verify循环。**`execute` runs the sandbox, captures logs and metrics. `verify` runs unit checks on metrics (did the loss decrease? 消融是否隔离了影响？)。失败的节点会在树中存储一个失败原因。

6. **的作家。**预算后，选择最好的分支机构。使用matplotlib渲染图形。通过Claude Opus 4.7生成一个LaTeX草稿，其中包含上下文中的分支跟踪。编译。将编译好的PDF反馈给Opus 4.7版本以供评论。迭代。

7. **评论家。**五名评委用neurips风格的标准对草稿进行评分（新颖性、严谨性、清晰度、可重复性、影响力）。如果平均值< 4.0/5，则返回给作者进行评论。3次重写后硬停止。

8. **红色团队。**构建或集成一组针对沙箱的对抗性任务：分叉炸弹，网络泄漏尝试，文件系统转义，llm编写的shell元字符。确认全部被封锁。写下你的发现。

9. **再现性。**每篇论文都附带了它的树搜索跟踪JSON，种子，W&B运行链接，沙盒配置，以及一个端到端复制它的自述文件。

## 船这

Z0给定一个种子想法+一个领域+ 30美元的预算，它运行完整的管道，并发出可审查的论文和可重复性包。

| Weight | Criterion | How it is measured |
|:-:|---|---|
| 25 | Paper quality | Blind rubric review against published workshop papers |
| 20 | Experimental rigor | Baselines, seeds, ablations; every claim backed by a cell in the results table |
| 20 | Cost and compute discipline | $30/paper ceiling enforced, Langfuse-traced |
| 20 | Safety | Sandbox red team passes; network policy and kill-switch verified |
| 15 | Reproducibility | One-command rerun with identical seeds reproduces the paper |
| **100** | | |

## 练习

1. 针对同一领域中的三个不同的种子想法运行管道。比较树搜索的哪些部分重叠。识别重复的浪费计算。

2. 在实验执行之前，为估计高于5美元的节点添加一个“人在环路”门。衡量总成本下降了多少。

3. 把审稿人换成一个单独的评委。测量一组已知的不良论文的误接受率。

4. 介绍一个网络泄露红队测试：代理编写代码试图确认记录这次尝试。

5. 将树搜索与平坦的随机基线进行比较（相同的预算，没有扩展策略）。报告新颖性×质量增益。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Tree search | "AB-MCTS-style expansion" | Best-first exploration over experiment nodes with a novelty×quality×budget score |
| Sandbox | "Experiment isolation" | Container with no network, bounded CPU/memory, pinned seeds, read-only inputs |
| Vision critique | "Render-then-read" | Compile the paper to PDF, feed the PDF back to a VLM for layout and claim-evidence critique |
| Reviewer ensemble | "Automated peer review" | Multiple LLM judges scoring the paper with a NeurIPS rubric; weighted aggregate gates the pipeline |
| Novelty score | "Is this new?" | Heuristic that penalizes proximity to the 50-paper literature cache |
| Cost ceiling | "$ budget" | Hard cap on total spend per paper; Langfuse counters + pre-run estimates |
| Red team | "Sandbox-escape audit" | Adversarial tasks that would escape the sandbox if the policy is wrong |
