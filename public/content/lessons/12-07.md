# 开放重量VLM食谱：什么才是真正重要的

> 2024-2026年开重VLM文献是一个烧蚀表的森林。苹果的MM1测试了13种图像编码器、连接器和数据组合的组合。艾伦人工智能的Molmo证明了详细的人类字幕胜过GPT-4V蒸馏。寒武纪-1运行了20多个编码器比较。Idefics2形式化了五轴设计空间。prism VLMs在一个受控基准上比较了27个训练配方。在所有这些噪音中，有一小部分结果贯穿了论文：图像编码器比连接器架构更重要，数据混合比两者都更重要，详细的人类字幕比提炼的合成数据更重要。这节课读这些表格，所以你不必。

**Type:** Learn + lab
**Languages:** Python (stdlib, ablation table parser + recipe picker)
**Prerequisites:** Phase 12 · 05 (LLaVA baseline)
**Time:** ~180 minutes

## 学习目标

- 命名五轴VLM设计空间：图像编码器，连接器，LLM，数据混合，分辨率调度。
- 读取MM1 / Idefics2 /寒武纪-1烧蚀表，并预测哪个旋钮移动给定基准。
- 在给定计算预算和任务组合的情况下，为新的VLM选择一个配方（编码器、连接器、数据、分辨率）。
- 解释为什么在相同的代币计数上，详细的人类字幕优于GPT-4V蒸馏。

## 这个问题

目前存在数百个开重vlm。“好”和“最先进”之间的大部分差距不是建筑。它是数据，分辨率调度和编码器的选择。当你的模型表现不佳时，知道首先转动哪个旋钮可以节省500万gpu小时的错误。

2023波（LLaVA-1.5, instructlip, MiniGPT-4）在标题对预训练+ llava - instructlip -150k上运行。良好的基线。最高达到了35%。

2024波（MM1, Idefics2, Molmo，寒武纪-1，棱镜VLMs）进行了彻底的烧蚀。结果是令人惊讶和实用的。

## 这个概念

### 五轴设计空间

Idefics2 （laurenon et al., 2024）命名了这些轴：

1. 图像编码器。CLIP vitl /14, SigLIP SO400m/14, DINOv2 vitg /14, intervit6b。编码器在补丁大小、分辨率和预训练目标上有所不同。
2. 连接器。MLP（2-4层），Q-Former（32个查询+交叉关注），percepver Resampler（64个查询），C-Abstractor（卷积+双线性池化）。
3. 语言模型。美洲驼-3 8B / 70B，西北风7B，菲-3，杰玛-2，启文2.5。LLM规模是占主导地位的参数成本。
4. 训练数据。字幕对（CC3M， LAION），交错（OBELICS, MMC4），指令（llava - instruction, ShareGPT4V, PixMo, Cauldron）。
5. 决议计划。固定224/336/448，任何res，本地动态。在训练期间斜坡或恒定。

每个生产VLM在每个轴上做出选择。MMMU分数的大部分差异是由轴1、轴4和轴5来解释的，而不是由你选择的连接器来解释的。

### 轴1：编码器>连接器

MM1 3.2节显示：从CLIP vitl /14切换到SigLIP SO400m/14增加了3+点MMMU。将连接器从MLP切换到感知器重新采样器增加不到1点。标识2复制：SigLIP > CLIP， Q-Former≈MLP≈percepver在相同的令牌计数。

寒武纪-1的“寒武纪视觉编码器匹配”（Tong et al., 2024）在以视觉为中心的基准（CV-Bench）上运行了20多个编码器。排行榜的顶部是DINOv2和SigLIP的混合；夹在包的中间；ImageBind和vita - mae较低。从CLIP viti - l到DINOv2 viti -g/14的差距在CV-Bench上约为5-7分。

2026年开放VLMs的默认编码器是SigLIP 2 SO400m/14，用于语义+密集特征，有时与DINOv2 vitg /14特征连接（Cambrian的“空间视觉聚合器”就是这样做的）。

### 轴线2：连接器设计是一种清洗

MM1、Idefics2、Prismatic和MM-Interleaved都得出了相同的结论：在固定的视觉令牌计数下，连接器架构几乎无关紧要。在相同的令牌预算下，平均池补丁上的2层MLP在32查询Q-Former的1点内执行。

重要的是令牌数量。更多的视觉标记=更多的LLM计算=在一定程度上更好的性能，然后递减回报。对于OCR来说，每张图像64个标记太少了。576-1024令牌是大多数开放vlm的最佳点。2048+只对文档和图表有帮助。

Q-Former vs MLP是成本问题，而不是质量问题：无论图像分辨率如何，Q-Former都将代币限制在32-64；MLP发出所有的补丁令牌。对于高分辨率输入，Q-Former保存LLM上下文；对于低分辨率，区别在于噪声。

### 轴3:LLM大小设置上限

将LLM从7B增加一倍到13B，每篇VLM论文的MMMU得分会增加2-4分。在70B时，大多数基准测试都饱和了。VLM的多模态推理天花板是LLM的文本推理天花板——视觉编码器只能提供它，而不能为它推理。

这就是为什么Qwen2.5-VL-72B和Claude Opus 4.7打败MMMU-Pro和ScreenSpot-Pro：语言大脑是巨大的。通过巧妙的连接器设计，7B VLM无法替代70B VLM。

### 轴4：数据-详细的人类说明打败蒸馏

Molmo + PixMo （Deitke et al., 2024）是2024年大家应该看的结果。Allen AI让人类注释者在1-3分钟的密集语音到文本传递中描述图像，产生712K密集字幕图像。在训练数据中没有任何GPT-4V蒸馏。

Molmo-72B在11项基准测试中的11项上击败了Llama-3.2-90B-Vision。delta不是建筑，而是标题质量。详细的人类字幕比简短的网页字幕每幅图像包含5-10倍的信息，并在GPT-4V蒸馏产生幻觉的地方保持事实基础。

ShareGPT4V （Chen et al., 2023）和Cauldron （Idefics2）采用了相同的剧本，混合了人类+ GPT-4V的字幕。趋势很明显：对于2026年的前沿，标题密度>标题数量>蒸馏便利性。

### 轴5：决议及其时间表

Idefics2的消融：384 -> 448增加1-2点。448 - bbb980与图像分割（AnyRes）增加了另外3-5的OCR基准。中等精度的平面分辨率训练平台；分辨率斜坡（开始224，结束448或本机）列车更快，结束更高。

寒武纪-1进行了分辨率与代币的权衡：在固定的计算中，你可以在较低的分辨率下拥有更多的代币，或者在较高的分辨率下拥有更少的代币。更高的分辨率赢得了OCR；对于一般场景的理解来说，“越低越好”的模式胜出。

2026生产配方：训练阶段1在384固定，阶段2与动态分辨率高达1280的ocr重任务。

### 棱柱形控制比较

棱镜VLMs （Karamcheti et al., 2024）是控制所有轴的纸张。相同的13B LLM，相同的指令数据，相同的评估-一次只有一个轴变化。结果:

- 每个图像的视觉标记计数解释了60%的方差。
- 编码器的选择解释了~20%。
- 连接器架构解释了~5%。
- 其他一切（数据混合、调度器、LR）占剩余的约15%。

这是一个粗略的分解，但它是文献中对“我应该首先消融什么”最清晰的回答。

### 2026年的选择

鉴于证据，2026年新项目的默认开放vlm配方：

- 编码器：SigLIP 2 SO400m/14在原生分辨率与NaFlex，与DINOv2 vitg /14连接密集的特征，如果你需要分割/接地。
- 连接器：补丁令牌上的2层MLP。跳过Q-Former，除非你有令牌限制。
- LLM: Qwen2.5 / Llama-3.1 / Gemma 2，成本为7B，质量为70B，由目标延迟选择。
- 数据：PixMo + ShareGPT4V + Cauldron，以特定任务的指令数据充值。
- 分辨率：动态（最小256，最大1280像素每长边）。
- 时间表：第一阶段调整（仅限投影仪），第二阶段全面微调，第三阶段特定任务微调。

每一个违约都可以追溯到本课结束时引用的论文中被测量的消融。

## 使用它

Z0它编码MM1和Idefics2消融表（浓缩），并允许您查询：

- “给定预算X和任务Y，哪种配方会胜出？”
- “如果我把7B美洲驼上的SigLIP换成CLIP，预期的MMMU增量是多少？”
- “要得到80%的可信度答案，我应该先切除哪个轴？”

输出是一个排序的食谱列表，其中包含预期的基准差值和“消融优先”建议。

## 船这

这一课产生了给定一个目标任务组合、一个计算预算和一个延迟目标，它会发出一个完整的配方（编码器、连接器、LLM、数据组合、解决方案计划），并引用消融来证明每个选择的合理性。阻止工程师在每次新的VLM项目开始时重新发明Idefics2烧蚀表。

## 练习

1. 阅读MM1 3.2节。对于预算为5000万图像的固定2B LLM，哪个编码器获胜？答案会在13B LLM翻转吗？为什么?

2. Cambrian-1发现，在以视觉为中心的基准测试中，连接DINOv2 + SigLIP的性能优于单独使用，但在MMMU上没有增加信号。预测哪些基准会上升，哪些会持平。

3. 您的目标是2B LLM上的移动UI代理。选择编码器、连接器、分辨率和数据混合。用一个特定的消融表来证明每个选择的合理性。

4. Molmo提供4B和72B型号。4B与封闭的7B vlm具有竞争力；72B在11月11日的基准测试中击败了Llama-3.2-90B-Vision。对于llm大小的平台假设，这说明了什么？

5. 设计一个烧蚀表，以隔离7B VLM上的数据混合质量和编码器质量。最少多少次训练？提出四轴设置。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Ablation | "Turning one knob" | Training multiple runs that differ in exactly one design-space axis, holding everything else constant |
| Connector | "Bridge" / "projector" | Trainable module that maps vision encoder output into the LLM's token space (MLP, Q-Former, Perceiver) |
| Detailed human caption | "Dense caption" | A multi-sentence human-written description (typically 80-300 tokens) richer than a web alt text |
| Distillation | "GPT-4V captions" | Training data generated by a stronger proprietary VLM; convenient but prone to inherited hallucination |
| AnyRes / dynamic res | "High-res path" | Strategy to feed images larger than the encoder's native resolution via tiling or M-RoPE |
| Resolution ramp | "Curriculum" | Training schedule that starts low-resolution and increases, speeding alignment learning |
| Vision-centric bench | "CV-Bench / BLINK" | Evaluation that stresses fine-grained visual perception rather than language-heavy reasoning |
| PixMo | "Molmo's data" | Allen AI's 712K densely-captioned image dataset; human speech transcribed into dense captions |
