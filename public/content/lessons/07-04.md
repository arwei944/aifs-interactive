# Position coding - sine, rope, alibi

> Note that the arrangement remains unchanged. "The cat sitting on the mat" and "the cat sitting on the mat" produce the same output without a position signal. There are three algorithms that can solve this problem - each algorithm places a different bet on the meaning of "location".

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 7 · 02 (Self-Attention), Phase 7 · 03 (Multi-Head Attention)
**Time:** ~45 minutes

## This question

The scaled dot product attention is sequentially blind. Note that the attention within the matrix shuffling does not care about position.

This is not an error in the bag-of-words model. It is fatal to language, code, audio, video - anything that carries meaning in order.

The solution is to inject positions in the embedding. The answers of three eras:

1. Absolute sine (Vaswani 2017). The addition is simple, requires no learning, and the inference outside the training length is very poor.
2. ** Rope - Rotating position Embedding ** (Su 2021). Rotate the Q and K vectors to an Angle proportional to their positions. Encode the * relative * positions directly in the dot product. Dominate in 2026.
3. ** Alibi - Attention to Linear Deviation ** (Publisher 2022) Skip embedding completely; Add a head linear penalty to the distance-based attention score. Excellent length extrapolation.

As of 2026, almost every frontier open model uses RoPE: Llama 2/3/4, Qwen 2/3, Mistral, Mixtral, DeepSeek V3, Kimi. A few long context models use ALiBi or its modern variants. Absolute sine is historical.

## This concept


### Absolute sine

Pre-calculate a fixed matrix

```
PE[pos, 2i]   = sin(pos / 10000^(2i / d_model))
PE[pos, 2i+1] = cos(pos / 10000^(2i / d_model))
```

Then each dimension is a sine wave of a different frequency. This model learns to read positions from the phase mode. Surpass failure

### Rope

Rotate the Q and K vectors (not embeddings). For a pair of dimensions

```
[q'_2i    ]   [ cos(pos·θ_i)  -sin(pos·θ_i) ] [q_2i   ]
[q'_2i+1  ] = [ sin(pos·θ_i)   cos(pos·θ_i) ] [q_2i+1 ]

θ_i = base^(-2i / d_head),  base = 10000 by default
```

Apply the same rotational dot product to the keys with positions, that is to say: ** The attention score only depends on the relative distance **, even if the rotation is controlled at the absolute position. Beautiful technique.

Extension rope: This is how "Alpaca 3" expands from 8K to 128K.

### Alibi

Skip the embedding technique. Direct bias towards attention score

```
attn_score[i, j] = (q_i · k_j) / √d  -  m_h · |i - j|
```

Where are the tokens closer to getting promoted? Remote tokens will be punished. There is no time cost for training. The length extrapolation is superior to the sine and matches the original training length of RoPE.

### What should I choose in 2026

| Variant | Extrapolation | Training cost | Used by |

## Build it

### Step 1: Sine encoding

See a 4-line calculation:

```python
def sinusoidal(N, d):
    pe = [[0.0] * d for _ in range(N)]
    for pos in range(N):
        for i in range(d // 2):
            theta = pos / (10000 ** (2 * i / d))
            pe[pos][2 * i]     = math.sin(theta)
            pe[pos][2 * i + 1] = math.cos(theta)
    return pe
```

Add this to the embedding matrix before the first attention layer.

### Step 2: RoPE applied to Q, K

RoPE operates in-place on Q and K. For each pair of dims:

```python
def apply_rope(x, pos, base=10000):
    d = len(x)
    out = list(x)
    for i in range(d // 2):
        theta = pos / (base ** (2 * i / d))
        c, s = math.cos(theta), math.sin(theta)
        a, b = x[2 * i], x[2 * i + 1]
        out[2 * i]     = a * c - b * s
        out[2 * i + 1] = a * s + b * c
    return out
```

Key: Apply the same function to Q at position, take their dot product a, and pay attention to learning relative positions for free.

### Step 4: verify relative-distance property of RoPE

Pick two random vectors `a, b`. Rotate by `(pos_a, pos_b)`. Then by `(pos_a + k, pos_b + k)`. Both dot products must match within floating-point error. That property is the whole point of RoPE — it is invariant to the absolute offset, only the relative gap matters.

## Use It

PyTorch 2.5+ ships RoPE utilities in `torch.nn.functional`. Most production code uses `flash_attn` or `xformers` where RoPE is applied inside the attention kernel.

```python
from transformers import AutoModel
model = AutoModel.from_pretrained("meta-llama/Llama-3.2-3B")
# model.config.rope_scaling → {"type": "yarn", "factor": 32.0, "original_max_position_embeddings": 8192}
```

*Long context tips for 2026: **

- NTK-aware interpolation. Re-scale
- "Yarn. Smarter interpolation, maintaining the attention entropy of long contexts. Llama 3.1 128K uses it.
- "LongRoPE. Microsoft's 2024 method uses evolutionary search to select per-dimensional scale factors. Phi-3-Long uses it.
- Position interpolation + fine-tuning. Just contract the position through the expansion factor and fine-tune the 1-5B tokens. Surprisingly, it is effective.

## Key terms

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Positional encoding | "Tells attention about order" | Any signal added to embeddings or attention that encodes position. |
| Sinusoidal | "The original one" | `sin/cos` at geometric frequencies added to embeddings; doesn't extrapolate. |
| RoPE | "Rotary embeddings" | Rotate Q, K by position-dependent angle; dot product encodes relative distance. |
| ALiBi | "Linear bias trick" | Add `-m·|i-j|` to attention scores; no embedding needed, great extrapolation. |
| base | "RoPE's knob" | The frequency scaler in RoPE; increase to extend context at inference. |
| NTK-aware | "A RoPE scaling trick" | Rescale `base` so high-frequency dims aren't squeezed when context expands. |
| YaRN | "The fancy one" | Per-dimension interpolation+extrapolation that preserves attention entropy. |
| Extrapolation | "Works beyond trained length" | Can the position scheme serve correct output past `max_len` seen in training? |
