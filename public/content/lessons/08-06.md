# 扩散模型- DDPM从零开始

## 这个问题

你想要一个样品gan是一个极小极大的博弈，它经常发散。VAEs从高斯解码器产生模糊的样本。你真正想要的训练目标是(a)一个单一的稳定损失（没有鞍点，没有极小值），(b)一个下界

Sohl-Dickstein et al.（2015）有一个理论上的答案：定义一个马尔可夫链Ho, Jain, Abbeel（2020）表明，损失可以简化为一行-预测噪声-并清理了数学。在2020年，这是一件稀奇的事。2021年，它生产出了最先进的样品。2022年，它变成了稳定扩散。在2026年，它是衬底。

## 这个概念

Z0

**正向处理**添加高斯噪声封闭形式——数学易于处理的原因——是累积步长也是高斯的：

```
q(x_t | x_0) = N( sqrt(α̅_t) · x_0,  (1 - α̅_t) · I )
```

在哪里挑选

**反向处理**学习神经网络给定

```
x_{t-1} = (1 / sqrt(α_t)) · ( x_t - (β_t / sqrt(1 - α̅_t)) · ε_θ(x_t, t) )  +  σ_t · z
```

在哪里这个表达式很难看，但它只是代数解法

**培训损失。* *

```
L_simple = E_{x_0, t, ε} [ || ε - ε_θ( sqrt(α̅_t) · x_0 + sqrt(1 - α̅_t) · ε,  t ) ||² ]
```

样本一次损失，没有极大极小值，没有KL，没有参数化技巧。

**抽样。**开始迭代相反的步骤完成了。

## 为什么它有效？

三个直觉:

1. **去噪容易；生成是困难的。** At在中级

2. **伪装得分匹配。** Vincent（2011）证明了预测噪声等同于估计反向SDE使用这个分数沿着密度梯度往上走——一个指向高概率区域的引导随机行走。

3. ** ELBO减少到简单的MSE。**全变分下界每个时间步长有一个KL项。通过DDPM的参数化，这些KL项简化为具有特定系数的噪声预测的MSE；Ho去掉了系数（称之为“简单”损失），质量得到了改善。

### Step 2: sample `x_t` in one shot

```python
def forward_sample(x0, t, alpha_bars, rng):
    a_bar = alpha_bars[t]
    eps = rng.gauss(0, 1)
    x_t = math.sqrt(a_bar) * x0 + math.sqrt(1 - a_bar) * eps
    return x_t, eps
```

### Step 4: reverse sampling

```python
def sample(model, alpha_bars, T, rng):
    x = rng.gauss(0, 1)
    for t in range(T - 1, -1, -1):
        eps_hat = model_forward(model, x, t)
        beta_t = 1 - alphas[t]
        x = (x - beta_t / math.sqrt(1 - alpha_bars[t]) * eps_hat) / math.sqrt(alphas[t])
        if t > 0:
            x += math.sqrt(beta_t) * rng.gauss(0, 1)
    return x
```

对于具有40个时间步长和24个单元MLP的一维问题，该方法在~200个epoch内学习到双模混合。

## 时间调节

网络需要知道它去噪的是哪个时间步长。两个标准选项：

- * *正弦嵌入。**像变压器位置编码。`embed(t) = [sin(t/ω_0), cos(t/ω_0), sin(t/ω_1), ...]`. 通过MLP，广播到网络上。
- **电影/群体规范条件反射。**项目嵌入到每通道规模/偏差（电影）在每个块。

我们的示例代码使用正弦→concat。生产U-Nets使用薄膜。

## 陷阱

- 日程安排很重要。**线性如果质量停滞，改变计划。
- **时间步嵌入很脆弱。**传递生料一定要使用合适的嵌入。
- ** v -预测vs . ε-预测。**对于窄域（非常小或非常大的t），v -预测(SDXL、SD3和Flux都使用它。
- * * Classifier-free指导。**在推理时，计算条件和无条件第08课的内容。
- 1000步很长。**生产使用DDIM（20-50步），DPM-Solver（10-20步）或蒸馏（1-4步）。参见第12课。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Forward process | "Adding noise" | Fixed Markov chain `q(x_t | x_{t-1})` that destroys the data. |
| Reverse process | "Denoising" | Learned chain `p_θ(x_{t-1} | x_t)` that reconstructs the data. |
| β schedule | "The noise ladder" | Per-step variance; linear, cosine, or sigmoid. |
| α̅ | "Alpha bar" | Cumulative product `∏(1 - β)`; gives closed-form `x_t` from `x_0`. |
| Simple loss | "MSE on noise" | `||ε - ε_θ(x_t, t)||²`; all variational derivations collapse to this. |
| ε-prediction | "Predict noise" | Output is the noise added; standard DDPM. |
| V-prediction | "Predict velocity" | Output is `α·ε - σ·x`; better conditioning across t. |
| DDPM | "The paper" | Ho et al. 2020; linear β, 1000 steps, U-Net. |
| DDIM | "Deterministic sampler" | Non-Markov sampler, 20-50 steps, same training objective. |
| Classifier-free guidance | "CFG" | Mix conditional and unconditional noise predictions to amplify conditioning. |

## 生产说明：扩散推理是一个计步问题

DDPM论文运行T=1000个反向步骤。没有人会将其投入生产。每个真正的推理堆栈都会选择以下三种策略中的一种——每种策略都清晰地映射到“延迟从何而来”的生产框架：

1. **更快的取样器，相同的型号。** DDIM（20-50步），dpm - solver++ (10-20), UniPC（8-16）。插入式更换反回路；受过训练的人减少延迟20-50倍。
2. * *蒸馏。**训练学生在更少的步骤中匹配老师：渐进蒸馏（2→1），一致性模型（任意→1-4），LCM, SDXL-Turbo, SD3-Turbo。减少5-10倍的延迟，需要重新训练。
3. **缓存和编译。**减少每步延迟~2倍。与(1)和(2)叠加。

对于生产扩散服务器，预算对话与生产文献中描述的llm相同：延迟为TTFT小（一步）；tpot等效是完整的响应时间，因为从用户的角度来看，图像生成是“一次性完成的”。
