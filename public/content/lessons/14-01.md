# 代理循环：观察、思考、行动

> 2026年的每个代理——Claude Code， Cursor, Devin， Operator——都是2022年ReAct循环的变体。推理令牌与工具调用和观察交织在一起，直到触发停止条件。在接触任何框架之前先了解这个循环。

## 这个问题

LLM本身就是一个自动补全。你问一个问题，你会得到一个字符串。它不能读取文件、运行查询、打开浏览器或验证声明。如果模型有过时或错误的信息，它会自信地说出错误的事情并停止。

代理用一种模式解决了这个问题：一个让模型决定暂停、调用工具、读取结果并继续思考的循环。这就是整个想法。阶段14中的每一个附加功能——内存、规划、子代理、辩论、评估——都是围绕这个循环搭建起来的。

## 这个概念

### ReAct：规范格式

Yao等人（ICLR 2023, arXiv:2210.03629）介绍每回合释放：

```
Thought: I need to look up the capital of France.
Action: search("capital of France")
Observation: Paris is the capital of France.
Thought: The answer is Paris.
Action: finish("Paris")
```

在原始论文中，模仿或强化学习基线的三个绝对优势：

- ALFWorld：只有1-2个上下文示例的绝对成功率+34分。
- WebShop：比模仿学习和搜索基线+10分。
- Hotpot QA: ReAct通过在检索过程中的每一步都接地来从幻觉中恢复。

推理跟踪完成了三件模型不能用仅操作提示完成的事情：诱导计划、跨步骤跟踪计划，以及在操作返回意外观察结果时处理异常。

不变的是：循环本身。观察→思考→行动→观察→思考→行动→停止。无论思想令牌是打印在成绩单中还是在单独的字段中携带，控制流程都是相同的。

### 五种成分

每个代理循环都需要五样东西。错过任何一个，你就成了聊天机器人，而不是特工。

1. 一个增长的消息缓冲区：用户转、助手转、工具转、助手转、工具转、助手转、最终。
2. 模型可以通过名称调用工具注册表——模式输入、执行、结果字符串输出。
3. 一个**停止条件** -模型说
4. A **转预算**，以防止无限循环。Anthropic的电脑使用公告称，每项任务需要几十到几百步是正常的；选择适合任务类别的帽子，而不是一种适合所有人的帽子。
5. 一个**观察格式化器**，将工具输出转换为模型可以读取的内容。堆栈中的每400个错误都需要以观察字符串结束，而不是崩溃。

### 为什么这个循环无处不在

Claude Agent SDK, OpenAI Agents SDK, LangGraph, AutoGen v0.4 AgentChat, CrewAI, Agno， master——这些都在底层运行ReAct。框架的差异是关于循环周围的东西：状态检查点（LangGraph），角色模型消息传递（AutoGen v0.4），角色模板（CrewAI），跟踪范围（OpenAI Agents SDK）。循环本身是不变的。

### 2026年的陷阱

- **信任边界崩溃。**工具输出是不可信的输入。从web检索到的PDF可以包含OpenAI的用户授权协议文档是明确的：“只有来自用户的直接指令才算作许可。”见第27课。
- * *级联故障。** 1个幽灵SKU， 4个下游API调用，1个多系统中断。代理人无法区分“我失败了”和“任务不可能完成”，并且经常在400次错误中产生成功的幻觉。见第26课。
- **循环长度爆炸。**大多数2026代理运行40-400步。调试步骤38的错误决定需要可观察性（第23课）和计算轨迹（第30课）。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Agent | "Autonomous AI" | A loop: LLM thinks, picks a tool, result feeds back, repeat until stop |
| ReAct | "Reasoning and Acting" | Yao et al. 2022 — interleave Thought, Action, Observation in one stream |
| Tool call | "Function calling" | Structured output the runtime dispatches to an executable |
| Observation | "Tool result" | The string representation of tool output fed back into the next prompt |
| Reasoning channel | "Thinking tokens" | Native reasoning output on a separate stream, passed through across turns |
| Stop condition | "Exit clause" | Explicit `finish`, no tool calls emitted, max turns, max tokens, or guardrail trip |
| Turn budget | "Max steps" | Hard cap on loop iterations — agents run 40–400 steps per task in 2026 |
| Trace | "Transcript" | Full record of thought, action, observation tuples for a run |
