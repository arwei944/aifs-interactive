# 具体VLAs: RT-2， OpenVLA, π0, GR00T

> 第一个从网站上读取食谱并在厨房机器人中执行的模型是RT-2（谷歌DeepMind， 2023年7月）。RT-2将动作离散为文本标记，在网络数据和机器人动作数据上共同微调VLM，证明了网络尺度的视觉语言知识转移到机器人控制中。OpenVLA（2024年6月）发布了open 7B参考。Physical Intelligence π0系列（2024-2025）新增流匹配动作专家。NVIDIA的GR00T N1（2025年3月）为大规模人形机器人提供了双系统（System 1 / System 2）控制。VLA原语——视觉-语言-行动，一个可以看到、读取和行动的单一模型——是这个阶段的理解模型和第15阶段的自治系统之间的桥梁。

**Type:** Learn
**Languages:** Python (stdlib, action tokenizer + VLA inference skeleton)
**Prerequisites:** Phase 12 · 05 (LLaVA), Phase 15 (Autonomous Systems, referenced)
**Time:** ~180 minutes

## 学习目标

- 描述动作标记化：离散bin编码（RT-2）， FAST高效动作标记，连续流匹配动作（π0）。
- 解释为什么网络+机器人数据的共同微调保留了对新任务的一般知识转移。
- 在同一机器人任务上比较OpenVLA （open 7B Llama+VLM）、π0 （flow-matching）和gr00tn1 （dual-system）。
- 将Open X-Embodiment数据集命名为RT-X训练语料库。

## 这个问题

自20世纪70年代以来，一种能够根据自然语言指令做家务的机器人一直是研究目标。21世纪20年代的答案是：视觉-语言-行动（VLA）模型。与VQA相同的VLM架构，但输出是动作（关节扭矩，末端执行器姿势，离散命令）而不是文本。

VLAs特有的挑战：

1. 动作空间是连续的（关节角度，力）和高维的（7-DOF手臂+ 3-DOF夹持器= 10个暗点在30赫兹）。
2. 针对机器人的训练数据很少。Open X-Embodiment拥有~1M轨迹；网页文本图像是5B+。
3. 控制频率很重要。30hz控制回路意味着每个动作33ms预算。
4. 安全。错误的操作会损坏硬件、人员或财产。

## 这个概念

### 动作标记化（RT-2）

RT-2的诀窍是：将每个联合目标表示为量化文本标记。将规范化的[- 1,1]范围离散为256个bin，将每个bin映射到一个词汇表ID。10- dof动作在每个控制步骤中变成10个令牌。

在混合上对PaLM-X VLM进行共同微调：

- Web图像-文本对（字幕，VQA）。
- 机器人示范，动作作为标志。

模型看到“捡起红色立方体”（语言）→图像（视觉）→10个令牌动作序列（离散的联合目标）。Web预训练保留了一般知识的迁移：RT-2可以遵循“向快速移动的对象移动”，即使“快速移动”并不在训练数据中。

RT-2论文中3-5 Hz的推断，受VLM自回归解码的限制。

### OpenVLA -开放7B参考

OpenVLA （Kim et al., June 2024）是开权重RT-2的等效物。7B羊驼主干，DINOv2 + SigLIP双视觉编码器，动作标记化超过256个箱子。

在Open X-Embodiment上训练（横跨22个机器人的970k轨迹）。提供LoRA微调支持，以适应新的机器人。

推论：4-5赫兹的A100与量化。对于慢速操作来说足够快，而不是高频控制。

### 快速标记器-更快的行动解码

Pertsch等人（2024）表明离散bin标记化是低效的——大多数动作聚集在一个小的bin空间区域。FAST（频域动作序列标记器）通过DCT压缩动作序列并量化系数。

一个30步的动作轨迹变成了~10个FAST令牌，而不是300个离散的bin令牌。在没有质量损失的情况下，推理速度提高3-5倍。

### π0和流量匹配动作

物理智能的π0 （Black et al., October 2024）用流匹配动作专家替换离散动作令牌：

- 一个小型动作Transformer读取VLM的隐藏状态，并通过整流输出连续的50步动作序列。
- 具有流量匹配损失的动作头部列车；VLM预训练保持不变。
- 推断：全动作序列发出约5个去噪步骤，有效控制50赫兹。

π0的主张：在广泛的操作任务上击败了OpenVLA和Octo。连续作用公式保留了离散化所破坏的平滑性。

π0.5和π0-FAST是增量升级。π0-FAST结合了FAST标记和流匹配。

### gr00tn1 -双系统的人形

NVIDIA的GR00T N1（2025年3月）是为人形机器人（bbb30自由度，全身）而制造的：

- 系统2：一个大型VLM读取场景+指令，以~ 1hz的频率产生高级子目标。
- 系统1：一个小型动作头Transformer，根据子目标产生低水平的50-100 Hz联合命令。

这种分裂反映了卡尼曼的快慢思维：系统2计划，系统1行动。优点：慢vlm大小的规划不会阻碍快速控制；系统1保持较小的延迟。

GR00T N1.7（2025年末）改进了数据可伸缩性。GR00T对来自Omniverse的模拟到真实的数据进行微调。

### 打开X-Embodiment

训练数据。RT-X（2023年10月）收集了22个数据集，涵盖22个机器人的1M个轨迹。Open X-Embodiment是每个人都使用的语料库：

- ALOHA / Bridge V2 / Droid / RT-2厨房/语言桌。
- 每个样本：（机器人状态，摄像头视图，指令，动作顺序）。
- 训练卫生：统一动作空间，规范关节范围，调整摄像机尺寸。

OpenVLA和π0在Open X-Embodiment上训练。通过LoRA对100-1000个特定任务的演示进行微调，可以缩小与任何特定机器人的领域差距。

### 共同微调vs机器人

协同微调混合了网络VQA数据和机器人轨迹。比例很重要：过多的VQA会导致模型忘记动作；过多的机器人数据会使模型失去一般知识。

RT-2的比值：~1:1。OpenVLA: ~0.5:1网络对机器人。π0:相似。精确的比例是根据数据集大小调整的超参数。

只有机器人的训练产生了特定于任务的模型，这些模型在未分发的指令上失败了。共同微调是“捡起红色立方体（在演示中）”和“捡起左边第三大的物体（新的措辞）”之间的区别。

### 安全及行动限制

每个生产VLA附带：

- 硬接头极限（不能超过规格）。
- 速度限制（软剪辑）。
- 工作空间边界（末端执行器不能离开表）。
- 对新任务的人工审批。

它们位于VLA之外，作为控制层检查。VLA的输出是一个建议，而不是一个命令。

## 使用它


- 实现256-bin操作标记化和去标记化。
- 设计了一种基于DCT +量化的快速标记器。
- 比较每个动作步骤（离散箱，快速，连续流）的令牌计数。
- 打印RT-2→OpenVLA→π0→GR00T的谱系摘要。

## 船这

这一课产生了给定一个机器人任务（操作，导航，仿人全身），选择离散bin + RT-2， FAST + OpenVLA，流匹配+ π0，或双系统+ GR00T。

## 练习

1. 一个10自由度的手臂在30赫兹的控制速率。256个箱的离散箱标记化每秒发出多少个令牌？7B VLM能跟上吗？

2. 快速标记化将30步轨迹压缩到约10个标记。如果轨迹有高频运动（如击鼓声），用户会损失什么？

3. π0的流匹配头分~5步去噪。将吞吐量与OpenVLA的4-5 Hz自回归解码进行比较。

4. GR00T的系统1 /系统2分裂映射到卡尼曼。提出一个不同的分裂（系统3?），这可能有助于两足行走。

5. 阅读Open X-Embodiment第4节关于数据集管理。请说出防止域泄漏的三个管理规则。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| VLA | "Vision-language-action" | Model that takes image + instruction and outputs action commands |
| Action tokenization | "Discrete bins" | Quantize continuous joint targets into 256 bins per dim, each a vocab ID |
| FAST tokenizer | "Frequency action tokens" | DCT + quantize to compress 30-step trajectories to ~10 tokens |
| Co-fine-tune | "Mix web + robot" | Train on web VQA data alongside robot demos to preserve general knowledge |
| Flow-matching action head | "π0 continuous output" | Small transformer that outputs a 50-step action sequence via rectified flow |
| System 1 / System 2 | "Dual-system control" | Large VLM plans slowly, small action head acts quickly; GR00T pattern |
| Open X-Embodiment | "RT-X dataset" | 1M-trajectory cross-robot dataset; the training corpus |
