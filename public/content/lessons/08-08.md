# 控制网，LoRA和调理

> 文字本身是一个笨拙的控制信号。ControlNet允许您克隆预训练的扩散模型，并使用深度图，姿势骨架，涂鸦或边缘图像来引导它。LoRA允许您通过训练1000万个参数来微调一个包含2b参数的模型。他们一起把“稳定扩散”从一个玩具变成了2026年的图像管道，在每个机构都有销售。

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 8 · 07 (Latent Diffusion), Phase 10 (LLMs from Scratch — for LoRA foundation)
**Time:** ~75 minutes

## 这个问题

像“一个穿红裙子的女人在繁忙的街道上遛狗”这样的提示，并没有给模特提供狗在哪里、女人在什么姿势、或者街道的视角等信息。文本固定约10%，你需要指定一个图像。其余的都是视觉上的，无法用语言有效地描述。

从头开始为每个信号（姿态、深度、精明、分割）训练一个新的条件模型是令人望而却步的。您希望保持2.6B-param SDXL主干冻结，附加一个读取条件的小侧网络，并让它推动主干的中间特征。这就是ControlNet。

你还想在不重新训练整个模型的情况下教给模型新的概念（你的脸、你的产品、你的风格）。你想要一个小100倍的增量。这就是LoRA——插入现有注意力权重的低级别适配器。

ControlNet + LoRA + text = 2026从业者的工具包。大多数生产图像管道层2-5个lora， 1-3个控制网，以及一个ip适配器在SDXL / SD3 / Flux基础之上。

## 这个概念

Z0

### ControlNet （Zhang et al., 2023）

取一个预训练的SD。*克隆* U-Net的编码器一半。冻结原件。训练克隆接受额外的条件输入（边缘，深度，姿势）。使用*零卷积*跳过连接将克隆连接回原始的解码器一半（1×1 convs初始化为零-作为无操作开始，学习delta）。

```
SD U-Net decoder:   ... ← orig_enc_features + zero_conv(controlnet_enc(condition))
```

Zero-conv init意味着ControlNet开始作为身份-甚至在训练之前没有伤害。以1M（提示，条件，图像）三元组进行标准扩散损失训练。

单模态控制网作为小型侧模（SDXL ~360M, sd1.5 ~70M）发货。你可以在推理中组合它们：

```
features += weight_a * control_a(depth) + weight_b * control_b(pose)
```

### 《LoRA》（胡等人，2021年）

对于任何线性层

```
W' = W + ΔW,  ΔW = B @ A,  A ∈ R^{r×d},  B ∈ R^{d×r}
```

有4-16级是注意力的标准，64-128级是重的精细曲调。新增参数数量：对于SDXL，请注意在整个模型中：LoRA通常是20-200MB，而不是基本的5GB。

在推理中，您可以扩展LoRA：`α = 0.5-1.5` is normal. 多个lora叠加在一起（通常需要注意的是它们以非线性方式交互）。

### ip适配器（Ye et al., 2023）

一个小适配器，接受一个“图像”作为条件（与文本一起）。使用CLIP图像编码器生成图像标记，将它们与文本标记一起注入交叉注意。~每个基本型号20MB。允许您在没有LoRA的情况下“以此参考的样式生成图像”。

## 陷阱

- * * Over-scaling罗拉。**保持
- **ControlNet权重冲突。**使用重量为1.0的姿态控制网和重量为1.0的深度控制网通常会过调。权重和≈1.0是安全的默认值。
- **LoRA在错误的基地。由于注意力维度不匹配，SDXL lora在sd1.5上静默不操作。扩散器将在0.30+中发出警告。
- **文本反转漂移。**在一个检查点上训练的标记在另一个检查点上漂移严重。LoRA更具可移植性。
- **LoRA权重合并和存储。**您可以将LoRA烘焙到基本模型权重中以获得更快的推断（不增加运行时），但您失去了扩展的能力保留两个版本。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| ControlNet | "Spatial control" | Cloned encoder + zero-conv skips; reads a conditioning image. |
| Zero convolution | "Starts as identity" | 1×1 conv initialized to zero; ControlNet starts as no-op. |
| LoRA | "Low-rank adapter" | `W + B @ A`, `r << d`; 100x fewer params than a full fine-tune. |
| rank r | "The knob" | LoRA compression; 4-16 typical, 64+ for heavy personalization. |
| α | "LoRA strength" | Runtime scaling of the LoRA delta. |
| IP-Adapter | "Reference image" | Small image-conditioning adapter via CLIP-image tokens. |
| DreamBooth | "Full subject fine-tune" | Train the full model on ~30 images of a subject. |
| Textual Inversion | "New token" | Learn a new word embedding only; legacy, mostly replaced. |

## 生产说明：LoRA交换、控制网通道、多租户服务

一个真正的文本到图像的SaaS通过相同的基本检查点为数百个lora和十几个controlnet提供服务。服务问题看起来很像LLM多租户（生产文献涵盖了连续批处理和LoRAX / S-LoRA下的LLM案例）：

- **热插拔lora，不要合并。**合并保持lora在VRAM中的温度为r级delta；扩散器暴露互换成本是
- **ControlNet作为第二注意通道。**克隆编码器与基础并行运行。两个权重为1.0的controlnet =每一步有两个额外的向前传递，而不是一个合并传递。批量大小的净空空间呈二次下降。每个主动控制网的步骤成本预算为1.5倍。
- **也量化了lora。**如果您量化基数（参见第07课，Flux on 8GB）， LoRA增量也将明确量化为8位或4位。qlora风格的加载允许您在4位Flux基础上堆叠5-10个lora，而不会损坏内存。

特定于flux: Niels的Flux-on-8GB笔记本电脑将基数量化为4位；堆叠风格LoRA (这是大多数SaaS机构在2026年发布的配方。
