## This question

In 2018, each NLP task - emotion, NER, QA, implication - trained its own model from scratch on its own labeled data. There is no pre-trained "understand English" checkpoint. You can make fine adjustments. ELMo (2018) indicates that you can pre-train context embeddings with bidirectional LSTM; It is helpful, but not generalized.

BERT (Devlin et al. 2018) asks: What if we use a transformer encoder to train every sentence on the Internet and force it to predict the missing words from the context on both sides? Then you fine-tune a head on the downstream task. Parameter efficiency is a revelation.

The result is that within 18 months, BERT and its variants (RoBERTa, ALBERT, ELECTRA) dominated all NLP rankings. By 2020, every search engine, content moderation pipeline and semantic search system on Earth will have a BERT.

In 2026, pure encoder models will remain the right tools for classification, retrieval, and structured extraction - they run 5 to 10 times faster per token than decoders, and their embeddings are the pillars of every modern retrieval stack. ModernBERT (December 2024) pushed the architecture to the 8K environment through Flash Attention + RoPE + GeGLU.

## This concept


### Training signal

For example:

Randomly block 15% of tokens

```
input:  the [MASK] brown fox jumps [MASK] the lazy dog
target: the  quick brown fox jumps  over  the lazy dog
```

Train the model to predict the original mark of the mask position. Because the encoder is bidirectional, predicting this is something that GPT cannot achieve.

### BERT mask rule

Among the 15% tokens selected for prediction:

- 80% of"
- 10% was replaced with random tokens.
- 10% remains unchanged.

Why not always? Because train the model to expect 10% randomness + 10% invariance to keep the model honest.

### The next prediction (NSP) - and why was it abandoned

The original BERT was also trained on NSP: given two sentences A and B, it predicted whether B would follow A. RoBERTa (2019) removed it and showed the NSP harm rather than help. Modern encoders skip it.

### What changes occurred in 2026: Modern

In 2024, ModernBERT's paper reconstructed blocks using 2026 primitives:

| Component | Original BERT (2018) | ModernBERT (2024) |
|-----------|----------------------|-------------------|
| Positional | Learned absolute | RoPE |
| Activation | GELU | GeGLU |
| Normalization | LayerNorm | Pre-norm RMSNorm |
| Attention | Full dense | Alternating local (128) + global |
| Context length | 512 | 8192 |
| Tokenizer | WordPiece | BPE |

Unlike the stack in 2018, it is native to flash Attention. When the sequence length is 8K, the inference speed is 2 to 3 times faster than DeBERTa-v3, which has a higher GLUE score.

### Use cases that still choose encoders in 2026

| Task | Why encoder beats decoder |
|------|---------------------------|
| Retrieval / semantic search embeddings | Bidirectional context = better embedding quality per token |
| Classification (sentiment, intent, toxicity) | One forward pass; no generation overhead |
| NER / token labeling | Per-position output, natively bidirectional |
| Zero-shot entailment (NLI) | Classifier head on top of encoder |
| Reranker for RAG | Cross-encoder scoring, 10x faster than LLM rerankers |

### Step 2: run MLM prediction on a tiny corpus

Train a 2-layer encoder + MLM head on a vocabulary of 20 words, 200 sentences. No gradient — we do forward-pass sanity checks. Full training needs PyTorch.

### Step 3: compare mask types

Show how the three-way rule keeps the model usable without `[MASK]`. Predict on an unmasked sentence and on a masked sentence. Both should produce reasonable token distributions because the model saw both patterns in training.

### Step 4: fine-tune head

Replace the MLM head with a classification head on a toy sentiment dataset. Only the head trains; the encoder is frozen. This is the pattern every BERT application follows.

## Use It

```python
from transformers import AutoModel, AutoTokenizer

tok = AutoTokenizer.from_pretrained("answerdotai/ModernBERT-base")
model = AutoModel.from_pretrained("answerdotai/ModernBERT-base")

text = "Attention is all you need."
inputs = tok(text, return_tensors="pt")
out = model(**inputs).last_hidden_state   # (1, N, 768)
```

*The embedded model is fine-tuned BERT. The encoders are the same. The loss has changed.

*The cross-encoder is reordered and BERT is fine-tuned. Pairing classification enables two-way attention between queries and documents, which is precisely the reason why cross-encoders are superior in quality to dual-encoders.

*When will BERT not be selected in 2026? Anything generated. The encoder has no reasonable way to generate labels regressively. In addition: Any small decoder with parameters lower than 1B can match the quality more flexibly (Phi-3-Mini, Qwen2-1.5B).

## Key terms

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| MLM | "Masked language modeling" | Training signal: randomly replace 15% of tokens with `[MASK]`, predict the originals. |
| Bidirectional | "Looks both ways" | Encoder attention has no causal mask — every position sees every other position. |
| `[CLS]` | "The pooler token" | A special token prepended to every sequence; its final embedding is used as the sentence-level representation. |
| `[SEP]` | "Segment separator" | Separates paired sequences (e.g. query/doc, sentence A/B). |
| NSP | "Next sentence prediction" | BERT's second pretraining task; shown to be useless in RoBERTa, dropped after 2019. |
| Fine-tuning | "Adapt to a task" | Keep the encoder mostly frozen; train a small head on top for the downstream task. |
| Cross-encoder | "A reranker" | A BERT that takes both query and doc as input, outputs a relevance score. |
| ModernBERT | "2024 refresh" | Encoder rebuilt with RoPE, RMSNorm, GeGLU, alternating local/global attention, 8K context. |
