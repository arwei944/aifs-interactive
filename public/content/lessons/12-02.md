## 这个问题

预夹视力被监督。收集标记数据集（ImageNet: 1.2M图像，1000类），训练CNN，发布。标签是昂贵的，标签偏向于标签者可以同意的内容，并且如果不进行微调，标签不能转移到新的任务中。

图片说明网站免费提供超过10亿对松散标记的图片。一张金毛寻回犬的照片，上面写着“我的狗马克斯在公园里”，这是一种监督信号——文字描述了这张照片。问题是：你能把它变成有用的培训吗？

CLIP的答案是：将图像标题对视为匹配任务。给定一批N个图像和N个标题，学习针对N-1个干扰物将每个图像与自己的标题匹配。监督是"这两件事是一起的；这些N-1没有。”没有类标签。没有人工注释。只是一种对比损失。

所得到的嵌入空间比CLIP所训练的要多。ImageNet zero-shot之所以有效，是因为“猫的照片”嵌入了从未明确标记为猫的猫的照片附近。这个赌注催生了每一个2026年的VLM。

### InfoNCE损失

CLIP对行和列使用对称交叉熵：

```
loss_i2t = CE(S, labels=identity)     # each image's positive is its own caption
loss_t2i = CE(S^T, labels=identity)   # each caption's positive is its own image
loss = (loss_i2t + loss_t2i) / 2
```

这是InfoNCE。CE中的softmax强制每个图像比批处理中的其他图像更匹配其标题。“否定”是所有其他批处理项目。更多的批次=更多的负面消息=更强的信号。CLIP训练在批次32k；规模很重要。

### 温度

Z0低tau→急剧分布，硬负开采效应。高tau→软，所有样品贡献。CLIP学习log(1/tau)， CLIP防止崩溃。SigLIP 2修复了初始的tau，并使用学习偏差代替。

### 为何乙状结肠缩放效果更好（SigLIP）

Softmax需要整个相似矩阵同步。在分布式训练中，你必须对每个副本的每个嵌入都进行集合，然后进行softmax。这是二次世界大小的通信。

SigLIP将softmax替换为每对元素的sigmoid：损失是：

```
L = -1/N sum over (i, j) [ y_ij log sigmoid(S[i,j]) + (1-y_ij) log sigmoid(-S[i,j]) ]
```

Z0每一对的损失是独立的。不需要集合。每个GPU计算其本地块和总和。SigLIP 2可以便宜地批量处理32k-512k，而CLIP则需要更多的通信。

### Zero-shot分类

给定N个类名，为每个类构建一个文本模板：

```
"a photo of a {class}"
```

用文本编码器嵌入每个模板。用图像编码器嵌入图像。余弦相似度=预测类。没有针对目标班级的培训。

提示模板很重要。CLIP的原始论文每节课使用80个模板（普通的、艺术的、照片的、绘画的等），并平均嵌入。+3个ImageNet点。现代用法通常选择一个或两个模板。

### 线性探头和微调

零射击是一个底线。线性探测（在冻结的CLIP特征上为目标类训练一个线性层）在域内任务中胜过零射击。全微调在域内优于线性探针，但会损害零射转移。三个政权有三个权衡。

### SigLIP 2: NaFlex和密集的特征

SigLIP 2（2025）补充道：
- NaFlex：单一模型处理可变宽高比和分辨率。
- 更好的密集特征用于分割和深度估计，目标用作VLMs中的冷冻骨干。
- 多语言：接受过100多种语言的培训，其中CLIP仅为英语。
- 1B参数尺度，CLIP在400M处达到峰值。

在2026年开放的vlm中，SigLIP 2 SO400m/14是默认的视觉塔。CLIP仍然是纯图像-文本检索的默认值，其中特定的LAION-2B训练分布与您的查询模式匹配。

### 对齐，基本，开夹，eva夹

ALIGN（谷歌，2021）：与CLIP相同，1.8B对尺度，90%噪声。证明了噪声数据的规模。OpenCLIP (LAION)：在LAION- 400m / 2B上开放复制CLIP，多个尺度，去打开检查点。EVA-CLIP：从遮罩图像建模初始化；VLMs的强骨干。基本：b谷歌的CLIP+ALIGN混合。都是同一个系列，不同的数据和调优。

### 零射击上限

clip类模型上限约为76% ImageNet零射击（CLIP-G, OpenCLIP-G）。Beyond要么需要更大的数据（SigLIP 2获得80%以上），要么需要架构变化（有监督的头部，更多参数）。基准已经饱和；真正的价值是下游vlm消耗的嵌入空间。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| InfoNCE | "Contrastive loss" | Cross-entropy over a batch's similarity matrix; each item's positive is its paired item, negatives are everything else |
| Sigmoid loss | "SigLIP loss" | Per-pair binary cross-entropy; no softmax, no all-gather, scales cheaply in distributed training |
| Temperature | "tau" | Scalar that scales logits before softmax/sigmoid; controls sharpness of the distribution |
| Zero-shot | "no-finetune classification" | Use text prompts to construct class embeddings and classify by cosine similarity; no training on target classes |
| Prompt template | "a photo of a ..." | Text scaffold around a class name; affects zero-shot accuracy by 1-5 points |
| Dual encoder | "Two-tower" | One image encoder + one text encoder, outputs in shared D-dim space |
| Hard negative | "Tough distractor" | A negative similar enough to the positive that the model has to work to separate them |
| Linear probe | "Frozen + one layer" | Train only a linear classifier on top of frozen features; measures feature quality |
| NaFlex | "Native flexible resolution" | SigLIP 2 capability to ingest images at any aspect ratio and resolution without resizing |
| Temperature scaling | "log-parametrized tau" | CLIP parametrizes `log(1/tau)` so gradients behave; clips to prevent collapse to near-zero tau |
