# 提示注入与PVE防御

> Greshake等人（AISec 2023）建立了间接提示注入作为def 代理安全问题。攻击者在代理检索到的数据中植入指令；在摄取时，这些指令将覆盖开发人员提示。将所有检索到的内容视为工具使用界面上的任意代码执行。

**Type:** Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 14 · 06 (Tool Use), Phase 14 · 21 (Computer Use)
**Time:** ~75 minutes

## 学习目标

- 说明Greshake等人的间接提示注入威胁模型。
- 列出五个已演示的漏洞利用类（数据窃取、蠕虫攻击、持久内存中毒、生态系统污染、任意工具使用）。
- 描述一下2026年的防御原则：不可信的内容，允许列表导航，每步安全，护栏，人在环，外部捕获。
- 实现PVE（提示-验证器-执行器）模式——在昂贵的主模型提交到工具调用之前，实现廉价的快速验证器。

## 这个问题

llm不能可靠地区分来自用户的指令和来自检索内容的指令。一个PDF文件、一个网页、一个记忆笔记或一个以前的代理回合都可以携带

这是2024-2026年的代理安全问题。每个生产主体都必须防范它。

## 这个概念

### Greshake等人，AISec 2023 （arXiv:2302.12173）

攻击类别：**间接提示注入**。

- 攻击者控制内容代理将检索：网页，PDF，电子邮件，记忆笔记，搜索结果。
- 当被摄取时，该内容中的指令将覆盖开发人员提示。
- 演示了针对Bing Chat， GPT-4代码完成，合成代理的漏洞利用：
  - **数据盗窃** -代理泄漏会话历史到攻击者控制的URL。
  - **蠕虫注入的内容指示代理在下一个输出中嵌入漏洞。
  - **持久内存中毒** -代理存储攻击者的指令；在下次会议上重新毒害自己。
  - **信息生态系统污染**——注入的事实通过共享内存传播给其他代理。
  - **任意工具使用** -注册表中的任何工具都可以被攻击者访问。

中心声明：处理检索到的提示等同于在代理的工具使用表面上执行任意代码。

### 2026年的国防学说

在供应商指南中聚合的六个控制：

1. **将所有检索到的内容视为不可信。** OpenAI CUA文档：“只有来自用户的直接指令才算作许可。”
2. **允许列表/黑名单导航。**缩小代理可以触摸的url、域或文件的集合。
3. **每步安全评估。**双子座2.5计算机使用模式-在执行前评估每个操作。
4. **工具输入和输出的护栏。第16课（OpenAI Agents SDK）；第06课（参数验证）。
5. ** Human-in-the-loop确认。**登录，购买，验证码，发送消息-人类决定。
6. **内容捕获与外部存储。**第23课—外部存储检索到的内容；跨度包含参考文献，而不是散文；事件是可审计的。

### 通过:Prompt-Validator-Executor

结合多个控件的部署模式：

- 一个**便宜、快速的**验证器模型在**昂贵的主模型**提交之前运行在每个候选工具调用上。
- 验证器检查：此操作是否与用户声明的意图一致？动作是否触及敏感表面？在参数中是否存在注入型内容？
- 如果验证器拒绝，主模型被告知“该操作被拒绝；尝试不同的方法。”

权衡：每个工具调用都有额外的推断。对于绝大多数代理产品来说，这是廉价的保险。

### 防御失败的地方

- **没有内容源元数据。**如果系统无法区分“此文本来自用户”和“此文本来自网页”，则无法区分权限级别。
- **所有护栏在尽头。**如果验证只在最终输出上运行，则模型已经接触了世界。
- **仅依靠指令跟随。“系统提示忽略不受信任的指令”不是强制执行的。
- **检索内存的过度信任。**昨天的代理人写了一封有毒的记忆笔记；今天的经纪人读它。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Indirect prompt injection | "Injection in retrieved content" | Instructions embedded in data the agent retrieves |
| Direct prompt injection | "Jailbreak" | User-supplied prompt bypasses guardrails |
| PVE | "Prompt-Validator-Executor" | Cheap fast validator before expensive main inference |
| Source tag | "Content provenance" | Metadata marking where content came from |
| Allowlist navigation | "URL whitelist" | Agent can only visit approved destinations |
| Worming | "Self-replicating exploit" | Injected content includes instructions to propagate |
| Memory poisoning | "Persistent injection" | Injected content stored as memory; re-poisons next session |
