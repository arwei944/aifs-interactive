# 水印-合成，稳定签名，C2PA

> 三种技术构建2026人工智能生成的内容来源。SynthID（谷歌DeepMind） - 2023年8月推出图像水印，2024年5月推出文本+视频（Gemini + Veo）， 2024年10月通过Responsible GenAI Toolkit开源文本，2025年11月与Gemini 3 Pro一起统一多媒体检测器。文本水印会不知不觉地调整下一个标记的采样概率；图像/视频水印在压缩、裁剪、滤镜和帧率变化中仍然存在。稳定签名（Fernandez等人，ICCV 2023, arXiv:2303.15435） -微调潜在扩散解码器，使每个输出包含固定消息；裁剪（内容的10%）生成的图像在FPR< 1e6时检测到>90%。后续“稳定签名是不稳定的”（arXiv:2405.07145, 2024年5月）-微调去除水印，同时保持质量。C2PA—加密签名、防篡改元数据标准（C2PA 2.2 interpreter 2025）。水印和C2PA是互补的：元数据可以被剥离，但具有更丰富的来源；水印在转码过程中仍然存在，但携带的信息较少。

## 学习目标

- 描述令牌级水印（合成文本样式）及其检测机制。
- 描述稳定签名和破坏它的2024移除攻击。
- 说明C2PA的作用以及为什么它是水印的补充。
- 描述关键的限制：特定于模型的信号、释义下的鲁棒性和意义保留攻击（arXiv:2508.20228）。

## 这个问题

2023-2024年，深度造假和人工智能生成的内容大规模进入政治和消费者环境。水印是提出的技术来源信号：在生成时标记代，之后检测它们。2025证据：没有水印是无条件鲁棒的，但与C2PA元数据分层的组合提供了一个可用的来源故事。

## 这个概念

### 文本水印（SynthID-text样式）

Kirchenbauer et al. 2023机制，由谷歌产生：

1. 在每个解码步骤中，对前面的K个标记进行散列，以生成词汇表的伪随机分区，分为“绿色”集和“红色”集。
2. 通过在绿色对数上加上δ，使抽样偏向绿色集。
3. 这一代包含的绿色代币比随机产生的要多。

检测：重新散列每个前缀，计算生成中的绿色标记，计算z分数。对于带水印的文本，z-score为>，对于人类文本，z-score为~0。

属性:
- 读者无法察觉（δ足够小，质量损失很小）。
- 通过访问词汇表配分函数来检测。
- 改写文本不可靠——重写文本会破坏信号。

SynthID-text将于2024年10月通过b谷歌的Responsible GenAI Toolkit开源。

### 稳定签名（图片）

Fernandez等人。ICCV 2023。微调潜扩散解码器，使每个生成的图像包含一个固定的二进制信息嵌入在潜表示。检测用神经解码器从潜在信号中解码。裁剪（内容的10%）图像在FPR< 1e6时检测到>90%。

2024年5月“稳定签名是不稳定的”（arXiv:2405.07145）：微调解码器去除水印，同时保持图像质量。对抗性的后一代微调是廉价的；水印的对抗鲁棒性是有限的。

### SynthID统一探测器（2025年11月）

除了Gemini 3 Pro之外，还有一个多媒体检测器，可以在一个API中读取文本、图像、音频和视频中的SynthID信号。统一谷歌来源堆栈。

### C2PA

内容来源和真实性联盟。加密签名防篡改元数据标准。c2pa2.2解释器（2025）。C2PA清单记录由创建者密钥签名的来源声明（谁创建、何时创建、进行了哪些转换）。

与水印互补的：
- 元数据可以被剥离；水印不能（很容易）。
- 元数据丰富（完整的来源链）；水印带有比特。
- C2PA取决于平台的采用；水印自动嵌入。

谷歌集成了搜索、广告和“关于这张图片”。

### 限制

- **模型相关的。** SynthID水印从启用SynthID的模型生成。没有SynthID的模型的生成是没有水印的，因此“没有SynthID信号”不能证明其真实性。
- **解释。**文本水印不能保存意义的释义。
- **转换攻击。** arXiv:2508.20228（2025）展示了同时破坏文本水印和许多图像水印的意义保留攻击。
- **微调。**每“稳定签名是不稳定的，”后一代微调删除嵌入的水印。

### EU AI Act Article 50

《人工智能生成内容标签透明度规范》(2025年12月初稿，2026年3月二稿，预计2026年6月定稿截至2026年4月，该准则仍处于草案阶段，时间表可能会发生变化。监管层需要技术层。深度造假必须贴上标签。

## 使用它

Z0令牌是整数0..N-1；水印采样偏向哈希def 的绿色集。检测器计算绿色标记z分数。您可以在1000个标记生成时观察检测，观察释义破坏信号，并测量人类文本的误报率。

## 船这

这一课产生了给定一个带有来源声明的内容部署，它会审计：水印机制（如果有的话）、C2PA签名链（如果有的话）、每个机制的对抗鲁棒性，以及每个模态的覆盖范围。

## 练习

1. 运行报告带有水印的1000个令牌生成与人工编写文本的z分数。在95%的置信阈值上确定假阳性率。

2. 实施释义攻击，用同义词替换30%的令牌。重新测量z分数。

3. 阅读Kirchenbauer等人。2023第6节关于稳健性。为什么文本水印在意译下失效，而图像水印在裁剪后仍然存在？

4. 设计一个使用synid -text + C2PA元数据的部署。描述消费者看到的来源链。确定每个部件的一种失效模式。

5. 2024年的“稳定签名是不稳定的”结果显示微调消除了图像水印。设计一个部署控制来限制这种攻击——例如，要求对经过微调的检查点进行签名发布。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| SynthID | "Google's watermark" | Cross-modal provenance signal; text, image, audio, video |
| Token watermark | "Kirchenbauer-style" | Biased-sampling text watermark detectable via green-token z-score |
| Stable Signature | "image watermark" | Fine-tuned-decoder watermark; ICCV 2023 |
| C2PA | "the metadata standard" | Cryptographically signed tamper-evident provenance metadata |
| Paraphrase robustness | "does rewording break it" | Text watermark property; currently limited |
| Fine-tune removal | "adversarial unwatermark" | Attack that removes image watermark via decoder fine-tuning |
| Cross-modal detector | "unified SynthID" | November 2025 unified API across modalities |
