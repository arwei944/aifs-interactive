# LLaVA和视觉指令调优

> LLaVA（2023年4月）是地球上被复制最多的多模式建筑。它用2层MLP取代了BLIP-2的Q-Former，用朴素的token连接取代了Flamingo的门状交叉注意，并训练了GPT-4从纯文本标题生成的158k视觉指令回合。任何在2023年至2026年之间构建VLM的从业者都构建了LLaVA的某些变体。LLaVA-1.5增加了任何res。LLaVA-NeXT提高了分辨率。LLaVA-OneVision将图像，多图像和视频统一在一个配方中。本节课将阅读食谱，实现投影仪，并解释为什么“更简单”。

**Type:** Build
**Languages:** Python (stdlib, projector + instruction-template builder)
**Prerequisites:** Phase 12 · 02 (CLIP), Phase 11 (LLM Engineering — instruction tuning)
**Time:** ~180 minutes

## 学习目标

- 构建一个2层MLP投影仪，将ViT补丁嵌入（dim1024）映射到LLM的嵌入暗淡（dim4096）。
- 走LLaVA的两步配方：(1)投影仪对准558k字幕对，(2)视觉指令调整158k gpt -4生成的转弯。
- 用图像令牌占位符、系统提示符和用户/助手提示符构造一个llava格式的提示符。
- 解释为什么社区从Q-Former转向MLP，尽管Q-Former赢得了代币预算。

## 这个问题

BLIP-2的Q-Former（第12.03课）将图像压缩为32个令牌。干净，高效，适合基准测试。但它有两个问题。

首先，Q-Former是可训练的，但它的损失不是最后的任务。第一阶段训练ITC+ITM+ITG。第二阶段训练LM损失。查询学习一些中间表示，然后LLM必须对其进行解码。信息在瓶颈中丢失。

其次，Q-Former需要188M参数，在LLaVA的2023年规模下，你必须与目标LLM共同设计它。更换LLM，重新培训Q-Former。改变视觉编码器，重新训练。每个组合都是一个独立的研发项目。

LLaVA的答案简单得令人尴尬：取ViT的576个补丁令牌，通过一个2层MLP (没有瓶颈。没有针对奇怪目标的第一阶段预训练。只要让MLP接受直接LM损失的训练。

数据从何而来？LLaVA的第二个见解：使用GPT-4（纯文本）生成指令数据。为GPT-4提供图像的COCO标题和边界框数据，要求它生成对话、描述和复杂的推理问题。158k个指令响应回合免费。没有人工注释。

结果是：一个在8个a100上运行一天的VLM，在MMMU上击败了Flamingo，并发布了一个开放的检查站，社区可以扩展。到2023年底，它已经衍生了50多个分支。

## 这个概念

### 体系结构

LLaVA-1.5 at 13B：
- 视觉编码器：CLIP vitl /14 @ 336（在第一阶段冻结，可选在第二阶段解冻）。
- 投影仪：2层MLP与GELU激活，
- LLM：Vicuna-13B（后来的Llama-3.1-8B）。

转发一个图像+文本提示符：

```
img -> ViT -> 576 patches of dim 1024
patches -> MLP -> 576 tokens of dim 4096
prompt: system + "<image>" placeholder + user question
replace <image> token with the 576 projected tokens
feed the full sequence to the LLM
decode response
```

该映像占用LLM上下文的576个令牌。在2048个上下文中，这为文本留下了1472个标记。在32k上下文中，这是一个舍入误差。

### 第一阶段：投影仪校准

冻结ViT。冻结LLM。只训练2层MLP。数据集：558k图像标题对（LAION-CC-SBU）。损失：字幕上的语言建模，以投影图像标记为条件。

在批次128的单个epoch中，这在几个小时内完成。投影仪学习将vit空间映射到llm空间。没有特定任务的监督。

### 第二阶段：视觉指令调整

解冻投影仪（仍可训练）。解冻LLM（通常是完全解冻，有时是解冻）。进行158k视觉指导转弯训练。

指令数据是关键。Liu等通过：
1. 拍摄一张COCO图像。
2. 提取文本描述（5个人工标题+装订框列表）。
3. 发送给GPT-4，有三个提示模板：
   - 对话：“在用户和助手之间生成关于该图像的来回对话。”
   - 详细描述：“对图像进行丰富、详细的描述。”
   - 复杂推理：“提出一个需要对图像进行推理的问题，然后回答。”
4. 将GPT-4的输出解析为（指令、响应）对。

这些都不直接涉及图像，只涉及文本描述。GPT-4产生可信的图像内容。虽然有些噪音，但效果不错：158k个回合足以开启对话。

### 为什么社区会复制这个

- 没有针对第一阶段的损失需要调整。整个LM损失。
- 投影仪训练需要几个小时，而不是几天。
- LLM可以通过重新训练投影仪来交换（LLaVA-Llama2, LLaVA-Mistral, LLaVA-Llama3）。
- 可视化教学数据管道使用GPT-4，为新领域再生成本低。

### LLaVA-1.5和LLaVA-NeXT

LLaVA-1.5（2023年10月）增加：
- 学术任务数据（VQA， OKVQA, RefCOCO）混合到指令调优中。
- 更好的系统提示。
- 2048→32k语境。

LLaVA-NeXT（2024年1月）新增：
- AnyRes：将高分辨率图像分割成336x336作物的2x2或1x3网格，加上一个全局低分辨率缩略图。每个作物变成576个代币；每个图像总共约有2880个视觉标记。OCR和图表任务大幅增加。
- 与ShareGPT4V（高质量GPT-4V字幕）更好的指令数据混合。
- 强碱llm （Mistral-7B, Yi-34B）。

### LLaVA-OneVision

第12.08课深入介绍了OneVision。简短版本：相同的投影仪，但培训课程涵盖单图像，多图像和视频在一个模型共享视觉令牌预算。

### 与Q-Former的比较

| | Q-Former (BLIP-2) | MLP (LLaVA) |
|---|---|---|
| Visual tokens per image | 32 | 576 (base) or 2880 (AnyRes) |
| Trainable params | 188M + LM | 40M + LM |
| Stage 1 loss | ITC+ITM+ITG | LM only |
| LLM drop-in | Requires retrain | Swap with minimal retrain |
| Multi-image | Awkward | Natural (concat) |
| Video | Awkward | Natural (per-frame concat) |
| Token budget | Small | Large |

MLP的优势在于简单性和令牌的灵活性。Q-Former赢得了象征性的预算。到2023年底，令牌预算不再是绑定约束（LLM上下文增长到32k-128k+），简单性占主导地位。

### 提示格式

```
A chat between a curious human and an artificial intelligence assistant. The assistant gives helpful, detailed, and polite answers to the human's questions. USER: <image> Describe this image in detail. ASSISTANT: The image shows ...
```

Z0在标记化之前，它被替换为576个视觉标记（或2880个AnyRes）。Tokenizer看到的序列比训练时稍微长一些，但LLM处理新的输入，因为阶段1教会了它。

### 经济参数

llava - 1.5 - 7 b分解:
- CLIP vitl /14 @ 336: 303M（冷冻阶段1，通常为非冷冻阶段2）。
- 投影仪（2倍线性）：~22M可训练。
- Llama-7B: 7 b。
- 总计：73亿参数。第二阶段可训练：全7B + 22M投影仪。

第二阶段的培训费用：在8xA100上约20小时。这是关键数字，一天，一个节点，可复制。这就是lava传播的原因。

## 使用它


1. 2层MLP投影仪（暗16→32→32玩具规模）纯Python。
2. 提示构建管道：系统提示+
3. 一个可视化器，用于显示在LLM上下文中576个令牌可视化块的样子（2k / 32k / 128k上下文所消耗的百分比）。

## 船这

这一课产生了给定一个llava家族检查点，它运行一个10提示的振动评估套件（3个字幕，3个VQA， 2个推理，2个拒绝），并报告一个人类可读的记分卡。不是基准；烟雾测试，以确认投影仪和LLM连接良好。

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Projector | "MLP bridge" | 2-layer MLP with GELU mapping ViT dim to LLM dim |
| Image token | "<image> placeholder" | Prompt marker replaced by N projected visual tokens before inference |
| Visual instruction tuning | "LLaVA stage 2" | Training on GPT-4-generated (image, instruction, response) triplets |
| Stage 1 alignment | "Projector pretraining" | Freeze ViT and LLM, train projector with LM loss on captions |
| AnyRes | "Multi-crop tiling" | Split high-res image into a tile grid and concatenate each tile's visual tokens |
| LLaVA-Instruct | "GPT-4-generated" | 158k instruction-response pairs synthesized from COCO captions + GPT-4 |
| Vision encoder freeze | "Backbone locked" | CLIP weights do not update in stage 1, sometimes not in stage 2 either |
| ShareGPT4V | "Better captions" | 1M dense captions generated by GPT-4V, used for higher-quality alignment |
| VQA | "Visual question answering" | Task of answering a free-form question about an image |
| Prismatic VLMs | "Design-space paper" | Karamcheti 2024 ablation systematically testing projector and data choices |
