# 绘制，绘制和图像编辑

> 文本到图像的转换创造了新事物。油漆修复旧的。在制作中，70%的可计费图像工作是编辑——交换背景，删除徽标，扩展画布，重新生成手。在绘画中，扩散得以维持。

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 8 · 07 (Latent Diffusion), Phase 8 · 08 (ControlNet & LoRA)
**Time:** ~75 minutes

## 这个问题

一个客户发来一张完美的产品照片，背景是一个分散注意力的标志。你想要擦除符号，并保持所有其他像素相同。你不能从头开始运行文本到图像——结果会有不同的颜色，不同的照明，不同的产品角度。您希望再生“仅”被遮挡的区域，并且希望再生能够尊重周围的环境。

这就是绘画。变体:

- * *修复。**在蒙版内部再生，保留外部像素。
- * * Outpainting。**在面具外（或画布外）再生，留在面具内。
- * *图像编辑。**重新生成整个图像，但保持语义或结构保真度的原始（SDEdit, InstructPix2Pix）。

2026年的每个扩散管道都有一个喷漆模式。Flux.1-Fill, Stable Diffusion Inpaint, SDXL-Inpaint, dall - e3 Edit。它们的工作原理是一样的。

### 幼稚的方法（以及为什么它是错误的）

使用掩码运行标准的文本到图像转换。在每个采样步骤中，用前向扩散的干净图像替换噪声潜伏的未掩蔽区域。它的工作原理……不好。边界伪影会渗透进来，因为模型没有关于被掩盖区域的信息。

### 正确的喷漆模型

训练一个修改后的U-Net，它接受9个输入通道而不是4个输入通道：

```
input = concat([ noisy_latent (4ch), encoded_image (4ch), mask (1ch) ], dim=channel)
```

额外的通道是vae编码的源图像的副本加上单通道掩码。在训练时，你随机屏蔽图像的区域，训练模型只去噪被屏蔽的区域，而未被屏蔽的区域作为一个干净的调理信号给出。在推理时，模型可以“看到”被掩盖区域周围的东西，并产生连贯的补全。

SD-Inpaint, SDXL-Inpaint， Flux-Fill都使用这个9通道（或模拟）输入。扩散器

### InstructPix2Pix （Brooks et al., 2023）

微调扩散模型在推理时，输入图像和文本指令的条件（“使其日落”，“添加龙”）。两种CFG尺度：图像尺度和文本尺度。

### 重新粉刷（Lugmayr et al., 2022）

保持一个标准的无条件扩散模型。在每一个反向步骤中，重新采样-偶尔跳回噪声状态并重新生成。避免边界伪影。当你没有训练有素的绘画模型时使用。

## 构建它

Z0我们在5- d混合数据上训练DDPM，其中每个样本是来自两个聚类之一的5个浮动。在推理时，我们“屏蔽”5个维度中的2个，在每一步注入未屏蔽的3个维度的噪声前向版本，并仅重新生成被屏蔽的维度。

### Step 2: train denoiser over all 5 dims

Standard DDPM. Net outputs 5-D noise prediction for 5-D noisy input.

### Step 3: at inference, mask-aware reverse

```python
def inpaint_step(x_t, mask, clean_image, alpha_bars, t, rng):
    # replace unmasked dims with a freshly noised version of the clean source
    a_bar = alpha_bars[t]
    for i in range(len(x_t)):
        if not mask[i]:
            x_t[i] = math.sqrt(a_bar) * clean_image[i] + math.sqrt(1 - a_bar) * rng.gauss(0, 1)
    # ...then run the normal reverse step on x_t
```

这是一种幼稚的方法，它适用于玩具1-D数据。真正的图像在绘画中使用9通道输入，因为纹理一致性更重要。

### 第四步：涂漆

外涂是用蒙版倒置的内涂：蒙版在新的（以前不存在的）画布上，用原始的填充其余部分。相同的训练目标。

## 陷阱

- * *。**幼稚的方法留下了可见的边界，因为梯度信息不会流过蒙版。修正：扩大掩模8-16像素，或使用适当的油漆模型。
- * *面具泄漏。**如果调理图像的未掩码区域质量低或有噪声，则会污染掩码内的生成。稍微去噪或模糊。
- **CFG与掩码大小相互作用。**小掩模上的高CFG =饱和贴片。减少CFG的小编辑。
- **忠诚悬崖。**从检查和检查点。
- * *提示不匹配。提示符应该描述整个图像，而不仅仅是新的内容。“一只猫坐在椅子上”而不是“一只猫”。

## 使用它

| Task | Pipeline |
|------|----------|
| Remove object, small mask | SD-Inpaint or Flux-Fill, standard prompt |
| Replace sky | SD-Inpaint + "blue sky at sunset" |
| Extend canvas | SDXL outpaint mode (8px feather) or Flux-Fill with outpaint mask |
| Regenerate hand / face | SD-Inpaint with prompt re-describing the subject + ControlNet-Openpose |
| Change style of one region | SDEdit at `t/T=0.5` on masked region |
| "Make it sunset" | InstructPix2Pix or Flux-Kontext |
| Background replacement | SAM mask → SD-Inpaint |
| Ultra-high-fidelity | Flux-Fill or GPT-Image (hosted) for hardest cases |

## 练习

1. * *容易。**中油漆质量（掩模中残留）在多大比例下等于无条件生成？
2. * *介质。**实现重绘：在每10个反向步骤，跳回5步（添加噪音）和重新去噪。测量它是否减少了掩模边缘的边界残留。
3. * *难。**使用拥抱面部扩散器来比较：SD 1.5 Inpaint + ControlNet-Openpose vs Flux.1-Fill在20个面部再生任务上。分数分别构成了依从性和身份保持。

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Inpainting | "Fill the hole" | Regenerate inside a mask; keep outside pixels. |
| Outpainting | "Extend the canvas" | Regenerate outside the canvas; keep inside. |
| 9-channel U-Net | "Proper inpainting model" | U-Net with `noisy | encoded-source | mask` as input. |
| SDEdit | "Img2img with noise level" | Noise to time `t`, denoise with new prompt. |
| InstructPix2Pix | "Text-only edits" | Fine-tuned diffusion on (image, instruction, output) triples. |
| RePaint | "No retraining" | Re-noise periodically during reverse to reduce seams. |
| SAM | "Segment Anything" | Mask generator by clicks or boxes; pairs with inpaint. |
| Flux-Kontext | "Edit with context" | Flux variant that accepts a reference image + instruction for edits. |

## 生产说明：编辑管道对延迟敏感

编辑图像的用户期望不到5秒的往返时间。在1024²下，30步SDXL-Inpaint在L4上是3-4秒，加上SAM掩码生成（~200毫秒）和VAE编码/解码（~500毫秒）。在生产框架中，这是ttft约束而不是吞吐量约束-批1，低并发性，最小化每个阶段：

- SAM-H比较慢。** SAM-H在1024²时为~200 ms；SAM-ViT-B为~40 ms，质量损失较小。SAM 2（视频）增加了时间开销；不要将其用于单个图像编辑。
- **可能时跳过编码。**如果你拥有来自上一代的潜在内容（典型的迭代编辑ui），请直接传递它们
- 掩码扩张对吞吐量也有影响。**一个小的掩码意味着大部分的U-Net前传被浪费了（未掩码的像素无论如何都会被夹住）。`diffusers`' `StableDiffusionInpaintPipeline` runs the full U-Net regardless; 只有9通道的适当油漆变体利用掩码计算。
- **Flux-Kontext是2025年的答案。**单向前传球在H100上，它会在1.5秒内完成编辑。建筑学的教训是：将阶段分解。
