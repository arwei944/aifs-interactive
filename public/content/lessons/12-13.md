# 输血：自回归文本+扩散图像在一个变压器

> 变色龙和Emu3把所有的赌注都押在了不同的代币上。它们是有效的，但是量化瓶颈是可见的——连续空间扩散模型下的图像质量趋于稳定。输血（Meta， Zhou等人，2024年8月）采取了相反的赌注：保持图像连续，完全放弃VQ-VAE，用两个损失训练一个变压器。文本标记获得下一个标记预测。图像补丁得到流匹配/扩散损失。两个目标优化相同的权重。基于稳定扩散3 （MMDiT）的体系结构是一个近亲。本课阅读输血论文，建立一个玩具双损训练器，并追踪注意力面具，让一个变压器做两项工作。

**Type:** Build
**Languages:** Python (stdlib, two-loss trainer on MNIST-scale toy)
**Prerequisites:** Phase 12 · 11 (Chameleon), Phase 8 (Generative AI)
**Time:** ~180 minutes

## 学习目标

- 在一个主干上连接一个运行两个损耗（文本令牌上的NTP，图像补丁上的弥散MSE）的变压器。
- 解释为什么跨图像补丁的双向注意加上文本标记的因果注意是正确的蒙版选择。
- 比较输血风格（连续图像，扩散损失）和变色龙风格（离散图像，NTP）在计算，质量和代码复杂性。
- 命名MMDiT的贡献：每个块的模态特定权重，剩余流的联合关注。

## 这个问题

离散与连续图像令牌之争早于llm。连续表示（原始像素，VAE潜在）保留细节。离散标记（VQ索引）适合变压器的本地词汇表，但在量化步骤中失去细节。

变色龙/ Emu3是离散的：一个损失，一个架构，但图像保真度受到标记器质量的限制。

扩散模型是连续的：出色的图像质量，但从LLM中分离出来的模型，复杂的噪声调度工程，没有与文本生成清晰的集成。

输血问：我们能两者兼得吗？保持图像连续，仍然训练一个模型，使用两个损失缝合成一个梯度步骤。

## 这个概念

### 双损耗架构

一个纯解码器转换器处理的序列包含：

- 文本标记（离散的，来自BPE词汇表）。
- 图像补丁（通过线性嵌入将连续的16x16像素块投影到隐藏的昏暗中-与ViT编码器的输入相同）。
- Z0

向前传球一次。loss从每个token的两个正面中选择一个：

- 对于文本标记：在词汇-逻辑头部的标准交叉熵。
- 对于图像补丁：连续补丁上的扩散损失-预测每个补丁上添加的噪声。

该梯度流过共用变压器本体。这两种损失同时提高了共享权值。

### 注意面具：因果文本+双向图像

文本标记必须是因果的——你不能让文本标记关注未来的文本，或者老师强迫中断。然而，图像补丁代表一个快照；它们应该在同一图像块内双向地相互关注。

面具:

```
M[i, j] = 1 if:
  (i is text and j is text and j <= i)   # causal for text
  OR (i is image and j is image and same_image_block(i, j))   # bidirectional within image
  OR (i is text and j is image and j < i_image_end)   # text attends to previous images
  OR (i is image and j is text and j < i_image_start)   # image attends to preceding text
```

在训练和推理时实现为块三角形掩码。

### 变压器内部扩散损耗

扩散损失是标准的：向图像斑块添加噪声，要求模型预测噪声（或等效的干净斑块）。输血的版本使用流动匹配-预测从嘈杂到清洁的速度场。

在训练:
1. 对于每个图像补丁x0，采样一个随机的时间步长t。
2. 样本噪声ε，计算xt = (1-t) * x0 + t * ε（流量匹配线性插值）。
3. 变压器预测v_theta(xt, t)；loss = MSE（v_theta(xt, t), ε - x0）。
4. 从同一序列回溯与文本NTP丢失。

在推理中，代为：
- 文本标记：标准的自回归抽样。
- 图像补丁：扩散采样循环（典型的10-30步）以先前的文本标记为条件。

### MMDiT：稳定扩散3的变体

Stable Diffusion 3 （Esser等人，2024年3月）与Transfusion几乎同时推出MMDiT（多模态扩散变压器）。这两个体系结构是兄弟关系。

MMDiT的主要区别：

- 每个块的模态特定权重。对于文本令牌和图像补丁，每个变压器块都有单独的Q、K、V和MLP权重。注意是联合的（跨模态）；其他的都是特定于模态的。
- 整流训练。一个特定的流匹配变体，具有已知的采样和比DDPM更简单的数学。
- 规模。MMDiT是SD3 （2B和8B参数变体）的骨干。输血的纸张有7B。

两者都集中在同一个核心思想上：一个变压器在文本上运行NTP，在连续图像表示上运行扩散。

### 为什么这打败了变色龙风格

连续扩散与离散ntp在图像生成上的质量差距是可测量的。输血纸报告：

- 在7B参数下，在FID上击败相同尺寸的变色龙风格模型3-5分。
- 不需要标记器训练-图像编码器更简单（线性投影到隐藏，与ViT的输入层相同）。
- 推理可以并行化图像patch去噪，不像自回归图像标记。

缺点：输血是一种双重损失模式，使训练动态更加棘手。损失权重需要调整。NTP和扩散之间的调度不匹配可能导致一个头占主导地位。

### 下游是什么？

Janus-Pro（第12.15课）通过解耦视觉编码器来改进输血的想法，以便理解和生成- SigLIP用于一个，VQ用于另一个-同时共享变压器体。Show-o（第12.14课）将扩散替换为离散扩散（掩模预测）。统一世代的家族在输血后迅速分支。

2026年生产的发射图像的VLMs——Gemini 3 Pro、GPT-5、Claude Opus 4.7的图像生成路径——几乎肯定使用了这个家族的一些后代。细节是专有的。

## 使用它

Z0

- 文本标题是描述数字（0-9）的短整数序列。
- 图像是4x4的字节网格。
- 一对共重线性投影充当变压器的替身；文本上的NTP损失，噪声补丁上的MSE损失。
- 训练循环交替出现两种损失，注意罩是显性的。
- 生成一个文本标题和一个4x4图像在一个向前传递。

变压器是一个玩具。双损耗管道、注意力掩模结构和推理回路是真正的人工制品。

## 练习

1. 输血风格的模型训练70%的文本标记和30%的图像补丁。图像扩散损失约为文本NTP损失的10倍。什么样的减肥方法能平衡他们？

2. 为一个序列实现块三角形掩码：将每个条目标记为0或1。

4. 生成：给定一个文本提示符，该模型为50个令牌运行NTP，然后点击总共有多少次向前传球？

## 关键术语

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Two-loss training | "NTP + diffusion" | A single transformer optimizes both cross-entropy on text tokens and MSE on continuous image patches in the same gradient step |
| Flow matching | "Rectified flow" | Diffusion variant that predicts a velocity field from noise to clean data; simpler math than DDPM |
| MMDiT | "Multimodal DiT" | Stable Diffusion 3's architecture: joint attention, modality-specific MLPs and norms |
| Block-triangular mask | "Causal text + bidirectional image" | Attention mask that is causal across text but bidirectional within image regions |
| Continuous image representation | "No VQ" | Image patches as real-valued vectors, not integer codebook indices |
| Velocity prediction | "v-parameterization" | Network output is the velocity field between noise and data, not the noise itself |
