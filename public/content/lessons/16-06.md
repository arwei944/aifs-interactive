# Hierarchical architecture and its failure modes

> Stratification is the nesting of supervisors. Managers and agents are superior to junior managers and employees. The LangGraph of crew equivalence is a natural pattern when the task is a true organizational chart. This is also the most likely pattern to fall into a management cycle - managers and agents fail to allocate work effectively, misunderstand offspring, or fail to reach a consensus. Order often prevails over it.

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 05 (Supervisor Pattern)
**Time:** ~60 minutes

## "Problem"

Once the supervisor model succeeds, the next step is naturally "What if the workers themselves are supervisors?" The team has sub-teams. The company has departments within departments. The hierarchical structure reflects this.

The problem is: A master of laws manager is different from a human manager. Human managers have a stable prior to what they know about their reports. The Master of Laws manager rereasons the organization from its context every time. In this case, even the slightest deviation will cause the entire tree to misallocate its work.

## Concept

### The shape

```
                 Manager
                 ┌─────┐
                 └──┬──┘
           ┌────────┴────────┐
           ▼                 ▼
       Sub-Mgr A         Sub-Mgr B
       ┌─────┐           ┌─────┐
       └──┬──┘           └──┬──┘
         ┌┴──┬──┐          ┌┴──┐
         ▼   ▼  ▼          ▼   ▼
       W1  W2  W3         W4  W5
```

Each internal node conducts planning, delegation and synthesis. Only leaves work.

### Where it shines

- Clear the organizational mapping. If the real task is the department (" legal review documents, financial review documents, engineering review documents, and then summarize and execute "), then the hierarchical structure is clear.
- Local summary. Each deputy manager compiles the output of their team before the top manager sees it. The top management sees the summaries of three lower-level managers rather than the outputs of fifteen employees.

### The place of fracture

Autopsies in 2026 continuously discovered three failure modes:

1. Task allocation error. The manager reads the target, creates the illusion of decomposition, and delegates it to the wrong deputy manager. Because the deputy manager obediently carried out the tasks assigned to him, errors would only occur at the highest synthesis level - this level is one layer away from where humans might find errors.
2. "Output misunderstanding." The deputy manager returned, "Claim x cannot be verified." The senior manager concluded, "Statement X has not been verified." Meaning drifts at every level.
3. Consensus loop. Two junior managers disagreed. The senior manager demanded that they reach a settlement. They were sent down again. The workers resumed operation. The answers given by the junior managers were slightly different. Cycle. Of the crew

### The decisive issue

Sequential (linear pipeline) vs Hierarchical: Does your task actually have independent sub-teams or is it a linear process that pretends to be a tree? If it is the latter, please use the sequence. If it is the former, please use a hierarchical but clearly budgeted reconciliation rule.

### The implementation of CrewAI

Manager 

- Receive top-level tasks
- Assign sub-tasks to team members;
- Evaluate the output of the crew;
- Decide whether to accept, re-delegate or iterate.

Document: https://docs.crewai.com/en/introduction (found in the core concept of "layered process").

### The implementation of LangGraph

LangGraph uses nested supervisors to have their own graphs. The external manager regards the internal graph as an opaque node. In terms of debugging, this is more concise than CrewAI (you can traverse each graph step by step separately), but it is difficult to express the dynamic reshaping of the tree.

Reference: https://reference.langchain.com/python/langgraph-supervisor.

## This ship

If you release a rated game:

- The depth of the hat tree is 2. The third layer has already concealed most of the observable errors.
- A clear adjustment budget. Set the maximum number of rounds that the top manager must submit. Usually 2
- Each synthetic source. The summary of each node must refer to which leaf output produced it.
- Decompose drift alerts. Decomposition of each step of the record manager; Compare user queries. If the decomposition no longer overwrites the query, an alert will be triggered.

## Practice

1. How many levels of management personnel are needed for handover before the issue where the highest output completely deviates from the user?
2. Add the third layer (top→sub→sub-sub→worker). Measure the frequency of self-correction of the disturbance path and the frequency of complete divergence as the depth increases.
3. Implement a "Canary" staff member on each deputy manager, always asking the original user the same questions. Use the Canary answer to detect decomposition drift. How should the manager react when the canary disagrees with the synthesized answer?
4. Read CrewAI's determination of a specific guardrail (step limitation, manager_llm constraint) for CrewAI applications and describe the failure modes it targets.
5. Compare the nested LangGraph manager with the CrewAI hierarchical manager. Does this make the detection cost of the harmonic cycle lower?

## Key terms

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Hierarchical | "Org chart pattern" | Supervisors over supervisors; only leaves do work. |
| Manager LLM | "The boss" | The LLM that decomposes, assigns, and validates at an internal node. |
| Decomposition drift | "The boss lost the plot" | Top manager's split no longer covers the original question. |
| Reconciliation loop | "Endless meetings" | Sub-managers disagree; top re-delegates; workers re-run; loop until budget exhausted. |
| Depth-2 ceiling | "Don't go deeper than 2 levels" | Empirical guardrail: 3+ levels collapses observability. |
| Canary question | "Ground truth at every level" | A worker that is always asked the original query unchanged, to detect drift. |
| Provenance chain | "Who said what" | Trace from each synthesis back to the leaf outputs that produced it. |
