## 这个问题

语言模型完成对提示符的处理，并生成一个50,000 logit的向量。它的词汇表中的每个符号对应一个。现在它必须选一个。如何?

如果它总是选择概率最高的令牌，那么每个反应都是相同的。确定的。无聊。如果它随机选取，输出就是胡言乱语。答案在这两个极端之间的某个地方，而这个地方是由抽样控制的。

抽样并不局限于文本生成。强化学习通过采样轨迹估计策略梯度。VAEs通过从学习到的分布中采样并通过随机性反向传播来学习潜在表示。扩散模型通过采样噪声和迭代去噪来生成图像。蒙特卡罗方法估计没有封闭形式解的积分。MCMC算法探索不可能枚举的高维后验分布。

每个生成式AI系统都是一个采样系统。采样策略决定了输出的质量、多样性和可控性。本课从头开始构建每个主要的采样方法，从均匀随机数开始，并以支持现代llm和生成模型的技术结束。

## 这个概念

### 为什么抽样很重要

采样在人工智能和机器学习中扮演着四个基本角色：

**的一代。**语言模型、扩散模型和gan都通过采样产生输出。采样算法直接控制创造力、连贯性和多样性。温度、顶k和核采样是工程师们每天都在使用的旋钮。

**培训。**小批量随机梯度下降样本。退出样本神经元使其失活。数据增强采样随机转换。在强化学习（PPO， TRPO）中，重要性抽样重新加权样本以减少梯度方差。

**估计。** ML中的许多量没有封闭形式的解。数据分布的预期损失，基于能量模型的配分函数，贝叶斯推理中的证据。蒙特卡罗估计通过对样本进行平均来逼近所有这些。

**探索。** MCMC算法探索贝叶斯推理中的后验分布。进化策略样本参数扰动。汤普森取样平衡了土匪的勘探和开采。

核心挑战：您只能直接从简单分布（均匀分布、正态分布）中采样。对于其他情况，您需要一种方法将简单样本转换为目标分布中的样本。

### 均匀随机抽样

每种抽样方法都从这里开始。一个均匀随机数生成器产生的值在[0,1)中，其中每个相等长度的子区间具有相等的概率。

```
U ~ Uniform(0, 1)

P(a <= U <= b) = b - a    for 0 <= a <= b <= 1

Properties:
  E[U] = 0.5
  Var(U) = 1/12
```

为了从n个项目的离散集合中均匀抽样，生成U并返回地板（n * U）。要从一个连续范围[a， b]中取样，计算a + (b - a) * U。

关键的观点是：一个单一的均匀随机数包含了从任何分布中产生一个样本的正确数量的随机性。关键在于找到正确的变换。

### 逆CDF法（逆变换采样）

累积分布函数（CDF）将值映射到概率：

```
F(x) = P(X <= x)

Properties:
  F is non-decreasing
  F(-inf) = 0
  F(+inf) = 1
  F maps the real line to [0, 1]
```

逆CDF将概率映射回值。如果U ~ Uniform(0,1)，则X = F_inverse(U)服从目标分布。

```
Algorithm:
  1. Generate u ~ Uniform(0, 1)
  2. Return F_inverse(u)

Why it works:
  P(X <= x) = P(F_inverse(U) <= x) = P(U <= F(x)) = F(x)
```

*指数分布的例子：**

```
PDF: f(x) = lambda * exp(-lambda * x),   x >= 0
CDF: F(x) = 1 - exp(-lambda * x)

Solve F(x) = u for x:
  u = 1 - exp(-lambda * x)
  exp(-lambda * x) = 1 - u
  x = -ln(1 - u) / lambda

Since (1 - U) and U have the same distribution:
  x = -ln(u) / lambda
```

当你可以把f_逆写成封闭形式的时候，这就完美地工作了。对于正态分布，不存在封闭形式的逆CDF，因此我们使用其他方法（Box-Muller或数值近似）。

*离散版本：**对于离散分布，将CDF构建为累积和，生成U，并找到累积和超过U的第一个索引

### 拒绝抽样

如果不能反转CDF，但可以将目标PDF计算到一个常数，则拒绝抽样有效。

```
Target distribution: p(x)  (can evaluate, possibly unnormalized)
Proposal distribution: q(x)  (can sample from)
Bound: M such that p(x) <= M * q(x) for all x

Algorithm:
  1. Sample x ~ q(x)
  2. Sample u ~ Uniform(0, 1)
  3. If u < p(x) / (M * q(x)), accept x
  4. Otherwise, reject and go to step 1

Acceptance rate = 1/M
```

边界M越紧，接受率越高。在低维（1-3）中，拒绝抽样效果很好。在高维中，接受率呈指数级下降，因为大多数提案被拒绝。这是拒绝抽样的维度诅咒。

**示例：从截断的正态抽样。**在截断的范围内使用统一的建议。信封M是该范围内正常PDF的最大值。

**示例：从半圆采样。**建议在边界矩形内均匀。如果点落在半圆内，接受。这就是蒙特卡罗计算圆周率的方法：接受率等于面积比pi/4。

### 重要性抽样

有时不需要目标分布p(x)的样本。你需要估计p(x)下的期望，你有来自不同分布q(x)的样本。

```
Goal: estimate E_p[f(x)] = integral of f(x) * p(x) dx

Rewrite:
  E_p[f(x)] = integral of f(x) * (p(x)/q(x)) * q(x) dx
            = E_q[f(x) * w(x)]

where w(x) = p(x) / q(x)  are the importance weights.

Estimator:
  E_p[f(x)] ~ (1/N) * sum(f(x_i) * w(x_i))    where x_i ~ q(x)
```

这在强化学习中至关重要。在PPO（近端策略优化）中，您在旧策略pi_old下收集轨迹，但希望优化新策略pi_new。重要性权重是pi_new(a|s) / pi_old（a|s）。PPO调整了这些权重，以防止新政策与旧政策偏离太远。

重要性抽样估计量的方差取决于q与p的相似程度。如果q与p非常不同，则少数样本会获得巨大的权重并主导估计。自归一化重要性抽样除以权值之和来减少这个问题：

```
E_p[f(x)] ~ sum(w_i * f(x_i)) / sum(w_i)
```

### Monte Carlo Estimation

蒙特卡罗估计通过平均随机样本来逼近积分。大数定律保证了收敛性。

```
Goal: estimate I = integral of g(x) dx over domain D

Method:
  1. Sample x_1, ..., x_N uniformly from D
  2. I ~ (Volume of D / N) * sum(g(x_i))

Error: O(1 / sqrt(N))   regardless of dimension
```

错误率与维度无关。这就是为什么蒙特卡罗方法在高维中占主导地位，而基于网格的集成是不可能的。

**估计圆周率:**

```
Sample (x, y) uniformly from [-1, 1] x [-1, 1]
Count how many fall inside the unit circle: x^2 + y^2 <= 1
pi ~ 4 * (count inside) / (total count)
```

**估计预期:**

```
E[f(X)] ~ (1/N) * sum(f(x_i))    where x_i ~ p(x)

The sample mean converges to the true expectation.
Variance of the estimator = Var(f(X)) / N
```

### 马尔科夫链蒙特卡洛（MCMC）：大都会黑斯廷斯

MCMC构造了一个平稳分布为目标分布p(x)的马尔可夫链。经过足够的步骤后，链上的样本（近似）是p(x)的样本。

```
Target: p(x)  (known up to a normalizing constant)
Proposal: q(x'|x)  (how to propose the next state given the current state)

Metropolis-Hastings algorithm:
  1. Start at some x_0
  2. For t = 1, 2, ..., T:
     a. Propose x' ~ q(x'|x_t)
     b. Compute acceptance ratio:
        alpha = [p(x') * q(x_t|x')] / [p(x_t) * q(x'|x_t)]
     c. Accept with probability min(1, alpha):
        - If u < alpha (u ~ Uniform(0,1)): x_{t+1} = x'
        - Otherwise: x_{t+1} = x_t
  3. Discard first B samples (burn-in)
  4. Return remaining samples
```

对于对称提议(q(x'|x) = q(x|x'))，比率简化为p(x')/p(x)。这是最初的Metropolis算法。

**为什么有效。**接受规则保证了详细平衡：在x处并移动到x‘的概率等于在x处并移动到x’的概率。详细平衡意味着p(x)是链的平稳分布。

**实际问题:**
- 老化：在链达到平衡之前丢弃早期样品
- 细化：保留每k个样本，以减少自相关性
- 提案规模：太小，链条移动缓慢（接受度高，探索速度慢）；太大，大多数提案被拒绝（接受度低，卡在原地）
- 高维高斯建议的最佳接受率约为0.234

### 吉布斯抽样

Gibbs抽样是多变量分布的MCMC的一种特殊情况。它不是一次在所有维度上提出移动，而是一次从条件分布中更新一个变量。

```
Target: p(x_1, x_2, ..., x_d)

Algorithm:
  For each iteration t:
    Sample x_1^{t+1} ~ p(x_1 | x_2^t, x_3^t, ..., x_d^t)
    Sample x_2^{t+1} ~ p(x_2 | x_1^{t+1}, x_3^t, ..., x_d^t)
    ...
    Sample x_d^{t+1} ~ p(x_d | x_1^{t+1}, x_2^{t+1}, ..., x_{d-1}^{t+1})
```

吉布斯抽样要求你可以从每个条件分布p（x_i | x_{-i}）中抽样。这对于许多模型来说都很简单：
- 贝叶斯网络：从图结构中得出条件
- 高斯混合：条件是高斯的
- 伊辛模型：每个自旋的条件只取决于它的邻居

接受率总是1（每个提议都被接受），因为从精确的条件中抽样会自动满足详细的平衡。

**限制。**当变量高度相关时，吉布斯抽样混合缓慢，因为一次更新一个变量不能在分布中进行大的对角线移动。

### 温度采样（用于LLMs）

语言模型输出logits z_1，…， z_V表示词汇表中的每个标记。Softmax将这些转换为概率。温度在softmax之前重新调整logits：

```
p_i = exp(z_i / T) / sum(exp(z_j / T))

T = 1.0: standard softmax (original distribution)
T -> 0:  argmax (deterministic, always picks highest logit)
T -> inf: uniform (all tokens equally likely)
T < 1.0: sharpens the distribution (more confident, less diverse)
T > 1.0: flattens the distribution (less confident, more diverse)
```

**为什么有效。**将logits除以T < 1可以放大logits之间的差异。如果z_1 = 2, z_2 = 1，除以T = 0.5得到z_1/T = 4, z_2/T = 2，使得差更大。在softmax之后，logit最高的令牌获得更大的份额。

*在实践中*:**
- T = 0.0：贪婪解码，最适合事实问答
- T = 0.3-0.7：稍微有创意，适合代码生成
- T = 0.7-1.0：平衡，适合一般谈话
- T = 1.0-1.5：创意写作，头脑风暴
- tbbb1.5：越来越随机，很少有用

温度不会改变哪些符号是可能的。它改变了分配给每个标记的概率质量。

### Top-k抽样

Top-k采样将候选集限制为具有最高概率的k个标记，然后从该限制集中重新规范化和采样。

```
Algorithm:
  1. Compute softmax probabilities for all V tokens
  2. Sort tokens by probability (descending)
  3. Keep only the top k tokens
  4. Renormalize: p_i' = p_i / sum(p_j for j in top-k)
  5. Sample from the renormalized distribution

k = 1:  greedy decoding
k = V:  no filtering (standard sampling)
k = 40: typical setting, removes long tail of unlikely tokens
```

Top-k防止模型选择存在于词汇表分布长尾中的极不可能的标记（拼写错误、无意义）。问题是：无论上下文如何，k都是固定的。当模型是可信的（一个令牌有95%的概率），k = 40仍然允许39个选择。当模型不确定时（概率分布在1000个令牌上），k = 40切断了可能的选项。

### Top-p（核）采样

Top-p采样动态调整候选集大小。它不保留固定数量的令牌，而是保留累积概率超过p的最小令牌集。

```
Algorithm:
  1. Compute softmax probabilities for all V tokens
  2. Sort tokens by probability (descending)
  3. Find smallest k such that sum of top-k probabilities >= p
  4. Keep only those k tokens
  5. Renormalize and sample

p = 0.9:  keeps tokens covering 90% of probability mass
p = 1.0:  no filtering
p = 0.1:  very restrictive, nearly greedy
```

当模型是自信的，核抽样保留很少的标记（可能2-3）。当模型不确定时，它会保留很多（可能是200个）。这种自适应行为就是为什么核采样通常比top-k生成更好的文本的原因。

**常见的组合:**
- 温度0.7 + top-p 0.9：良好的通用设置
- 温度0.0（贪婪）：最适合确定性任务
- 温度1.0 + top-k 50: Fan et al.（2018）原论文设定

Top-k和top-p可以组合。先用top-k，再用top-p。

### 重参数化技巧（用于VAEs）

变分自编码器（VAEs）通过将输入编码到潜在空间的分布中，从该分布中采样，然后解码样本来学习。问题是：不能通过抽样操作进行反向传播。

```
Standard sampling (not differentiable):
  z ~ N(mu, sigma^2)

  The randomness blocks gradient flow.
  d/d_mu [sample from N(mu, sigma^2)] = ???
```

重参数化技巧将随机性与参数分离：

```
Reparameterized sampling:
  epsilon ~ N(0, 1)          (fixed random noise, no parameters)
  z = mu + sigma * epsilon   (deterministic function of parameters)

  Now z is a deterministic, differentiable function of mu and sigma.
  d(z)/d(mu) = 1
  d(z)/d(sigma) = epsilon

  Gradients flow through mu and sigma.
```

因为N（，²）和+ * N（0,1）的分布是一样的。关键的见解是：将随机性移动到无参数源（epsilon），然后将样本表示为参数的可微变换。

**在VAE训练循环中：**
1. 编码器为每个输入输出mu和log（sigma^2）
2. 样本ε ~ N（0,1）
3. 计算z = + *
4. 解码z以重建输入
5. 反向传播通过步骤4,3,2,1（可能因为步骤3是可微的）

如果没有重参数化技巧，就不能用标准的反向传播来训练vae。这一见解使VAEs具有实用性。

### Gumbel-Softmax（可微分类抽样）

重参数化技巧适用于连续分布（高斯分布）。对于离散分类分布，我们需要一种不同的方法。Gumbel-Softmax提供了分类抽样的可微分近似。

** Gumbel-Max技巧（不可导）：**

```
To sample from a categorical distribution with log-probabilities log(p_1), ..., log(p_k):
  1. Sample g_i ~ Gumbel(0, 1) for each category
     (g = -log(-log(u)), where u ~ Uniform(0, 1))
  2. Return argmax(log(p_i) + g_i)

This produces exact categorical samples.
```

**Gumbel-Softmax（可微逼近）：**

```
Replace the hard argmax with a soft softmax:
  y_i = exp((log(p_i) + g_i) / tau) / sum(exp((log(p_j) + g_j) / tau))

tau (temperature) controls the approximation:
  tau -> 0:  approaches a one-hot vector (hard categorical)
  tau -> inf: approaches uniform (1/k, 1/k, ..., 1/k)
  tau = 1.0: soft approximation
```

Gumbel-Softmax产生离散样本的连续松弛。输出是一个概率向量（软的1 -hot）而不是硬的1 -hot。梯度流通过softmax。在训练中的向前传球期间，您可以使用“直通”估计器：对向前传球使用硬argmax，但对向后传球使用软Gumbel-Softmax梯度。

**应用程序:**
- VAEs中的离散潜在变量
- 神经结构搜索（选择离散操作）
- 硬注意力机制
- 离散行为的强化学习

### 分层抽样

标准蒙特卡罗采样可能会偶然地在样本空间中留下间隙。分层采样通过将空间划分为不同的层并从每个层中采样来强制均匀覆盖。

```
Standard Monte Carlo:
  Sample N points uniformly from [0, 1]
  Some regions may have clusters, others gaps

Stratified sampling:
  Divide [0, 1] into N equal strata: [0, 1/N), [1/N, 2/N), ..., [(N-1)/N, 1)
  Sample one point uniformly within each stratum
  x_i = (i + u_i) / N   where u_i ~ Uniform(0, 1),  i = 0, ..., N-1
```

与标准蒙特卡罗相比，分层抽样总是具有更低或相等的方差：

```
Var(stratified) <= Var(standard Monte Carlo)

The improvement is largest when f(x) varies smoothly.
For piecewise-constant functions, stratified sampling is exact.
```

**应用程序:**
- 数值积分(准蒙特卡罗)
- 训练数据分割（确保每一层的类平衡）
- 分层重要性抽样（结合两种技术）
- NeRF（神经辐射场）使用分层采样沿着相机光线

### 与扩散模型的联系

扩散模型通过采样过程生成图像。前向过程将高斯噪声添加到图像中，经过T步，直到它变成纯噪声。反向过程学习去噪，逐步恢复原始图像。

```
Forward process (known):
  x_t = sqrt(alpha_t) * x_{t-1} + sqrt(1 - alpha_t) * epsilon
  where epsilon ~ N(0, I)

  After T steps: x_T ~ N(0, I)  (pure noise)

Reverse process (learned):
  x_{t-1} = (1/sqrt(alpha_t)) * (x_t - (1 - alpha_t)/sqrt(1 - alpha_bar_t) * epsilon_theta(x_t, t)) + sigma_t * z
  where z ~ N(0, I)

  Each denoising step is a sampling step.
```

与本课方法的联系：
- 每个去噪步骤使用重参数化技巧（采样噪声，应用确定性变换）
- 噪声表{alpha_t}控制温度退火的一种形式
- 训练使用蒙特卡罗估计来近似ELBO（证据下界）。
- 扩散模型中的祖先抽样是一个马尔可夫链（每一步只取决于当前状态）。

整个图像生成过程是迭代采样：从噪声开始，每一步在学习到的去噪模型的条件下，采样噪声稍小的版本。

def top_k_sample(logits, k):
    indexed = sorted(enumerate(logits), key=lambda x: -x[1])
    top = indexed[:k]
    top_logits = [l for _, l in top]
    probs = softmax(top_logits)
    idx = sample_from_probs(probs)
    return top[idx][0]

def top_p_sample(logits, p):
    probs = softmax(logits)
    indexed = sorted(enumerate(probs), key=lambda x: -x[1])
    cumsum = 0
    selected = []
    for token_idx, prob in indexed:
        cumsum += prob
        selected.append((token_idx, prob))
        if cumsum >= p:
            break
    sel_probs = [pr for _, pr in selected]
    total = sum(sel_probs)
    sel_probs = [pr / total for pr in sel_probs]
    idx = sample_from_probs(sel_probs)
    return selected[idx][0]
```

def gumbel_sample():
    u = random.random()
    return -math.log(-math.log(u))

def gumbel_softmax(logits, temperature):
    gumbels = [math.log(p) + gumbel_sample() for p in logits]
    return softmax([g / temperature for g in gumbels])

## Key Terms

| Term | What people say | What it actually means |
|------|----------------|----------------------|
| Sampling | "Drawing random values" | Generating values according to a probability distribution. The mechanism behind all generative AI |
| Uniform distribution | "All equally likely" | Every value in [a, b] has equal probability density 1/(b-a). The starting point for all sampling methods |
| Inverse CDF | "Probability transform" | F_inverse(U) converts a uniform sample into a sample from any distribution with known CDF. Exact and efficient |
| Rejection sampling | "Propose and accept/reject" | Generate from a simple proposal, accept with probability proportional to target/proposal ratio. Exact but wastes samples |
| Importance sampling | "Reweight samples" | Estimate expectations under p(x) using samples from q(x) by weighting each sample by p(x)/q(x). Core to PPO in RL |
| Monte Carlo | "Average random samples" | Approximate integrals as sample averages. Error O(1/sqrt(N)) regardless of dimension |
| MCMC | "Random walk that converges" | Construct a Markov chain whose stationary distribution is the target. Metropolis-Hastings is the foundational algorithm |
| Metropolis-Hastings | "Accept uphill, sometimes downhill" | Propose moves, accept based on density ratio. Detailed balance ensures convergence to target distribution |
| Gibbs sampling | "One variable at a time" | Update each variable from its conditional distribution holding others fixed. 100% acceptance rate |
| Temperature | "Confidence knob" | Divides logits by T before softmax. T<1 sharpens (more confident), T>1 flattens (more diverse) |
| Top-k sampling | "Keep the k best" | Zero out all but the k highest-probability tokens, renormalize, sample. Fixed candidate set size |
| Nucleus sampling (top-p) | "Keep the probable ones" | Keep the smallest set of tokens whose cumulative probability exceeds p. Adaptive candidate set size |
| Reparameterization trick | "Move randomness outside" | Write z = mu + sigma * epsilon where epsilon ~ N(0,1). Makes sampling differentiable. Essential for VAE training |
| Gumbel-Softmax | "Soft categorical sampling" | Differentiable approximation to categorical sampling using Gumbel noise + softmax with temperature |
| Stratified sampling | "Forced coverage" | Divide sample space into strata, sample from each. Always lower variance than naive Monte Carlo |
| Burn-in | "Warm-up period" | Initial MCMC samples discarded before the chain reaches its stationary distribution |
| Detailed balance | "Reversibility condition" | p(x) * T(x->y) = p(y) * T(y->x). Sufficient condition for p to be the stationary distribution of a Markov chain |
| Diffusion sampling | "Iterative denoising" | Generate data by starting from noise and applying learned denoising steps. Each step is a conditional sampling operation |
