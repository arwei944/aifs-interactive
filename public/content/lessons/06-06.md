# Speaker identification and verification

> ASR asked, "What did they say?" Speaker recognition will ask, "Who said it?" Mathematics seems the same - embedding plus cosine - but each production decision depends on a single EER number.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 6 · 02 (Spectrograms & Mel), Phase 5 · 22 (Embedding Models)
**Time:** ~45 minutes

## This question

The user enters a passphrase. You want to know: Is this the person they claim to be (* verification *, 1:1), or the first person you register with the bank (* verification *, 1:n)? Or neither - is this an unknown speaker (* open *)?

Before 2018: GMM-UBM + i-vectors. A reasonable EER, but it is easily affected by channel switching (mobile phone vs. laptop) and emotions. 2018-2022: x Vector (TDNN backbone trained with corner edges). 2022+: ECAPA-TDNN and wavlm - Large Embeddings. By 2026, this field will be dominated by three models and one indicator.

The metric is EER - equal error rate. Set the decision threshold so that the false acceptance rate equals the false rejection rate. The intersection is EER. I have used every newspaper, every ranking list and every purchasing call.

*AAM-softmax. Standard softmax and additional margins enforce angular separation between classes. Typical

### Score

- Register and test the cosine value between the embedding. Determined based on the threshold.
- PLDA (Probability LDA). The project is embedded in the latent space, where the same speaker has a closed likelihood ratio with different speakers. Add a 10-20% EER reduction at the top of the cosine. The standard was before 2020. It is currently only used for closed Settings.
- "Score normalization. It is crucial for cross-domain eval.

### Diarization

"Who is speaking and when?" Pipeline: VAD→ Segmentation → Embedding in each segment → Clustering (condensation or spectroscopy) → Smoothing boundaries. Modern stack: The SOTA ratio of AMI in 2026 is approximately 15% (lower than 23% in 2022).

### Step 2: cosine similarity + threshold

```python
def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    na = math.sqrt(sum(x * x for x in a))
    nb = math.sqrt(sum(x * x for x in b))
    return dot / (na * nb) if na and nb else 0.0

def verify(enroll, test, threshold=0.75):
    return cosine(enroll, test) >= threshold
```

## Use It

The 2026 stack:

| Situation | Pick |
|-----------|------|
| Closed-set 1:1 verification, edge | ECAPA-TDNN + cosine threshold |
| Open-set verification, cloud | WavLM-SV + AS-norm |
| Diarization (meetings, podcasts) | `pyannote/speaker-diarization-3.1` |
| Anti-spoofing (replay / deepfake detection) | AASIST or RawNet2 |
| Tiny embedded (KWS + enrollment) | Titanet-Small (NeMo) |

## Pitfalls

- **Channel mismatch.** Model trained on VoxCeleb (web video) ≠ phone-call audio. Always evaluate on target channel.
- **Short utterances.** EER degrades sharply below 3 seconds of test audio.
- **Enrollment with noise.** One noisy enrollment poisons the anchor. Use ≥3 clean samples and average.
- **Fixed threshold across conditions.** Always tune the threshold on a held-out dev set from the target domain.
- **Cosine on non-normalized embeddings.** L2-normalize first; otherwise the magnitude dominates.

## Key Terms

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| EER | The headline metric | Threshold where False Accept = False Reject. |
| Verification | 1:1 | "Is this Alice?" |
| Identification | 1:N | "Who is speaking?" |
| Open-set | Unknown possible | Test set can contain unenrolled speakers. |
| Enrollment | Registering | Computing a speaker's reference embedding. |
| AAM-softmax | The loss | Softmax with additive angular margin; forces cluster separation. |
| PLDA | Classic scoring | Probabilistic LDA; likelihood-ratio scoring on top of embeddings. |
| DER | Diarization metric | Diarization Error Rate — miss + false alarm + confusion. |
